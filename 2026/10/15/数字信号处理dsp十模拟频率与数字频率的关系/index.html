模拟频率与数字频率的关系

标签： #数字信号处理 #DSP #采样 #频率关系 #归一化频率

一、基本概念

在处理离散时间信号时，需要区分两种频率：

  • 模拟频率：描述连续时间信号的频率，单位为赫兹（Hz）或弧度/秒（rad/s）。
  • 数字频率：描述离散时间信号的频率，单位为弧度（rad），是归一化的角频率。

两者的桥梁只有一个数：采样频率 fsf_sfs​。所以凡涉及换算，"fsf_sfs​ 是多少"永远是第一个要问的问题。

三、核心关系式

1. 数字频率与模拟角频率的关系

ω=ΩTs=Ωfs\omega = \Omega T_s = \frac{\Omega}{f_s} ω=ΩTs​=fs​Ω​

即数字角频率等于模拟角频率乘以采样周期。

2. 数字频率与模拟频率的关系

ω=2πfTs=2πffs\omega = 2\pi f T_s = \frac{2\pi f}{f_s} ω=2πfTs​=fs​2πf​

3. 归一化频率（有两种约定，务必分清）

fnorm=ffs/2=2ffs=ωπ,fnorm∈[0, 1]f_{\text{norm}} = \frac{f}{f_s/2} = \frac{2f}{f_s} = \frac{\omega}{\pi},\qquad f_{\text{norm}}\in[0,\ 1] fnorm​=fs​/2f​=fs​2f​=πω​,fnorm​∈[0, 1]

1. 为什么数字频率是周期的？

上图：两条连续余弦 cos⁡(ω0t)\cos(\omega_0 t)cos(ω0​t)（蓝，ω0=π/3\omega_0=\pi/3ω0​=π/3）与 cos⁡[(ω0+2π)t]\cos[(\omega_0+2\pi)t]cos[(ω0​+2π)t]（橙虚线）在连续域里波形完全不同；但以整数 nnn 采样后，两者的离散值逐点重合（下图的蓝茎与红茎完全叠在一起）。数字频率相差 2π2\pi2π 时对应同一个离散序列。

ej(ω+2π)n=ejωn⋅ej2πn=ejωne^{j(\omega + 2\pi)n} = e^{j\omega n} \cdot e^{j2\pi n} = e^{j\omega n} ej(ω+2π)n=ejωn⋅ej2πn=ejωn

所以 ω\omegaω 与 ω+2πk\omega + 2\pi kω+2πk 描述同一个离散序列。数字频率"卷"成了一个周长 2π2\pi2π 的圆，这正是（一）信号周期性判断）里那条结论的根源：判周期要用 ω0/2π\omega_0/2\piω0​/2π 是否为有理数。

2. 为什么"最高频率"只到 π\piπ？

数字频率 ω=π\omega = \piω=π 对应的模拟频率是

f=ωfs2π=fs2f = \frac{\omega f_s}{2\pi} = \frac{f_s}{2} f=2πωfs​​=2fs​​

正好是 Nyquist 频率。再高的模拟频率采样后会折叠回 (−π,π](-\pi, \pi](−π,π]，所以数字域里 π\piπ 就是"最高音"，ω\omegaω 超过 π\piπ 不是"更高频"，而是"换个说法表示同一个低频"。

为什么 ω=π\omega=\piω=π 是"最快振荡"：此时序列为 (−1)n(-1)^n(−1)n，相邻两点符号必然相反，一个采样点就完成半周期——这已经是离散序列能做到的最快变化。再快也"看不出来"了（这就是混叠的物理本质）。

3. 负频率是什么？

负 ω\omegaω 不是"频率为负"的物理概念，而是复数表示的产物：实信号的频谱满足共轭对称 ω\omegaω 与 −ω-\omega−ω 成对出现。工程上讨论实信号时通常只看 0≤ω≤π0 \leq \omega \leq \pi0≤ω≤π 的正频率部分即可。

五、采样定理的约束

根据奈奎斯特采样定理，为避免混叠，需满足：

fs>2fmax⁡f_s \gt 2f_{\max} fs​>2fmax​

即采样频率必须大于信号最高频率的两倍。

在数字频率中，这等价于：

ωmax⁡=2πfmax⁡fs<π\omega_{\max} = \frac{2\pi f_{\max}}{f_s} \lt \pi ωmax​=fs​2πfmax​​<π

因此，数字频率的有效范围为 ∣ω∣<π\lvert \omega \rvert \lt \pi∣ω∣<π（对应模拟频率 ∣f∣<fs/2\lvert f \rvert \lt f_s/2∣f∣<fs​/2）。

六、混叠频率怎么算（工程必会）

若模拟频率 fff 超过了 fs/2f_s/2fs​/2，采样后会"折返"成一个较低的表观频率 faf_afa​。计算方法只有一句话：

把 fff 对 fsf_sfs​ 取余，若余数超过 fs/2f_s/2fs​/2 再用 fsf_sfs​ 减一次。

f  →  mod fs   r  ⟹  fa={r,r≤fs/2fs−r,r>fs/2f \;\xrightarrow{\ \bmod f_s\ }\; r \;\Longrightarrow\; f_a = \begin{cases} r, & r\le f_s/2\\ f_s-r, & r\gt f_s/2 \end{cases} f modfs​ ​r⟹fa​={r,fs​−r,​r≤fs​/2r>fs​/2​

对应的数字频率 ωa=2πfafs\omega_a = \dfrac{2\pi f_a}{f_s}ωa​=fs​2πfa​​（落在 [0,π][0,\pi][0,π]）。

为什么这样折：采样序列是 cos⁡(2πfn/fs)\cos(2\pi fn/f_s)cos(2πfn/fs​)，把 fff 换成 f−kfsf-kf_sf−kfs​ 后 2π(f−kfs)n/fs=2πfn/fs−2πkn2\pi(f-kf_s)n/f_s = 2\pi fn/f_s-2\pi kn2π(f−kfs​)n/fs​=2πfn/fs​−2πkn，多出的 2πkn2\pi kn2πkn 对整数 nnn 恒为 2π2\pi2π 的整数倍，序列不变。所以 fff、f±fsf\pm f_sf±fs​、f±2fsf\pm2f_sf±2fs​…采样结果完全相同。再配合 cos⁡\coscos 的偶对称把负值翻正，就得到上面的折返公式。

八、常见错误提醒

  1. 混淆数字频率与模拟频率：数字频率是无量纲的，不要直接当作 Hz 使用；读 FFT 结果时忘了乘 fs/Nf_s/Nfs​/N 是最高频的错误。
  2. 忽略采样频率的影响：同一个模拟频率在不同采样率下对应的数字频率不同，"ω=π/3\omega = \pi/3ω=π/3 是多少赫兹"必须先问 fsf_sfs​。
  3. 把换算公式写反：正确是 ω=Ω/fs\omega=\Omega/f_sω=Ω/fs​（除以），Ω=ωfs\Omega=\omega f_sΩ=ωfs​（乘以）。用"fsf_sfs​ 越大 ω\omegaω 越小"来自检。
  4. 误认为数字频率范围是无限的：数字频率只在长度为 2π2\pi2π 的区间内有意义，超出部分折叠回该区间（混叠），见（十一）奈奎斯特采样定理。
  5. 归一化频率两套约定混用：约定 A 是 F=f/fs∈[0,0.5]F=f/f_s\in[0,0.5]F=f/fs​∈[0,0.5]，约定 B 是 f/(fs/2)∈[0,1]f/(f_s/2)\in[0,1]f/(fs​/2)∈[0,1]，差一个因子 2。看到具体数值先确认属于哪套。
  6. 以为 ω\omegaω 越大频率越高：ω\omegaω 只在一个 2π2\pi2π 周期内可比大小；ω=1.5π\omega = 1.5\piω=1.5π 实际上等价于 ω=−0.5π\omega = -0.5\piω=−0.5π，是低频。
  7. 混叠频率只取余不镜像：取余后若大于 fs/2f_s/2fs​/2，还要用 fsf_sfs​ 再减一次。漏了这步结果会大于 Nyquist 频率，自相矛盾。
  8. 在换算时漏掉 2π2\pi2π：f=ωfs/(2π)f = \omega f_s/(2\pi)f=ωfs​/(2π) 里的 2π2\pi2π 来自"角频率 ↔ 频率"，Ω=ωfs\Omega = \omega f_sΩ=ωfs​ 则是角频率之间的换算，两者别搞混。
  9. 不区分 TsT_sTs​ 与 fsf_sfs​：ω=ΩTs=Ω/fs\omega = \Omega T_s = \Omega/f_sω=ΩTs​=Ω/fs​，写成 ω=Ωfs\omega = \Omega f_sω=Ωfs​ 是高频错误。

九、应用场景

  • 数字滤波器设计：通常先指定数字频率指标（如通带截止频率 ωp\omega_pωp​），再根据采样频率换算为模拟频率。
  • 频谱分析：FFT输出的横轴通常是数字频率（归一化到 0∼2π0\sim 2\pi0∼2π），需结合采样频率转换为实际频率。
  • 系统函数与频率响应：频率响应 H(ejω)H(e^{j\omega})H(ejω) 的自变量 ω\omegaω 就是数字角频率。
  • 振动/声学测量：要从谱峰索引反推机械转速或声源频率，必须做 f=kfs/Nf=kf_s/Nf=kfs​/N 的换算。
