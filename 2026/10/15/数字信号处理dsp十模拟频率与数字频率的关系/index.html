【数字信号处理DSP】（十）模拟频率与数字频率的关系

模拟频率与数字频率的关系

标签： #数字信号处理 #DSP #采样 #频率关系 #归一化频率

一、基本概念

在处理离散时间信号时，需要区分两种频率：

  • 模拟频率：描述连续时间信号的频率，单位为赫兹（Hz）或弧度/秒（rad/s）。
  • 数字频率：描述离散时间信号的频率，单位为弧度（rad），是归一化的角频率。

二、符号约定

符号 含义 单位
fff 模拟频率（每秒周期数） Hz
Ω\OmegaΩ 模拟角频率 rad/s
fsf_sfs​ 采样频率（每秒样本数） Hz
TsT_sTs​ 采样周期 s
ω\omegaω 数字角频率 rad（无量纲）

关系：Ω=2πf\Omega = 2\pi fΩ=2πf，Ts=1/fsT_s = 1/f_sTs​=1/fs​

三、核心关系式

1. 数字频率与模拟角频率的关系

ω=ΩTs=Ωfs\omega = \Omega T_s = \frac{\Omega}{f_s} ω=ΩTs​=fs​Ω​

即数字角频率等于模拟角频率乘以采样周期。

2. 数字频率与模拟频率的关系

ω=2πfTs=2πffs\omega = 2\pi f T_s = \frac{2\pi f}{f_s} ω=2πfTs​=fs​2πf​

3. 归一化频率

有时定义归一化频率 FFF（无量纲，范围0~1）：

F=ffs=ω2πF = \frac{f}{f_s} = \frac{\omega}{2\pi} F=fs​f​=2πω​

此时数字角频率 ω=2πF\omega = 2\pi Fω=2πF。

1. 为什么数字频率是周期的？

上图：两条连续正弦 sin⁡(0.3πt)\sin(0.3\pi t)sin(0.3πt)（蓝）与 sin⁡(2.3πt)\sin(2.3\pi t)sin(2.3πt)（橙）形状不同，但在整数采样点 nnn 上取到的离散值完全相同（红圈）。数字频率相差 2π2\pi2π 时对应同一个离散序列。

ej(ω+2π)n=ejωn⋅ej2πn=ejωne^{j(\omega + 2\pi)n} = e^{j\omega n} \cdot e^{j2\pi n} = e^{j\omega n} ej(ω+2π)n=ejωn⋅ej2πn=ejωn

所以 ω\omegaω 与 ω+2πk\omega + 2\pi kω+2πk 描述同一个离散序列。数字频率"卷"成了一个周长 2π2\pi2π 的圆，这正是（一）信号周期性判断）里那条结论的根源：判周期要用 ω0/2π\omega_0/2\piω0​/2π 是否为有理数。

2. 为什么"最高频率"只到 π\piπ？

数字频率 ω=π\omega = \piω=π 对应的模拟频率是

f=ωfs2π=fs2f = \frac{\omega f_s}{2\pi} = \frac{f_s}{2} f=2πωfs​​=2fs​​

正好是 Nyquist 频率。再高的模拟频率采样后会折叠回 (−π,π](-\pi, \pi](−π,π]，所以数字域里 π\piπ 就是"最高音"，ω\omegaω 超过 π\piπ 不是"更高频"，而是"换个说法表示同一个低频"。

3. 负频率是什么？

负 ω\omegaω 不是"频率为负"的物理概念，而是复数表示的产物：实信号的频谱满足共轭对称 ω\omegaω 与 −ω-\omega−ω 成对出现。工程上讨论实信号时通常只看 0≤ω≤π0 \leq \omega \leq \pi0≤ω≤π 的正频率部分即可。

五、采样定理的约束

根据奈奎斯特采样定理，为避免混叠，需满足：

fs>2fmax⁡f_s \gt 2f_{\max} fs​>2fmax​

即采样频率必须大于信号最高频率的两倍。

在数字频率中，这等价于：

ωmax⁡=2πfmax⁡fs<π\omega_{\max} = \frac{2\pi f_{\max}}{f_s} \lt \pi ωmax​=fs​2πfmax​​<π

因此，数字频率的有效范围为 ∣ω∣<π\lvert \omega \rvert \lt \pi∣ω∣<π（对应模拟频率 ∣f∣<fs/2\lvert f \rvert \lt f_s/2∣f∣<fs​/2）。

七、常见错误提醒

  1. 混淆数字频率与模拟频率：数字频率是无量纲的，不要直接当作 Hz 使用；读 FFT 结果时忘了乘 fsf_sfs​ 是最高频的错误。
  2. 忽略采样频率的影响：同一个模拟频率在不同采样率下对应的数字频率不同，"ω=π/3\omega = \pi/3ω=π/3 是多少赫兹"必须先问 fsf_sfs​。
  3. 误认为数字频率范围是无限的：数字频率只在长度为 2π2\pi2π 的区间内有意义，超出部分折叠回该区间（混叠），见（十一）奈奎斯特采样定理。
  4. 把 FFF 和 ω\omegaω 混用：F=f/fsF = f/f_sF=f/fs​（范围 0∼0.50 \sim 0.50∼0.5 或 0∼10 \sim 10∼1），ω=2πF\omega = 2\pi Fω=2πF（范围 0∼π0 \sim \pi0∼π 或 0∼2π0 \sim 2\pi0∼2π），两者差一个 2π2\pi2π。
  5. 以为 ω\omegaω 越大频率越高：ω\omegaω 只在一个 2π2\pi2π 周期内可比大小；ω=1.5π\omega = 1.5\piω=1.5π 实际上等价于 ω=−0.5π\omega = -0.5\piω=−0.5π，是低频。
  6. 在换算时漏掉 2π2\pi2π：f=ωfs/(2π)f = \omega f_s/(2\pi)f=ωfs​/(2π) 里的 2π2\pi2π 来自"角频率 ↔ 频率"，Ω=ωfs\Omega = \omega f_sΩ=ωfs​ 则是角频率之间的换算，两者别搞混。
  7. 不区分 TsT_sTs​ 与 fsf_sfs​：ω=ΩTs=Ω/fs\omega = \Omega T_s = \Omega/f_sω=ΩTs​=Ω/fs​，写成 ω=Ωfs\omega = \Omega f_sω=Ωfs​ 是高频错误。

八、应用场景

  • 数字滤波器设计：通常先指定数字频率指标（如通带截止频率 ωp\omega_pωp​），再根据采样频率换算为模拟频率。
  • 频谱分析：FFT输出的横轴通常是数字频率（归一化到 0∼2π0\sim 2\pi0∼2π），需结合采样频率转换为实际频率。
  • 系统函数与频率响应：频率响应 H(ejω)H(e^{j\omega})H(ejω) 的自变量 ω\omegaω 就是数字角频率。
