【数字信号处理DSP】（十二）系统互联

系统互联

标签： #数字信号处理 #DSP #系统互联 #级联 #并联 #反馈

一、为什么需要研究系统互联？

实际的数字信号处理系统很少只由一个环节构成，而是若干简单子系统连接起来的结果：

  • 一个 FIR 均衡器后面接一个 IIR 陷波器 —— 级联
  • 两路不同滤波器的输出相加，凑出梳状或更陡的过渡带 —— 并联
  • 把输出的一部分送回输入端去修正输入，构成 IIR 滤波器、锁相环、控制器 —— 反馈

把复杂系统拆成模块再互联，好处是可复用、可调试、可分步设计。但拆开之后绕不开三个问题：

  1. 功能问题：已知各子系统的 hi[n]h_i[n]hi​[n] 或 Hi(z)H_i(z)Hi​(z)，整体系统的 h[n]h[n]h[n]、H(z)H(z)H(z) 怎么求？
  2. 性质问题：各子系统的因果性、稳定性，互联之后还在不在？
  3. 实现问题：功能相同的系统，哪种互联结构运算量更小、存储更省、定点实现时舍入噪声更小？

本节回答前两个问题，第三个问题给出定性的判断标准。它是「差分方程」与「系统函数」之间的桥梁，也是后面讲数字滤波器结构（直接型、级联型、并联型）的直接基础。

本节要建立的三条直觉

  • 级联 → 冲激响应卷积、系统函数相乘；
  • 并联 → 冲激响应相加、系统函数相加；
  • 反馈 → 唯一会改写极点位置的结构，所以每一条闭环都必须重新判稳。

二、基本运算单元与框图表示

任何 LTI 离散时间系统，最终都可以只用三种基本单元互联实现：

读图的三个步骤

反过来，给定框图求系统函数，机械地做三件事就够了：

  1. 给每个加法器输出起个名字（e[n],w[n],y[n]e[n], w[n], y[n]e[n],w[n],y[n]……）；
  2. 沿箭头方向，在每个加法器处写一个方程（输入之和 = 该节点信号）；
  3. 在 z 域联立消去所有中间变量，只留 Y(z)Y(z)Y(z) 与 X(z)X(z)X(z)。

这三步对任何复杂的互联结构都成立，是后面级联、并联、反馈、混联所有公式的统一来源。记住步骤比背公式可靠。

三、级联（串联）

上图：一阶低通 H1H_1H1​ 与二阶陷波器 H2H_2H2​（零点位于单位圆上的 e±jπ/2e^{\pm j\pi/2}e±jπ/2）级联。三个子系统各自都是「平的」或者「宽凹的」，但相乘之后，整体同时具备低通形状与 ω=π/2\omega=\pi/2ω=π/2 处的零增益陷波。注意级联只能相乘：某处只要有一个子系统为零，整体就为零；但一个子系统做不到的深谷，另一个也补不出来。

1. 定义

两个系统首尾相连，前一个的输出作为后一个的输入。

graph LR
  X["x[n]"] --> S1["系统 1<br/>h₁[n]"] --> W["w[n]"] --> S2["系统 2<br/>h₂[n]"] --> Y["y[n]"]

2. 整体单位脉冲响应

中间信号 w[n]=h1[n]∗x[n]w[n] = h_1[n] * x[n]w[n]=h1​[n]∗x[n]，输出 y[n]=h2[n]∗w[n]y[n] = h_2[n] * w[n]y[n]=h2​[n]∗w[n]。由卷积的结合律：

h[n]=h1[n]∗h2[n]=h2[n]∗h1[n]h[n] = h_1[n] * h_2[n] = h_2[n] * h_1[n] h[n]=h1​[n]∗h2​[n]=h2​[n]∗h1​[n]

也就是说：级联系统的单位脉冲响应等于各子系统单位脉冲响应的卷积。

3. 整体系统函数

对两边取 Z 变换，时域卷积对应 z 域相乘：

H(z)=H1(z)⋅H2(z)H(z) = H_1(z) \cdot H_2(z) H(z)=H1​(z)⋅H2​(z)

同理，频域上幅频特性相乘、相频特性相加：

H(ejω)=H1(ejω) H2(ejω),∣H(ejω)∣=∣H1∣⋅∣H2∣,∠H=∠H1+∠H2H(e^{j\omega}) = H_1(e^{j\omega}) \, H_2(e^{j\omega}), \qquad \lvert H(e^{j\omega}) \rvert = \lvert H_1 \rvert \cdot \lvert H_2 \rvert, \qquad \angle H = \angle H_1 + \angle H_2 H(ejω)=H1​(ejω)H2​(ejω),∣H(ejω)∣=∣H1​∣⋅∣H2​∣,∠H=∠H1​+∠H2​

取对数之后乘法变加法：20lg⁡∣H∣=20lg⁡∣H1∣+20lg⁡∣H2∣20\lg\lvert H\rvert = 20\lg\lvert H_1\rvert + 20\lg\lvert H_2\rvert20lg∣H∣=20lg∣H1​∣+20lg∣H2​∣。这就是伯德图能「把级联系统的曲线直接叠起来看」的原因，也是工程上大量使用 dB 的实际动机。

4. 极零点集合：直接并起来

设 H1=N1/D1H_1 = N_1/D_1H1​=N1​/D1​、H2=N2/D2H_2 = N_2/D_2H2​=N2​/D2​，则

H(z)=N1(z)N2(z)D1(z)D2(z)H(z) = \frac{N_1(z) N_2(z)}{D_1(z) D_2(z)} H(z)=D1​(z)D2​(z)N1​(z)N2​(z)​

于是

  • 零点 = H1H_1H1​ 的零点 ∪\cup∪ H2H_2H2​ 的零点（重数相加）
  • 极点 = H1H_1H1​ 的极点 ∪\cup∪ H2H_2H2​ 的极点（重数相加）

级联不会凭空造出新极点，也不会凭空消掉极点 —— 除非两个子系统的零点、极点恰好落在同一位置（极零相消），那属于人为设计，不是级联本身的性质。

5. 收敛域（ROC）

级联后极点是两个子系统极点集合的并集，所以一般有

R⊇R1∩R2R \supseteq R_1 \cap R_2 R⊇R1​∩R2​

注意是包含而不是等于。若某子系统的极点恰好被另一个子系统的零点抵消（极零相消），公共部分会扩大，甚至整体可能变成有限长系统。

例：H1(z)=1−2z−1H_1(z) = 1 - 2z^{-1}H1​(z)=1−2z−1（零点 z=2z=2z=2）与 H2(z)=11−2z−1H_2(z) = \dfrac{1}{1 - 2z^{-1}}H2​(z)=1−2z−11​（极点 z=2z=2z=2，ROC 为 ∣z∣>2\lvert z \rvert \gt 2∣z∣>2）级联，整体 H(z)=1H(z)=1H(z)=1，ROC 变成整个 z 平面。

工程提醒：这种「用不稳定子系统抵消出稳定系统」在数学上成立，实际实现时中间信号 w[n]=2nu[n]w[n] = 2^n u[n]w[n]=2nu[n] 会发散到溢出，工程上不能这样搭。理论等价 ≠ 实现等价，这是本节反复出现的主题。

6. 性质

  • 卷积满足交换律，级联顺序不影响整体响应（仅对 LTI 系统成立）
  • 卷积满足结合律，多个系统可以任意分组化简
  • 各子系统稳定 ⇒ 级联稳定（BIBO 稳定性由 ∑∣h[n]∣<∞\sum \lvert h[n] \rvert \lt \infty∑∣h[n]∣<∞ 判断，卷积后仍是绝对可和）
  • 各子系统因果 ⇒ 级联因果
  • 反过来不成立：整体稳定/因果，推不出每个子系统都稳定/因果

7. 顺序与代价：为什么工程上仍然要挑顺序

理论上 h1∗h2=h2∗h1h_1 * h_2 = h_2 * h_1h1​∗h2​=h2​∗h1​，实际实现却有区别：

差别 说明
阶次 总阶次 = 各子系统阶次之和，与顺序无关
中间信号动态范围 先放大再衰减，中间信号可能溢出；先衰减再放大，可能被量化噪声淹没
定点舍入噪声 增益大的环节放前面，噪声被后面的衰减压下去；反过来噪声被放大

所以**「可交换」是数学结论，「随便换」不是工程结论**。滤波器设计软件里能手动拖级联顺序，就是给这件事留的操作空间。

四、并联

1. 定义

两个系统共用同一输入，输出相加。

graph LR
  X["x[n]"] --> S1["系统 1<br/>h₁[n]"]
  X --> S2["系统 2<br/>h₂[n]"]
  S1 --> SUM(("Σ"))
  S2 --> SUM
  SUM --> Y["y[n]"]

2. 整体单位脉冲响应

由系统的线性（叠加原理）：

h[n]=h1[n]+h2[n]h[n] = h_1[n] + h_2[n] h[n]=h1​[n]+h2​[n]

并联系统的单位脉冲响应等于各子系统单位脉冲响应之和。

3. 整体系统函数

H(z)=H1(z)+H2(z),H(ejω)=H1(ejω)+H2(ejω)H(z) = H_1(z) + H_2(z), \qquad H(e^{j\omega}) = H_1(e^{j\omega}) + H_2(e^{j\omega}) H(z)=H1​(z)+H2​(z),H(ejω)=H1​(ejω)+H2​(ejω)

注意频域是复数相加而不是模相加，两路信号可能同相叠加、也可能反相抵消 —— 这正是并联结构能造出「陷波零点」的原因。

举一个最小例子：H1=11−0.9z−1H_1 = \dfrac{1}{1-0.9z^{-1}}H1​=1−0.9z−11​、H2=−0.9z−11−0.9z−1H_2 = \dfrac{-0.9z^{-1}}{1-0.9z^{-1}}H2​=1−0.9z−1−0.9z−1​，两路幅度几乎一样、相位反着来，相加得 H=1−0.9z−11−0.9z−1=1H = \dfrac{1-0.9z^{-1}}{1-0.9z^{-1}} = 1H=1−0.9z−11−0.9z−1​=1。这就是一个梳状/补偿思想的雏形。

4. 极零点与 ROC

通分：

H(z)=N1D1+N2D2=N1D2+N2D1D1D2H(z) = \frac{N_1}{D_1} + \frac{N_2}{D_2} = \frac{N_1 D_2 + N_2 D_1}{D_1 D_2} H(z)=D1​N1​​+D2​N2​​=D1​D2​N1​D2​+N2​D1​​

  • 极点：仍是 H1H_1H1​ 与 H2H_2H2​ 的极点并集（因为分母就是 D1D2D_1D_2D1​D2​），除非分子恰在这些位置也为零
  • 零点：由 N1D2+N2D1=0N_1D_2 + N_2D_1 = 0N1​D2​+N2​D1​=0 决定，不能由子系统零点直接得到 —— 这是并联与级联最大的差别

R⊇R1∩R2R \supseteq R_1 \cap R_2 R⊇R1​∩R2​

稳定性方面比级联苛刻：只要有一个子系统不稳定，整体一般就不稳定，除非两个不稳定子系统恰好完全相消（例如 H1=11−az−1H_1 = \frac{1}{1-az^{-1}}H1​=1−az−11​ 与 H2=−11−az−1H_2 = -\frac{1}{1-az^{-1}}H2​=−1−az−11​ 相加得 0，同样存在中间信号发散的实际问题）。

七、运算律与框图变换

由于 LTI 系统的互联本质上是卷积与加法的运算，三条运算律直接对应三种框图变换：

运算律 表达式 框图含义
交换律 h1∗h2=h2∗h1h_1 * h_2 = h_2 * h_1h1​∗h2​=h2​∗h1​ 级联的两个系统可以前后对调
结合律 (h1∗h2)∗h3=h1∗(h2∗h3)(h_1 * h_2) * h_3 = h_1 * (h_2 * h_3)(h1​∗h2​)∗h3​=h1​∗(h2​∗h3​) 级联可以任意分组，也可合并成一个系统

分配律这条最有用：它说明级联型和并联型结构可以互相转换。同一个 H(z)H(z)H(z) 既可以写成若干一阶/二阶环节级联，也可以部分分式展开成若干支路并联 —— 两种结构的运算量、存储量、字长效应对噪声的敏感度都不同，这正是后面讨论滤波器结构时反复使用的自由度。

两条重要限制：

  1. 运算律只对 LTI（线性时不变）子系统成立。 若某个模块是非线性（如限幅、量化）或时变的（如系数随时间变化、自适应滤波器的更新环节），交换顺序会改变整体行为。
  2. 理论等价 ≠ 实现等价。 级联顺序可交换是数学结论，但不同顺序的中间信号动态范围不同，定点实现时的舍入噪声也不同，工程上仍要挑顺序。

九、常见错误提醒

  1. 级联与并联的规律记反：级联对应卷积、相乘；并联对应相加、相加。小心「并联却把系统函数相乘」这类低级错。
  2. ROC 直接写成交集：严格地说只是包含关系，极零相消时 ROC 会扩大；解题时若发现分子分母有公因子，必须先约掉再定 ROC。
  3. 忽视「中间信号发散」：用不稳定子系统相消得到稳定整体，数学上成立但不可实现，工程上不采用。
  4. 反馈公式的符号弄错：负反馈分母是 1+GF1 + GF1+GF，正反馈是 1−GF1 - GF1−GF；先分清哪个是前向、哪个是反馈再套公式。
  5. 用开环稳定性代替闭环稳定性：必须解特征方程求闭环极点，前向、反馈各自稳定不代表闭环稳定。
  6. 以为闭环零点还是开环零点：闭环零点 = 前向通路零点 ∪\cup∪ 反馈通路极点，是真的会「无中生有」的。
  7. 回路里没有延迟：无延迟回路（代数环）无法实时按样本计算，框图必须含 z−1z^{-1}z−1。
  8. 对非 LTI 模块套用运算律：时变、非线性模块不能随意交换或合并。
  9. 以为并联一定「叠加增强」：频域是复数相加，可能反相相消，并联既能造峰值也能造陷波。
  10. 滥用 H(1)=∑h[n]H(1)=\sum h[n]H(1)=∑h[n] 做检验：这个等式只在 ROC 含 z=1z=1z=1（即系统稳定）时成立；对不稳定系统拿它验算会得出「矛盾」的假象。

十一、总结

  • 级联：整体冲激响应是卷积，系统函数是乘积（时域卷积 ↔ z 域相乘）；极零点是两子系统的并集。
  • 并联：整体冲激响应是相加，系统函数是相加；频域复数相加可能相消，极点保留、零点重算。
  • 反馈：H(z)=G(z)1±G(z)F(z)H(z) = \dfrac{G(z)}{1 \pm G(z)F(z)}H(z)=1±G(z)F(z)G(z)​，闭环极点由特征方程全新给出；一阶情形 p闭环=p1±kp_{\text{闭环}}=\dfrac{p}{1\pm k}p闭环​=1±kp​，负反馈用增益换带宽，正反馈 k>1k\gt1k>1 直接出圈。
  • 混联：由内向外、先并后串；结构复杂时可用梅森增益公式一次写对。
  • 稳定性与因果性在级联中可继承、在并联中较脆弱、在反馈中必须重判；ROC 一律按「包含交集」处理，约分之后要重定。
  • LTI 系统的互联结果仍是 LTI 系统，所以三条运算律（交换、结合、分配）可以自由用于框图变换 —— 但「可交换」不等于「可随便换」，工程上还要看动态范围与噪声。

一句话总结：级联是串在一起 —— 冲激响应做卷积、系统函数做乘积；并联是并排走 —— 冲激响应与系统函数都做加法；反馈是绕回来 —— 它唯一会改写极点位置，所以每一条闭环都必须单独判稳。掌握这三条，再复杂的系统也能由内向外拆解清楚。
