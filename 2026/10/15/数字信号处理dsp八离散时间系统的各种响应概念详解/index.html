【数字信号处理DSP】（八）离散时间系统的各种响应概念详解

离散时间系统的各种响应概念详解

标签： #数字信号处理 #DSP #系统响应 #零输入响应 #零状态响应 #自由响应 #强迫响应

一、为什么要区分不同的响应？

系统的输出不仅取决于输入信号，还取决于系统内部的初始状态（如寄存器初值、电容初始电压等）。为了清楚分析输出的来源，我们将全响应分解为不同的分量，每个分量有明确的物理意义和数学形式。

二、五大核心响应概念

上图：同一个一阶系统 h[n]=0.6nu[n]h[n]=0.6^nu[n]h[n]=0.6nu[n]（上），它的单位阶跃响应是逐点累加：s[n]=∑k=0nh[k]s[n]=\sum_{k=0}^{n}h[k]s[n]=∑k=0n​h[k]（下）。因为 u[n]=∑kδ[n−k]u[n]=\sum_k\delta[n-k]u[n]=∑k​δ[n−k]，所以阶跃响应就是脉冲响应的"累积求和"，并最终趋于稳态值 11−0.6=2.5\frac{1}{1-0.6}=2.51−0.61​=2.5。

先用一张表把五个概念对齐，再看后面的详细说明：

概念 符号 数学成分 由谁决定

零状态响应 yzs[n]y_{zs}[n]yzs​[n] 齐次解 + 特解 输入信号

关键在最后一行：这两种分解是同一件事的两种说法，不是四种独立的东西。下面逐个展开。

1. 零输入响应（Zero-Input Response, ZIR）

定义：系统在没有外部输入（x[n]=0x[n]=0x[n]=0）时，仅由初始状态产生的输出。

符号：yzi[n]y_{zi}[n]yzi​[n]

数学形式：齐次解，系数完全由初始条件决定。

物理意义：系统的"记忆"——过去输入留下的痕迹。

2. 零状态响应（Zero-State Response, ZSR）

定义：系统初始状态为零时，仅由输入信号产生的输出。

符号：yzs[n]y_{zs}[n]yzs​[n]

数学形式：齐次解 + 特解。其中齐次部分的系数由输入确定（前提是初始状态为零），特解形式与输入有关。

物理意义：系统对输入的"直接反应"。

计算方法：卷积和 yzs[n]=x[n]∗h[n]y_{zs}[n] = x[n] * h[n]yzs​[n]=x[n]∗h[n]，或令初始条件为零后用经典法求解。

为什么零状态响应里会有齐次解？ 这是本章最反直觉的一点，值得单独讲清。

齐次解的形式由系统特征根决定，只要方程是齐次的，它就会出现。零状态响应满足的是非齐次方程（右边有 x[n]x[n]x[n]），它的通解 = 齐次解 + 特解，所以必然带一个齐次项。

物理上：输入在 n=0n=0n=0 时刻"突然"加进来，相当于给系统一个冲击，把系统自身的固有振荡"激"起来了。这个振荡按特征根衰减，但它确实存在——它就是零状态响应里的齐次部分。

注意：这一部分的系数由"输入"决定（因为初始状态为零，没有别的来源）；而零输入响应的齐次系数由"初始条件"决定。两者形式相同、来源不同，这正是容易混淆的根源。

3. 自由响应（Natural Response）

定义：系统差分方程的齐次解，反映系统自身的固有特性。

符号：yh[n]y_h[n]yh​[n]

数学形式：由特征根决定的指数/振荡形式的组合，系数由初始条件和输入共同决定。

物理意义：系统"天生"的响应模式，在稳定系统中通常随时间衰减（瞬态）。

4. 强迫响应（Forced Response）

定义：系统差分方程的特解，由输入信号的形式强制产生。

符号：yp[n]y_p[n]yp​[n]

数学形式：与输入形式相同或类似（如输入为常数则特解为常数，输入为正弦则特解为同频正弦）。

物理意义：系统被输入"牵着走"的那部分响应，通常构成稳态部分。

5. 全响应（Total Response）

定义：系统实际的总输出。

符号：y[n]y[n]y[n]

y[n]=yzi[n]+yzs[n]=yh[n]+yp[n]y[n] = y_{zi}[n] + y_{zs}[n] = y_h[n] + y_p[n] y[n]=yzi​[n]+yzs​[n]=yh​[n]+yp​[n]

三、两对分解方式的对应关系

系统分析中有两种常见的分解视角，它们不是独立的四种响应，而是从不同角度对全响应的划分。

视角一：按原因分解（工程常用）

y[n]=yzi[n]⏟零输入响应+yzs[n]⏟零状态响应y[n] = \underbrace{y_{zi}[n]}_{\text{零输入响应}} + \underbrace{y_{zs}[n]}_{\text{零状态响应}} y[n]=零输入响应yzi​[n]​​+零状态响应yzs​[n]​​

  • 零输入响应：由初始条件引起，只含齐次解。
  • 零状态响应：由输入引起，含齐次解和特解。

视角二：按数学形式分解（经典法）

y[n]=yh[n]⏟自由响应+yp[n]⏟强迫响应y[n] = \underbrace{y_h[n]}_{\text{自由响应}} + \underbrace{y_p[n]}_{\text{强迫响应}} y[n]=自由响应yh​[n]​​+强迫响应yp​[n]​​

  • 自由响应：齐次解，形式由系统特征根决定。
  • 强迫响应：特解，形式由输入决定。

两对之间的交叉关系

两种视角不是简单并列，而是交叉的：零输入响应整个属于自由响应，而零状态响应被"劈"成两半。

graph LR
  ZI["零输入响应<br/>全是齐次解"] --> NH["自由响应<br/>齐次解"]
  ZSH["零状态响应里的<br/>齐次部分"] --> NH
  ZSP["零状态响应里的<br/>特解部分"] --> FP["强迫响应<br/>特解"]

关键结论：

  • 自由响应 = 零输入响应 + 零状态响应中的齐次解部分
  • 强迫响应 = 零状态响应中的特解部分
  • 因此：零输入响应只有自由响应成分；零状态响应同时含有两种成分；强迫响应只来自零状态响应。

换个角度记："零输入 / 零状态"是按"谁引起的"分，"自由 / 强迫"是按"长什么样子"分。 前者对应物理原因，后者对应数学形式。

上图（同一系统 y[n]−0.5y[n−1]=x[n]y[n]-0.5y[n-1]=x[n]y[n]−0.5y[n−1]=x[n]、x[n]=u[n]x[n]=u[n]x[n]=u[n]、y[−1]=1y[-1]=1y[−1]=1）：绿方块是零输入响应（只有初始状态，从 0.50.50.5 起衰减），橙三角是零状态响应（只有输入，从 000 起上升），蓝线是两者之和即全响应。两者都趋于 222，但零输入那半在衰减、零状态那半在上升——这就是"同一件事的两种说法"在时间上的直观差异。

四、h[n] 与 s[n]：两个"标准输入"对应的输出

工程上最常用的两个"标准输入"是单位脉冲 δ[n]\delta[n]δ[n] 和单位阶跃 u[n]u[n]u[n]，它们对应的输出分别是单位脉冲响应 h[n]h[n]h[n] 与单位阶跃响应 s[n]s[n]s[n]。

1. 两者的关系（必背）

因为 u[n]=∑k=−∞nδ[n−k]u[n]=\sum_{k=-\infty}^{n}\delta[n-k]u[n]=∑k=−∞n​δ[n−k]，由 LSI 的线性叠加：

s[n]=∑k=−∞nh[k]=h[n]∗u[n]\boxed{s[n]=\sum_{k=-\infty}^{n}h[k]=h[n]*u[n]} s[n]=k=−∞∑n​h[k]=h[n]∗u[n]​

反过来（差分）：

h[n]=s[n]−s[n−1]\boxed{h[n]=s[n]-s[n-1]} h[n]=s[n]−s[n−1]​

这两个式子为什么好用：只要知道 hhh 或 sss 之一，另一个立刻就出来。
注意 n=0n=0n=0 的处理：s[n]−s[n−1]s[n]-s[n-1]s[n]−s[n−1] 在 n=0n=0n=0 处用到 s[−1]=0s[-1]=0s[−1]=0（系统在输入加进来之前没有输出），所以 h[0]=s[0]h[0]=s[0]h[0]=s[0]。

五、补充：瞬态响应与稳态响应

这两个概念是从时间持久性角度划分的，与上述分类正交。

名称 含义 通常来源
瞬态响应 随时间增长而衰减消失的部分 稳定系统的自由响应（齐次解）
稳态响应 持续存在的部分 强迫响应（特解）或非衰减的自由响应

注意：零输入响应在稳定系统中是瞬态的，但在不稳定系统中可能不衰减；零状态响应中既有瞬态（齐次部分）也有稳态（特解部分）。

稳定系统 + 持续输入时的完整对应：

y[n]=yh[n]⏟瞬态，衰减到 0+yp[n]⏟稳态，长期保留y[n]=\underbrace{y_h[n]}_{\text{瞬态，衰减到 }0}+\underbrace{y_p[n]}_{\text{稳态，长期保留}} y[n]=瞬态，衰减到 0yh​[n]​​+稳态，长期保留yp​[n]​​

这是考试里最常用的一句话结论。前提是"系统稳定"且"输入持续存在"，两者缺一，这个对应就不成立（不稳定系统自由响应不衰减；输入撤掉后稳态也消失）。

例题 3：二阶系统的零输入响应

题目：系统 y[n]−1.5 y[n−1]+0.5 y[n−2]=x[n]y[n]-1.5\,y[n-1]+0.5\,y[n-2]=x[n]y[n]−1.5y[n−1]+0.5y[n−2]=x[n]，初始条件 y[−1]=1y[-1]=1y[−1]=1、y[−2]=0y[-2]=0y[−2]=0，x[n]=0x[n]=0x[n]=0。求 yzi[n]y_{zi}[n]yzi​[n]。

解：

（1）写特征方程（令 y=λny=\lambda^ny=λn 代入齐次方程）：

λ2−1.5λ+0.5=0  ⟹  (λ−1)(λ−0.5)=0\lambda^{2}-1.5\lambda+0.5=0 \;\Longrightarrow\; (\lambda-1)(\lambda-0.5)=0 λ2−1.5λ+0.5=0⟹(λ−1)(λ−0.5)=0

特征根 λ1=1\lambda_1=1λ1​=1、λ2=0.5\lambda_2=0.5λ2​=0.5，互异，故

yzi[n]=A⋅1n+B⋅(0.5)n=A+B(0.5)ny_{zi}[n]=A\cdot1^{n}+B\cdot(0.5)^{n}=A+B(0.5)^{n} yzi​[n]=A⋅1n+B⋅(0.5)n=A+B(0.5)n

（2）代入两个初始条件（注意 nnn 可取负值）：

  • n=−1n=-1n=−1：A+B(0.5)−1=A+2B=1A+B(0.5)^{-1}=A+2B=1A+B(0.5)−1=A+2B=1
  • n=−2n=-2n=−2：A+B(0.5)−2=A+4B=0A+B(0.5)^{-2}=A+4B=0A+B(0.5)−2=A+4B=0

（3）解方程组：两式相减得 2B=−12B=-12B=−1，即 B=−0.5B=-0.5B=−0.5；回代得 A=2A=2A=2。

yzi[n]=2−0.5(0.5)n=2−(0.5)n+1,n≥0\boxed{y_{zi}[n]=2-0.5(0.5)^{n}=2-(0.5)^{n+1},\quad n\ge 0} yzi​[n]=2−0.5(0.5)n=2−(0.5)n+1,n≥0​

（4）检验（代回原方程核对 n=0,1n=0,1n=0,1）：

  • n=0n=0n=0：y[0]−1.5y[−1]+0.5y[−2]=(2−0.5)−1.5(1)+0=0y[0]-1.5y[-1]+0.5y[-2]=(2-0.5)-1.5(1)+0=0y[0]−1.5y[−1]+0.5y[−2]=(2−0.5)−1.5(1)+0=0 ✓
  • n=1n=1n=1：y[1]−1.5y[0]+0.5y[−1]=(2−0.25)−1.5(1.5)+0.5=1.75−2.25+0.5=0y[1]-1.5y[0]+0.5y[-1]=(2-0.25)-1.5(1.5)+0.5=1.75-2.25+0.5=0y[1]−1.5y[0]+0.5y[−1]=(2−0.25)−1.5(1.5)+0.5=1.75−2.25+0.5=0 ✓

例题 4：判断题（四步判据 + 反例）

题目：判断下列说法是否正确，说明理由。

  1. 零状态响应就是强迫响应。
  2. 零输入响应是自由响应的一部分。
  3. 自由响应只由初始条件决定。
  4. 稳定系统在持续输入下，瞬态响应就是自由响应、稳态响应就是强迫响应。

解：

（1）说法 1 —— 错。

判据：零状态响应的通解 = 齐次解 + 特解；强迫响应只等于特解。

反例（用例题 1 的结果）：yzs[n]=2−2(0.5)n+1y_{zs}[n]=2-2(0.5)^{n+1}yzs​[n]=2−2(0.5)n+1，其中 222 是特解，而 −2(0.5)n+1-2(0.5)^{n+1}−2(0.5)n+1 是齐次解。所以零状态响应含齐次成分，不能等同于强迫响应。

（2）说法 2 —— 对。

判据：自由响应定义为"全部齐次解"，而零输入响应在 x[n]=0x[n]=0x[n]=0 时只能是齐次解（无输入就没有特解）。所以零输入响应必然落在自由响应之中。

验证：例题 1 中 yzi=(0.5)n+1y_{zi}=(0.5)^{n+1}yzi​=(0.5)n+1，而 −0.5(0.5)n-0.5(0.5)^n−0.5(0.5)n 才是全部齐次解；(0.5)n+1=0.5⋅(0.5)n(0.5)^{n+1}=0.5\cdot(0.5)^n(0.5)n+1=0.5⋅(0.5)n 确实是其中一部分（系数的一部分）✓

（3）说法 3 —— 错。

判据：自由响应 = 零输入响应 + 零状态响应中的齐次部分，后者的系数由输入决定。

反例：同一系统 y[n]−0.5y[n−1]=x[n]y[n]-0.5y[n-1]=x[n]y[n]−0.5y[n−1]=x[n]：

  • 若 y[−1]=1y[-1]=1y[−1]=1、x=u[n]x=u[n]x=u[n]：自由响应 =−0.5(0.5)n=-0.5(0.5)^n=−0.5(0.5)n
  • 若 y[−1]=0y[-1]=0y[−1]=0、x=u[n]x=u[n]x=u[n]：零输入为零，自由响应只剩零状态部分 =−2(0.5)n+1=-2(0.5)^{n+1}=−2(0.5)n+1

两种情形下自由响应不同，且都受输入影响，所以"只由初始条件决定"不成立。

（4）说法 4 —— 对（但前提必须写上）。

判据：稳定系统特征根的模全小于 111，故齐次解（=自由响应）必衰减到 000，是瞬态；特解由输入形式决定、持续存在，是稳态。

验证：例题 1 中 yh=−0.5(0.5)n→0y_h=-0.5(0.5)^n\to0yh​=−0.5(0.5)n→0（瞬态），yp=2y_p=2yp​=2（稳态）✓；两者之和 =y[n]=y[n]=y[n] ✓

答题要点：判"对"要把前提条件讲出来（"稳定"和"持续输入"缺一不可）。只说"对"不解释，等于没答。

七、常见错误提醒

  1. 把四种响应当成四种独立的东西：全响应既等于"零输入 + 零状态"，也等于"自由 + 强迫"，两组分解只是视角不同。
  2. 认为"零状态响应 = 强迫响应"：这是最常错的一条。零状态响应里也含齐次解（由输入激励出来的那部分），只有特解才等于强迫响应。
  3. 认为"零输入响应 = 自由响应"：零输入响应只是自由响应的一部分（它是纯自由响应，但自由响应还包含零状态里的齐次部分）。
  4. 求零输入响应时带入了输入：零输入响应必须令 x[n]=0x[n]=0x[n]=0，只用初始条件解齐次方程。
  5. 求零状态响应时用了非零初始条件：零状态要求初始状态全为零，两套分解不能用同一组初始条件混着算。
  6. 代初始条件时用了 n=0,1n=0,1n=0,1：初始条件给的是 n=−1,−2,…n=-1,-2,\dotsn=−1,−2,…（输入加入之前），必须用负下标代入定系数。
  7. 把瞬态 / 稳态与自由 / 强迫直接划等号：稳态通常来自强迫响应，但系统不稳定时自由响应也不衰减，那时它也是稳态的一部分。
  8. hhh 与 sss 互推时漏掉 n=0n=0n=0：h[0]=s[0]h[0]=s[0]h[0]=s[0]（因为 s[−1]=0s[-1]=0s[−1]=0），不能机械套 s[n]−s[n−1]s[n]-s[n-1]s[n]−s[n−1] 而不处理边界。
