【数字信号处理DSP】（九）离散时间系统的时域解法

离散时间系统的时域解法

标签： #数字信号处理 #DSP #差分方程 #齐次解 #特解 #零输入响应 #零状态响应 #迭代法

一、概述

离散时间系统通常用线性常系数差分方程描述：

∑k=0Nak y[n−k]=∑r=0Mbr x[n−r]\sum_{k=0}^{N} a_k \, y[n-k] = \sum_{r=0}^{M} b_r \, x[n-r] k=0∑N​ak​y[n−k]=r=0∑M​br​x[n−r]

其中 a0=1a_0 = 1a0​=1（归一化），NNN 为系统阶数。

时域解法就是直接求解差分方程，得到输出序列 y[n]y[n]y[n]。主要有三种方法：

  • 经典法：齐次解 + 特解
  • 零输入/零状态分解法
  • 迭代法（递推法）

三种方法算出的全响应是同一个，只是观察角度不同：

graph TD
  T["差分方程求全响应 y[n]"] --> A["经典法：yh[n] + yp[n]"]
  T --> B["分解法：yzi[n] + yzs[n]"]

  B3["yzs：零状态响应 = x[n]*h[n]"] --- A3["yp：强迫响应"]

两个分法的区别（这是本章最容易绕晕的点，一句话记住）：

  • 齐次解/特解 是按数学形式分：齐次解满足方程的"左边为 0"，特解负责"凑出输入"。
  • 零输入/零状态 是按物理来源分：一个来自初始储能，一个来自外部输入。

两种分法的四个分量之间有交叉关系，对照表见 （八）离散时间系统的各种响应概念详解。

二、经典法（齐次解 + 特解）

1. 齐次解（自由响应）

令输入 x[n]=0x[n] = 0x[n]=0，求解齐次方程：

∑k=0Nak yh[n−k]=0\sum_{k=0}^{N} a_k \, y_h[n-k] = 0 k=0∑N​ak​yh​[n−k]=0

设 yh[n]=λny_h[n] = \lambda^nyh​[n]=λn，代入得特征方程：

∑k=0Nak λ−k=0⇒λN+a1λN−1+⋯+aN=0\sum_{k=0}^{N} a_k \, \lambda^{-k} = 0 \quad \Rightarrow \quad \lambda^N + a_1 \lambda^{N-1} + \cdots + a_N = 0 k=0∑N​ak​λ−k=0⇒λN+a1​λN−1+⋯+aN​=0

  • 单根 λi\lambda_iλi​：对应项 CiλinC_i \lambda_i^nCi​λin​

三、零输入响应与零状态响应

将全响应分解为两部分：

y[n]=yzi[n]+yzs[n]y[n] = y_{zi}[n] + y_{zs}[n] y[n]=yzi​[n]+yzs​[n]

1. 零输入响应（ZIR）

系统无外部输入（x[n]=0x[n]=0x[n]=0），仅由初始储能引起的响应。

  • 求解方法与齐次解相同
  • 初始条件由系统在 n<0n<0n<0 时的状态决定（如 y[−1],y[−2],…y[-1], y[-2], \dotsy[−1],y[−2],…）

2. 零状态响应（ZSR）

系统初始状态为零（松弛状态），仅由输入 x[n]x[n]x[n] 引起的响应。

  • 计算方法：卷积和 yzs[n]=x[n]∗h[n]y_{zs}[n] = x[n] * h[n]yzs​[n]=x[n]∗h[n]
  • 或采用经典法，令齐次解中的系数由零初始条件确定

3. 全响应 = 零输入 + 零状态

上图：以 y[n]−0.5y[n−1]=u[n]y[n]-0.5y[n-1]=u[n]y[n]−0.5y[n−1]=u[n]、y[−1]=1y[-1]=1y[−1]=1 为例，绿为零输入响应、橙为零状态响应、蓝为二者相加得到的全响应。

y[n]=yzi[n]+x[n]∗h[n]y[n] = y_{zi}[n] + x[n] * h[n] y[n]=yzi​[n]+x[n]∗h[n]

四、迭代法（递推法）

将差分方程改写为递推形式：

y[n]=−∑k=1Nak y[n−k]+∑r=0Mbr x[n−r]y[n] = -\sum_{k=1}^{N} a_k \, y[n-k] + \sum_{r=0}^{M} b_r \, x[n-r] y[n]=−k=1∑N​ak​y[n−k]+r=0∑M​br​x[n−r]

从 n=0n=0n=0 开始，依次利用已知的初始条件和输入计算后续输出值。

优点：简单直观，适合计算机实现
缺点：只能得到数值解，难以得到闭式表达式

五、由差分方程求单位脉冲响应 h[n]h[n]h[n]

单位脉冲响应 h[n]h[n]h[n] 是系统在零状态下对 δ[n]\delta[n]δ[n] 的响应。

方法一：迭代法

令 x[n]=δ[n]x[n] = \delta[n]x[n]=δ[n]，初始条件为零，递推计算 h[n]h[n]h[n]。

方法二：经典法

  1. 求齐次解（形式与零输入相同）
  2. 利用 δ[n]\delta[n]δ[n] 仅在 n=0n=0n=0 处非零的特点，确定初始条件
  3. 对于 n≥0n \geq 0n≥0，h[n]h[n]h[n] 满足齐次方程（因为 n>0n>0n>0 时 δ[n]=0\delta[n]=0δ[n]=0）

常用结论：

  • 一阶系统：y[n]−ay[n−1]=bx[n]y[n] - a y[n-1] = b x[n]y[n]−ay[n−1]=bx[n] ⇒ h[n]=banu[n]h[n] = b a^n u[n]h[n]=banu[n]
  • 二阶系统：y[n]−a1y[n−1]−a2y[n−2]=b0x[n]y[n] - a_1 y[n-1] - a_2 y[n-2] = b_0 x[n]y[n]−a1​y[n−1]−a2​y[n−2]=b0​x[n] ⇒ h[n]h[n]h[n] 形式取决于特征根

  • n=0n=0n=0：A+2=1⇒A=−1A + 2 = 1 \Rightarrow A = -1A+2=1⇒A=−1
  • n=1n=1n=1：12(−1⋅22+B⋅22)+2=2⇒B=1\frac{1}{\sqrt{2}}\left(-1\cdot\frac{\sqrt{2}}{2} + B\cdot\frac{\sqrt{2}}{2}\right) + 2 = 2 \Rightarrow B = 12​1​(−1⋅22​​+B⋅22​​)+2=2⇒B=1

于是

y[n]=2+2(12)nsin⁡ ⁣(πn4−π4),n≥0y[n] = 2 + \sqrt{2}\left(\frac{1}{\sqrt{2}}\right)^{n} \sin\!\left(\frac{\pi n}{4} - \frac{\pi}{4}\right), \quad n \geq 0 y[n]=2+2​(2​1​)nsin(4πn​−4π​),n≥0

验算：y[2]=2+2⋅12⋅sin⁡π4=2.5y[2] = 2 + \sqrt{2}\cdot\frac{1}{2}\cdot\sin\frac{\pi}{4} = 2.5y[2]=2+2​⋅21​⋅sin4π​=2.5，与递推 y[2]=y[1]−0.5y[0]+1=2.5y[2] = y[1] - 0.5y[0] + 1 = 2.5y[2]=y[1]−0.5y[0]+1=2.5 一致。

→ 输出是振幅按 rnr^nrn 指数衰减的振荡，最终稳定到 222。r<1r \lt 1r<1 说明系统稳定。

两个参数各管一件事：

  • 模长 rrr 决定"振不振得下去"：r<1r \lt 1r<1 衰减、r=1r = 1r=1 等幅、r>1r \gt 1r>1 发散；

七、三种方法的对比

方法 优点 缺点 适用场景
经典法 得到闭式表达式 需确定初始条件，高阶计算繁琐 低阶系统、理论分析
零输入/零状态分解 物理概念清晰，便于理解系统行为 需分别计算两部分 系统分析、教学
迭代法 简单直接，适合编程 只能得到数值解，无法看出规律 计算机仿真、实时计算

八、常见错误提醒

  1. 特解形式选择错误：当输入与齐次解形式相同时，需乘以 nnn（或 nrn^rnr）
  2. 初始条件使用不当：经典法需要的是 n=0,1,…,N−1n=0,1,\dots,N-1n=0,1,…,N−1 的初始值，而不是 n=−1,−2,…n=-1,-2,\dotsn=−1,−2,… 的初始条件，需通过递推转换
  3. 零状态响应忽略了系统初始松弛：零状态必须假设所有初始条件为零
  4. 卷积和与差分方程混淆：卷积和只适用于零状态响应，不能直接用于非零初始条件
