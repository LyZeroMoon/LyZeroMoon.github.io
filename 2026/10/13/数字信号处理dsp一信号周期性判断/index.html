【数字信号处理DSP】（一）信号周期性判断

信号周期性判断

标签： #数字信号处理 #DSP #周期性 #正弦序列 #复指数序列

一、为什么"离散正弦"不一定是周期的？

连续时间的正弦信号 sin⁡(Ωt)\sin(\Omega t)sin(Ωt) 对任意 Ω≠0\Omega \ne 0Ω=0 都是周期的，周期 T=2π/ΩT = 2\pi/\OmegaT=2π/Ω。

离散时间序列没这么幸运。序列只在整数点 nnn 上有定义，要求存在正整数 NNN 使

x[n+N]=x[n]对所有整数 n 成立x[n+N] = x[n] \qquad \text{对所有整数 } n \text{ 成立} x[n+N]=x[n]对所有整数 n 成立

对 x[n]=Asin⁡(ω0n+φ)x[n] = A\sin(\omega_0 n + \varphi)x[n]=Asin(ω0​n+φ) 代入：

Asin⁡(ω0(n+N)+φ)=Asin⁡(ω0n+φ)A\sin\big(\omega_0 (n+N) + \varphi\big) = A\sin(\omega_0 n + \varphi) Asin(ω0​(n+N)+φ)=Asin(ω0​n+φ)

正弦以 2π2\pi2π 为周期，两式相等要求相位差是 2π2\pi2π 的整数倍：

ω0N=2πm(m 为整数)(1)\omega_0 N = 2\pi m \quad (m \text{ 为整数}) \tag{1} ω0​N=2πm(m 为整数)(1)

式 (1) 就是全部秘密所在。把它改写成比值形式：

ω02π=mN\boxed{\frac{\omega_0}{2\pi} = \frac{m}{N}} 2πω0​​=Nm​​

左边由信号给定，右边是两个整数之比。所以：

ω0/(2π)\omega_0/(2\pi)ω0​/(2π) 必须是有理数，序列才可能周期。

连续域里"想多慢就多慢"的自由，在离散域被"只能用整数点采样"这个约束砍掉了一大半——绝大多数数字频率对应的离散正弦都根本不周期。

二、判据与算法

上图：蓝色是 sin⁡(πn/4)\sin(\pi n/4)sin(πn/4) 的采样点，落在连续正弦上且每隔 8 点完全重复（绿色箭头标出一个周期 N=8N=8N=8）；红色是 sin⁡(2 n)\sin(\sqrt{2}\,n)sin(2​n) 的采样点，落在连续正弦上但永不重复。采样点是否重复，正是离散正弦是否周期的判据。

1. 核心判据

ω02π=mN (最简分数，m,N 互质)⟹基本周期=N\frac{\omega_0}{2\pi} = \frac{m}{N}\ (\text{最简分数，} m,N \text{ 互质}) \quad\Longrightarrow\quad \text{基本周期} = N 2πω0​​=Nm​ (最简分数，m,N 互质)⟹基本周期=N

"基本周期"指满足条件的最小正整数。

2. 两种等价的算法

做法 步骤 结论取自
比值法（推荐） 算 ω0/2π\omega_0/2\piω0​/2π，化成最简分数 mN\dfrac{m}{N}Nm​ 分母 NNN
倒数法 算 2π/ω02\pi/\omega_02π/ω0​，化成最简分数 Nm\dfrac{N}{m}mN​ 分子 NNN

⚠️ 坑在这里：ω0/2π\omega_0/2\piω0​/2π 为无理数 ⇒ 非周期（无论怎么约分都得不到整数 NNN）；而 2π/ω02\pi/\omega_02π/ω0​ 不是整数时，不能四舍五入当周期。例如 2π/ω0=8/32\pi/\omega_0 = 8/32π/ω0​=8/3，基本周期是 888，既不是 333、也不是 8/38/38/3。

3. 判断流程

4. 为什么"最简分数"这一步不能省

若 ω02π=mN\dfrac{\omega_0}{2\pi} = \dfrac{m}{N}2πω0​​=Nm​ 但 m,Nm,Nm,N 有公因子 ddd，则 mN=m/dN/d\dfrac{m}{N} = \dfrac{m/d}{N/d}Nm​=N/dm/d​，真正的最小周期是 N/dN/dN/d 而不是 NNN。

例如 ω02π=612\dfrac{\omega_0}{2\pi} = \dfrac{6}{12}2πω0​​=126​，若不约分会答成 N=12N=12N=12；约分后 12\dfrac{1}{2}21​，正确答案是 N=2N=2N=2。先约分，再取分母。

3. 多个正弦叠加

判据：

  1. 分别求各分量基本周期 N1,N2,…,NkN_1, N_2, \dots, N_kN1​,N2​,…,Nk​；

2. 两个直接推论

  1. 讨论数字频率只需限定在长度为 2π2\pi2π 的区间内，习惯取 −π<ω≤π-\pi \lt \omega \leq \pi−π<ω≤π 或 0≤ω<2π0 \leq \omega \lt 2\pi0≤ω<2π。
  2. 数字频率 ω\omegaω 是模拟频率对采样率归一化的结果（详见 （十）模拟频率与数字频率的关系），这个"卷起来"的周期性正来自采样。

3. 一条重要直觉：ω\omegaω 越大不代表振荡越快

由于上述等价性，ω\omegaω 与 2π−ω2\pi - \omega2π−ω 是同一个序列：

ej(2π−ω0)n=e−jω0ne^{j(2\pi-\omega_0)n} = e^{-j\omega_0 n} ej(2π−ω0​)n=e−jω0​n

右端是原序列的共轭（实部相同、虚部反号）。对实正弦而言 cos⁡((2π−ω0)n)=cos⁡(ω0n)\cos\big((2\pi-\omega_0)n\big) = \cos(\omega_0 n)cos((2π−ω0​)n)=cos(ω0​n)，两者完全相同。

于是：

  • ω\omegaω 从 000 增到 π\piπ，振荡越来越快；
  • ω\omegaω 从 π\piπ 增到 2π2\pi2π，振荡反而越来越慢，在 2π2\pi2π 处退化为常数。

ω=π\omega = \piω=π 是离散序列能表示的"最快振荡"（每两点翻转一次，形如 1,−1,1,−1,…1,-1,1,-1,\dots1,−1,1,−1,…）。这条直觉是后面理解"最高频率只到 π\piπ""混叠""采样定理"的地基。

上图：上栏把 cos⁡(πn/4)\cos(\pi n/4)cos(πn/4)（蓝点）与 cos⁡(7πn/4)\cos(7\pi n/4)cos(7πn/4)（红圈）画在一起，红圈处处套在蓝点上——ω=7π/4\omega=7\pi/4ω=7π/4 与 ω=π/4\omega=\pi/4ω=π/4 是同一个序列。下栏把 ω\omegaω 从 000 扫到 2π2\pi2π，纵轴是"有效振荡速率"：0→π0\to\pi0→π 段越来越快，π\piπ 处达到最快，之后折返下降，到 2π2\pi2π 退回直流。所以"频率越大振荡越快"只在半个周期内成立。

4. "周期"与"频率是有理数倍"的等价

ω0/(2π)\omega_0/(2\pi)ω0​/(2π) 序列性质 数字频率的等价类
有理数 m/Nm/Nm/N 周期，基本周期 NNN 落在 2π2\pi2π 区间内的某个确定值上
无理数 非周期 在 (−π,π](-\pi,\pi](−π,π] 内稠密地"游走"，永不回到原点

所以"序列是否周期"本质上问的是：这个数字频率能不能写成 2π2\pi2π 的有理数倍。

六、常见错误提醒

  1. 把 2π/ω02\pi/\omega_02π/ω0​ 直接当周期：只有它恰好是整数时才成立。一般应把 ω0/2π\omega_0/2\piω0​/2π 化成最简分数 m/Nm/Nm/N，分母才是基本周期。
  2. 由"约分不干净"就判非周期：sin⁡(3πn/4)\sin(3\pi n/4)sin(3πn/4) 的 2π/ω0=8/32\pi/\omega_0 = 8/32π/ω0​=8/3 不是整数，但它周期（N=8N=8N=8）。
  3. 忘记先约分：ω0/2π=6/12\omega_0/2\pi = 6/12ω0​/2π=6/12 时答案是 N=2N=2N=2，不是 121212。
  4. 相加序列漏判某分量：只要有一个分量非周期，整体非周期，不必再算 LCM。
  5. 误以为"实指数序列都不周期"：a=1a=1a=1、a=−1a=-1a=−1 都是周期的。
  6. 忘了 ω0\omega_0ω0​ 与 ω0+2πk\omega_0+2\pi kω0​+2πk 等价：sin⁡(1.5πn)\sin(1.5\pi n)sin(1.5πn) 与 sin⁡(−0.5πn)\sin(-0.5\pi n)sin(−0.5πn) 是同一序列，判周期前可先化简到 (−π,π](-\pi,\pi](−π,π]，结论不变。
  7. 把连续域直觉搬过来：连续正弦"任意频率都周期"，离散正弦"多数频率都不周期"，这是最容易失分的地方。
  8. 答周期却不给最小正周期：题目问"周期"时若有多个周期，考试要求写出基本（最小正）周期。

八、总结

  • 一个判据管所有：ω0/(2π)\omega_0/(2\pi)ω0​/(2π) 有理则周期，无理则非周期。
  • 基本周期：把它化成最简分数 m/Nm/Nm/N，NNN 就是基本周期（先约分再取分母）。
  • 相加序列：全周期才周期且取 LCM；有一个非周期，整体非周期。
  • 实指数序列：∣a∣≠1\lvert a\rvert\ne 1∣a∣=1 时非周期；a=1a=1a=1 周期 111，a=−1a=-1a=−1 周期 222。
  • 离散域独有：数字频率以 2π2\pi2π 为周期，ω\omegaω 与 ω+2πk\omega+2\pi kω+2πk 是同一序列，故 ω=π\omega=\piω=π 是最快振荡。

一句话总结：正弦 / 复指数序列是否周期，只看 ω0/(2π)\omega_0/(2\pi)ω0​/(2π) 是不是有理数——有理则周期（最简分数的分母即基本周期），无理则非周期；这个"有理数门槛"正是离散时间与连续时间最大的差别之一。
