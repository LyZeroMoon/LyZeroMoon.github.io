【数字信号处理DSP】（一）信号周期性判断

信号周期性判断

标签： #数字信号处理 #DSP #周期性 #正弦序列 #复指数序列

一、为什么"离散正弦"不一定是周期的？

连续时间的正弦信号 sin⁡(Ωt)\sin(\Omega t)sin(Ωt) 对任意 Ω\OmegaΩ 都是周期的，周期 T=2π/ΩT = 2\pi/\OmegaT=2π/Ω。

离散时间序列没这么幸运。序列只在整数点 nnn 上有定义，要求

x[n+N]=x[n]对所有整数 n 成立x[n+N] = x[n] \quad \text{对所有整数 } n \text{ 成立} x[n+N]=x[n]对所有整数 n 成立

对 x[n]=Asin⁡(ω0n+φ)x[n] = A\sin(\omega_0 n + \varphi)x[n]=Asin(ω0​n+φ) 来说，这意味着必须存在正整数 NNN 使

ω0N=2πm(m 为整数)\omega_0 N = 2\pi m \quad (m \text{ 为整数}) ω0​N=2πm(m 为整数)

也就是说，ω0\omega_0ω0​ 必须是 2π2\pi2π 的有理数倍。连续域里"想多慢就多慢"的自由，在离散域被"只能用整数点"这个约束砍掉了一大半。

二、判断公式

上图：蓝色是 sin⁡(πn/4)\sin(\pi n/4)sin(πn/4) 的采样点（落在连续正弦上且每隔 8 点重复），橙色是 sin⁡(2 n)\sin(\sqrt{2}\,n)sin(2​n) 的采样点（永不重复）。采样点是否重复，正是离散正弦是否周期的判据。

1. 核心判据

ω02π=mN(最简分数)  ⟹  基本周期=N\frac{\omega_0}{2\pi} = \frac{m}{N} \quad (\text{最简分数}) \;\Longrightarrow\; \text{基本周期} = N 2πω0​​=Nm​(最简分数)⟹基本周期=N

其中"基本周期"是满足条件的最小正整数。

2. 两种等价的算法

做法 步骤 结果
比值法（推荐） 算出 ω0/2π\omega_0/2\piω0​/2π，化成最简分数 m/Nm/Nm/N 分母 NNN 就是基本周期
倒数法 算出 2π/ω02\pi/\omega_02π/ω0​，化成最简分数 N/mN/mN/m 分子 NNN 才是基本周期

⚠️ 常见坑：ω0/2π\omega_0/2\piω0​/2π 为无理数时非周期，此时无论怎么约分都得不到整数 NNN；而 2π/ω02\pi/\omega_02π/ω0​ 不是整数时，也不能直接四舍五入当成周期（比如 2π/ω0=8/32\pi/\omega_0 = 8/32π/ω0​=8/3，基本周期是 8 而不是 3，也不是 8/38/38/3）。

3. 判断流程

graph LR
  A["算出比值 ω₀ 除以 2π"] --> B{"是有理数吗"}
  B -->|是| C["化成最简分数 m 除以 N"]
  B -->|否| D["非周期序列"]
  C --> E["基本周期就是分母 N"]

三、不同类型序列的周期判断

1. 正弦序列 x[n] = A·sin(ω₀n + φ)

判断方法与相位 φ\varphiφ 无关（φ\varphiφ 只影响起始位置，不影响周期）。

示例1：x[n]=sin⁡(πn/4)x[n] = \sin(\pi n/4)x[n]=sin(πn/4)

ω02π=π/42π=18  ⇒  N=8\frac{\omega_0}{2\pi} = \frac{\pi/4}{2\pi} = \frac{1}{8} \; \Rightarrow \; N = 8 2πω0​​=2ππ/4​=81​⇒N=8

示例2：x[n]=sin⁡(3πn/4)x[n] = \sin(3\pi n/4)x[n]=sin(3πn/4)

ω02π=3π/42π=38  ⇒  N=8\frac{\omega_0}{2\pi} = \frac{3\pi/4}{2\pi} = \frac{3}{8} \; \Rightarrow \; N = 8 2πω0​​=2π3π/4​=83​⇒N=8

注意这里 2π/ω0=8/32\pi/\omega_0 = 8/32π/ω0​=8/3 不是整数，但基本周期确实是 8 —— 这正是要用"比值法"的原因。

示例3：x[n]=sin⁡(3n)x[n] = \sin(3n)x[n]=sin(3n)

ω02π=32π≈0.477（无理数）  ⇒  非周期序列\frac{\omega_0}{2\pi} = \frac{3}{2\pi} \approx 0.477 \quad \text{（无理数）} \;\Rightarrow\; \textbf{非周期序列} 2πω0​​=2π3​≈0.477（无理数）⇒非周期序列

2. 复指数序列 x[n] = e^(jω₀n)

判据与正弦序列完全相同：只看 ω0/2π\omega_0/2\piω0​/2π 是否为有理数。

示例4：x[n]=ejπn/3x[n] = e^{j\pi n/3}x[n]=ejπn/3

ω02π=16  ⇒  N=6\frac{\omega_0}{2\pi} = \frac{1}{6} \;\Rightarrow\; N = 6 2πω0​​=61​⇒N=6

示例5：x[n]=ejnx[n] = e^{jn}x[n]=ejn

ω02π=12π（无理数）  ⇒  非周期序列\frac{\omega_0}{2\pi} = \frac{1}{2\pi} \quad \text{（无理数）} \;\Rightarrow\; \textbf{非周期序列} 2πω0​​=2π1​（无理数）⇒非周期序列

3. 多个正弦相加的序列

判断方法：

  1. 分别求出每个分量的基本周期 N1,N2,…N_1, N_2, \dotsN1​,N2​,…
  2. 若每个分量都周期，整体周期为各周期的最小公倍数（LCM）
  3. 若有任何一个是非周期，整体非周期

示例6：x[n]=sin⁡(πn/3)+cos⁡(πn/4)x[n] = \sin(\pi n/3) + \cos(\pi n/4)x[n]=sin(πn/3)+cos(πn/4)

  • 第一项：ω1/2π=1/6⇒N1=6\omega_1/2\pi = 1/6 \Rightarrow N_1 = 6ω1​/2π=1/6⇒N1​=6
  • 第二项：ω2/2π=1/8⇒N2=8\omega_2/2\pi = 1/8 \Rightarrow N_2 = 8ω2​/2π=1/8⇒N2​=8
  • LCM(6,8)=24  ⇒  N=24\mathrm{LCM}(6, 8) = 24 \;\Rightarrow\; N = 24LCM(6,8)=24⇒N=24

示例7：x[n]=sin⁡(πn/3)+sin⁡(n)x[n] = \sin(\pi n/3) + \sin(n)x[n]=sin(πn/3)+sin(n)

  • 第一项：N1=6N_1 = 6N1​=6
  • 第二项：非周期
  • 整体非周期（一个非周期分量就足以拖垮整个序列）

4. 实指数序列 x[n] = aⁿ

结论：实指数序列永远不是周期的。

  • a=1a = 1a=1 时 x[n]≡1x[n] \equiv 1x[n]≡1，任意 NNN 都是周期（可视为周期为 1 的平凡情况）
  • a=0a = 0a=0 时序列只在 n≥0n \geq 0n≥0 起点非零，同样不构成周期
  • 其余情况：∣a∣≠1\lvert a \rvert \neq 1∣a∣=1 时模值单调变化，∣a∣=1\lvert a \rvert = 1∣a∣=1 时退化为常数或 ±\pm± 交替

四、数字频率的周期性

这是离散序列独有的性质，也是后面理解频域分析的起点：

ej(ω0+2πk)n=ejω0n⋅ej2πkn=ejω0ne^{j(\omega_0 + 2\pi k)n} = e^{j\omega_0 n} \cdot e^{j2\pi kn} = e^{j\omega_0 n} ej(ω0​+2πk)n=ejω0​n⋅ej2πkn=ejω0​n

因为 ej2πkn=1e^{j2\pi kn} = 1ej2πkn=1（nnn、kkk 皆为整数）。所以

数字频率 ω0\omega_0ω0​ 与 ω0+2πk\omega_0 + 2\pi kω0​+2πk 描述的是同一个序列（kkk 为任意整数）。

随之而来的两个结论：

  1. 讨论数字频率时只需限定在 2π2\pi2π 的区间内，习惯取 −π<ω≤π-\pi \lt \omega \leq \pi−π<ω≤π 或 0≤ω<2π0 \leq \omega \lt 2\pi0≤ω<2π
  2. 与（（十）模拟频率与数字频率的关系）连起来看：数字频率 ω\omegaω 是模拟频率对采样率归一化的结果，这个"卷起来"的周期性正来自采样

关于"周期"和"频率为有理数"的关系

  • ω0/2π\omega_0/2\piω0​/2π 是有理数 ⇒\Rightarrow⇒ 序列周期，且数字频率落在 2π2\pi2π 内的同一个值上
  • ω0/2π\omega_0/2\piω0​/2π 是无理数 ⇒\Rightarrow⇒ 序列非周期

所以"序列是否周期"本质上问的是：这个数字频率能不能写成 2π2\pi2π 的有理数倍。

六、常见错误提醒

  1. 把 2π/ω02\pi/\omega_02π/ω0​ 直接当周期：它只在"恰好是整数"时成立；一般要把 ω0/2π\omega_0/2\piω0​/2π 写成最简分数 m/Nm/Nm/N，分母才是基本周期。
  2. 由"约分不干净"就判非周期：sin⁡(3πn/4)\sin(3\pi n/4)sin(3πn/4) 的 2π/ω0=8/32\pi/\omega_0 = 8/32π/ω0​=8/3，但它依然是周期的（N=8N = 8N=8）。
  3. 相加序列里漏判某一个分量：只要有一个分量非周期，整体就非周期，不用再算 LCM。
  4. 忘了 ω0\omega_0ω0​ 与 ω0+2πk\omega_0 + 2\pi kω0​+2πk 等价：sin⁡(1.5πn)\sin(1.5\pi n)sin(1.5πn) 和 sin⁡(−0.5πn)\sin(-0.5\pi n)sin(−0.5πn) 是同一个序列，判周期时可以先化简到 (−π,π](-\pi, \pi](−π,π] 区间内再算，结论一致。
  5. 把连续域的直觉搬过来：连续正弦"任意频率都周期"，离散正弦"多数频率都不周期"，这是最容易失分的地方。

八、总结

  • 一个判据管所有：ω0/2π\omega_0/2\piω0​/2π 是有理数则周期，无理数则非周期。
  • 基本周期：把 ω0/2π\omega_0/2\piω0​/2π 化成最简分数 m/Nm/Nm/N，NNN 就是基本周期。
  • 相加序列：全周期才周期，周期取最小公倍数；有一个非周期，整体非周期。
  • 实指数序列永远不是周期的。
  • 离散域独有的现象：数字频率以 2π2\pi2π 为周期，ω\omegaω 与 ω+2πk\omega + 2\pi kω+2πk 是同一个序列。

一句话总结：正弦 / 复指数序列是否周期，只看 ω0/2π\omega_0/2\piω0​/2π 是不是有理数 —— 有理则周期（最简分数的分母就是基本周期），无理则非周期；这个"有理数门槛"正是离散时间与连续时间最大的差别之一。
