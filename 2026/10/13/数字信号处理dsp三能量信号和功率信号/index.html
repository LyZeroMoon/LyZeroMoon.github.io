【数字信号处理DSP】（三）能量信号和功率信号

能量信号和功率信号

标签： #数字信号处理 #DSP #能量信号 #功率信号 #平均功率

一、为什么要区分能量信号和功率信号？

在数字信号处理中，我们需要对信号进行分类，以便选择合适的分析方法。

  • 能量信号：能量有限、功率为零 → 适合用傅里叶变换分析
  • 功率信号：功率有限、能量无限 → 适合用功率谱分析
  • 既非能量也非功率信号：如 x[n]=nx[n] = nx[n]=n，能量和功率都无限，不做讨论

这个分类的现实意义在于：它决定了你手上这个信号能用哪套工具。一个能量有限的衰减脉冲可以做频谱分析；而一个永不停歇的周期信号或白噪声，能量无限，只能退而求其次分析它的功率分布。

二、基本定义

1. 信号的能量

离散时间信号 x[n]x[n]x[n] 的能量定义为：

E=∑n=−∞∞∣x[n]∣2E = \sum_{n=-\infty}^{\infty} \lvert x[n] \rvert^2 E=n=−∞∑∞​∣x[n]∣2

2. 信号的平均功率

离散时间信号 x[n]x[n]x[n] 的平均功率定义为：

P=lim⁡N→∞12N+1∑n=−NN∣x[n]∣2P = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=-N}^{N} \lvert x[n] \rvert^2 P=N→∞lim​2N+11​n=−N∑N​∣x[n]∣2

四、如何判断？

判断步骤

  1. 计算能量 E=∑n=−∞∞∣x[n]∣2E = \sum_{n=-\infty}^{\infty} \vert x[n]\vert^2E=∑n=−∞∞​∣x[n]∣2
  2. 若 EEE 为有限正值 → 能量信号
  3. 若 EEE 为无限大，则计算平均功率 PPP
  4. 若 PPP 为有限正值 → 功率信号
  5. 若 PPP 也为无限大 → 既非能量也非功率信号

补充：能量有限（平方可和）≠ 绝对可和

判断"能量信号"用的是 ∑∣x[n]∣2<∞\sum \lvert x[n] \rvert^2 \lt \infty∑∣x[n]∣2<∞，称为平方可和；而判断一个系统是否 BIBO 稳定用的是 ∑∣h[n]∣<∞\sum \lvert h[n] \rvert \lt \infty∑∣h[n]∣<∞，称为绝对可和（见（二）离散时间系统六大性质）。这两件事不是一回事：

  • 绝对可和 ⇒\Rightarrow⇒ 平方可和（能量必然有限），但反过来不成立
  • 反例：x[n]=1nu[n−1]x[n] = \dfrac{1}{n}u[n-1]x[n]=n1​u[n−1]。它的能量

E=∑n=1∞1n2=π26<∞E = \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6} \lt \infty E=n=1∑∞​n21​=6π2​<∞

但绝对值之和 ∑n=1∞1n\sum_{n=1}^{\infty} \dfrac{1}{n}∑n=1∞​n1​ 发散，所以它不是绝对可和的。

也就是说，一个序列可以既是"能量信号"，又不是绝对可和的。能量、功率、稳定性是三套独立判据，别互相搬用。另外注意：判断周期信号的平均功率时，只需在一个周期内求平均就够了（后续周期完全重复），即

P=1N∑n=0N−1∣x[n]∣2P = \frac{1}{N}\sum_{n=0}^{N-1} \lvert x[n] \rvert^2 P=N1​n=0∑N−1​∣x[n]∣2

五、典型例题

例题1：有限长序列

x[n]={1,−2,3}x[n] = \{1, -2, 3\}x[n]={1,−2,3}（仅在 n=0,1,2n=0,1,2n=0,1,2 处有值，其余为0）

解：

E=12+(−2)2+32=1+4+9=14<∞E = 1^2 + (-2)^2 + 3^2 = 1 + 4 + 9 = 14 < \infty E=12+(−2)2+32=1+4+9=14<∞

P=lim⁡N→∞142N+1=0P = \lim_{N \to \infty} \frac{14}{2N+1} = 0 P=N→∞lim​2N+114​=0

→ 能量信号 ✅

例题2：单位阶跃序列

x[n]=u[n]x[n] = u[n]x[n]=u[n]

解：

E=∑n=0∞12=∞E = \sum_{n=0}^{\infty} 1^2 = \infty E=n=0∑∞​12=∞

P=lim⁡N→∞12N+1∑n=0N1=lim⁡N→∞N+12N+1=12P = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=0}^{N} 1 = \lim_{N \to \infty} \frac{N+1}{2N+1} = \frac{1}{2} P=N→∞lim​2N+11​n=0∑N​1=N→∞lim​2N+1N+1​=21​

→ 功率信号 ✅

例题3：正弦周期序列

x[n]=sin⁡(πn/4)x[n] = \sin(\pi n/4)x[n]=sin(πn/4)

解：

  • 周期序列，能量无限
  • 基本周期 N=8N = 8N=8（见（一）信号周期性判断），一个周期内的平均功率为有限值

P=1N∑n=0N−1∣sin⁡(πn/4)∣2=18(0+12+1+12+0+12+1+12)=48=12P = \frac{1}{N}\sum_{n=0}^{N-1} \lvert \sin(\pi n/4) \rvert^2 = \frac{1}{8}\Bigl(0 + \frac{1}{2} + 1 + \frac{1}{2} + 0 + \frac{1}{2} + 1 + \frac{1}{2}\Bigr) = \frac{4}{8} = \frac{1}{2} P=N1​n=0∑N−1​∣sin(πn/4)∣2=81​(0+21​+1+21​+0+21​+1+21​)=84​=21​

→ 功率信号 ✅

补充：任意振幅为 AAA 的正弦序列，平均功率都是 A2/2A^2/2A2/2；复指数序列 ejω0ne^{j\omega_0 n}ejω0​n 的平均功率是 1。这两个结论以后会反复用到。

例题4：衰减指数序列

x[n]=(0.5)n⋅u[n]x[n] = (0.5)^n \cdot u[n]x[n]=(0.5)n⋅u[n]

解：

E=∑n=0∞(0.5)2n=∑n=0∞(0.25)n=11−0.25=43<∞E = \sum_{n=0}^{\infty} (0.5)^{2n} = \sum_{n=0}^{\infty} (0.25)^n = \frac{1}{1-0.25} = \frac{4}{3} < \infty E=n=0∑∞​(0.5)2n=n=0∑∞​(0.25)n=1−0.251​=34​<∞

→ 能量信号 ✅

例题5：常数序列

x[n]=3x[n] = 3x[n]=3（对所有 nnn）

解：

E=∑n=−∞∞9=∞E = \sum_{n=-\infty}^{\infty} 9 = \infty E=n=−∞∑∞​9=∞

P=lim⁡N→∞12N+1∑n=−NN9=lim⁡N→∞9(2N+1)2N+1=9P = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=-N}^{N} 9 = \lim_{N \to \infty} \frac{9(2N+1)}{2N+1} = 9 P=N→∞lim​2N+11​n=−N∑N​9=N→∞lim​2N+19(2N+1)​=9

→ 功率信号 ✅

例题6：增长指数序列

x[n]=2n⋅u[n]x[n] = 2^n \cdot u[n]x[n]=2n⋅u[n]

解：

E=∑n=0∞(2)2n=∑n=0∞4n=∞E = \sum_{n=0}^{\infty} (2)^{2n} = \sum_{n=0}^{\infty} 4^n = \infty E=n=0∑∞​(2)2n=n=0∑∞​4n=∞

七、快速记忆口诀

有限长、衰减快 → 能量信号
周期长、一直晃 → 功率信号
增长快、不停涨 → 啥也不是别多想

八、与后续内容的联系

  • 能量信号：可以用傅里叶变换（DTFT）分析频谱
  • 功率信号：不能用常规傅里叶变换，需要用功率谱密度分析
  • 周期信号：属于功率信号，可以用傅里叶级数（DFS）分析

这部分内容在后续学习随机信号处理和功率谱估计时会再次遇到。

九、常见错误提醒

  1. 能量和功率混着算：先判能量 EEE，EEE 有限就结束了（一定是能量信号，PPP 必然为 0），不必再去求 PPP。反过来 E=∞E = \inftyE=∞ 才需要求 PPP。
  2. 忘了"功率"是平均：离散功率不是 ∑∣x[n]∣2\sum \lvert x[n] \rvert^2∑∣x[n]∣2，而是除以窗口长度 2N+12N+12N+1 后取极限，少了这个归一化因子就会得到"无穷大"。
  3. 周期信号只在 n≥0n \geq 0n≥0 上求和：算平均功率必须覆盖整个时间轴（或一个完整周期），只从 n=0n=0n=0 开始求和会漏掉负半轴，结论会错。
  4. 把"能量有限"当成"系统稳定"：稳定看的是 ∑∣h[n]∣\sum \lvert h[n] \rvert∑∣h[n]∣（绝对可和），能量看的是 ∑∣h[n]∣2\sum \lvert h[n] \rvert^2∑∣h[n]∣2（平方可和），后者更宽松，两者不能互换。
  5. 认为"有限长序列一定是能量信号"：这里有前提 —— 序列必须在每个点上都取有限值。若某点取无穷，能量就不是有限值了。

十、知识链定位

能量信号与功率信号（本节）

│

├── 定义：能量 E = Σ|x[n]|²，平均功率 P = lim Σ|x[n]|² /(2N+1)

├── 三类：能量信号 / 功率信号 / 既非能量也非功率

└── 平方可和 ≠ 绝对可和

│

├── 序列的周期性判断（第一节）

├── 系统的 BIBO 稳定性：用绝对可和判断（第二节）

└── 功率谱密度：功率信号的频域分析工具（第五节）

十一、总结

  • 判据只有两条：先看 E=∑∣x[n]∣2E = \sum \lvert x[n] \rvert^2E=∑∣x[n]∣2，有限则为能量信号；无限再看 PPP，有限则为功率信号；两者都无限则不做讨论。
  • 典型归属：有限长序列、衰减指数序列 → 能量信号；周期序列、阶跃、常数 → 功率信号；增长指数序列 → 既非能量也非功率。
  • 周期序列的平均功率只算一个周期，P=1N∑n=0N−1∣x[n]∣2P = \frac{1}{N}\sum_{n=0}^{N-1}\lvert x[n] \rvert^2P=N1​∑n=0N−1​∣x[n]∣2。
  • 能量有限（平方可和）不等于绝对可和，后者才是判断系统稳定的条件。
  • 分类的意义在于选择工具：能量信号谈频谱，功率信号谈功率谱。

一句话总结：能量信号"活一会儿就没了"，功率信号"永远在但强度有限" —— 用 EEE 有限还是 PPP 有限来分；同时记住"能量有限"和"绝对可和"是两回事，前者宽松、后者才是稳定性的判据。
