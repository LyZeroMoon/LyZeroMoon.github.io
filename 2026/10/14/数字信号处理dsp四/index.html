【数字信号处理DSP】（四）自相关函数与互相关函数

自相关函数与互相关函数

标签： #数字信号处理 #DSP #自相关 #互相关 #时延估计 #相关分析

一、为什么需要相关函数？

在信号处理中，我们常常想知道：

  • 信号在不同时刻之间有没有关系？
  • 两个不同的信号之间有没有关联？
  • 信号中是否隐藏着周期成分？
  • 如何从噪声中检测出已知信号？

相关函数就是用来回答这些问题的工具——它衡量信号之间（或信号与自身）在不同延迟下的相似程度。

一个直观的例子：把一段录音和它自己延迟 0.1 秒的版本对齐。如果两边波形"长得像"，逐点相乘再求和就很大；如果完全不像，正负相消，求和接近零。"延迟 + 相乘 + 求和" 就是相关运算的全部内容。

一个必须一开始就说清的约定：不同教材对 rxy[m]r_{xy}[m]rxy​[m] 的定义符号方向相反，导致「延时峰出现在 +n0+n_0+n0​ 还是 −n0-n_0−n0​」看起来互相矛盾。本文统一使用

rxy[m]=∑nx[n] y∗[n−m]r_{xy}[m]=\sum_{n}x[n]\,y^{*}[n-m] rxy​[m]=n∑​x[n]y∗[n−m]

在此约定下，若 y[n]=x[n−n0]y[n]=x[n-n_0]y[n]=x[n−n0​]（yyy 是 xxx 的延迟版本），峰出现在 m=−n0m=-n_0m=−n0​。做题时按题目给的定义推，不要背结论。

二、基本定义

1. 自相关函数（Autocorrelation Function）

上图：左为一个实有限长序列 x[n]x[n]x[n]；右为由它实际算出的自相关 rxx[m]r_{xx}[m]rxx​[m]。可见两个特征——关于 m=0m=0m=0 偶对称（红色虚线把 r[−1]r[-1]r[−1] 与 r[1]r[1]r[1]、r[−2]r[-2]r[−2] 与 r[2]r[2]r[2] 分别等高连起来），且零延迟处取最大值 rxx[0]=Er_{xx}[0]=Erxx​[0]=E（等于序列能量）。序列长度 L=6L=6L=6，自相关长度 2L−1=112L-1=112L−1=11。

衡量同一个信号在不同时刻的相关性。

确定性信号（能量型）

rxx[m]=∑n=−∞∞x[n] x∗[n−m]r_{xx}[m] = \sum_{n=-\infty}^{\infty} x[n] \, x^*[n-m] rxx​[m]=n=−∞∑∞​x[n]x∗[n−m]

随机信号（宽平稳）

rxx[m]=E[x[n] x∗[n−m]]r_{xx}[m] = E\left[x[n] \, x^*[n-m]\right] rxx​[m]=E[x[n]x∗[n−m]]

实际计算（各态历经假设）

rxx[m]=lim⁡N→∞12N+1∑n=−NNx[n] x∗[n−m]r_{xx}[m] = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=-N}^{N} x[n] \, x^*[n-m] rxx​[m]=N→∞lim​2N+11​n=−N∑N​x[n]x∗[n−m]

两种归一化不要混用：

  • 不除以长度（上面前两式）得到的是相关序列，rxx[0]r_{xx}[0]rxx​[0] 等于信号能量；
  • 除以长度（第三式）得到的是平均相关，rxx[0]r_{xx}[0]rxx​[0] 等于信号平均功率，量纲和平稳性都更好，功率谱分析中通常用这一种。

本文涉及周期信号、白噪声时用的都是平均相关。周期信号必须用平均相关，否则 ∑nx[n]x[n−m]\sum_n x[n]x[n-m]∑n​x[n]x[n−m] 发散。

2. 互相关函数（Cross-Correlation Function）

衡量两个不同信号之间的相关性。

定义式

rxy[m]=∑n=−∞∞x[n] y∗[n−m]r_{xy}[m] = \sum_{n=-\infty}^{\infty} x[n] \, y^*[n-m] rxy​[m]=n=−∞∑∞​x[n]y∗[n−m]

或等价地（把 nnn 换成 n+mn+mn+m 再重新标号）：

rxy[m]=∑n=−∞∞x[n+m] y∗[n]r_{xy}[m] = \sum_{n=-\infty}^{\infty} x[n+m] \, y^*[n] rxy​[m]=n=−∞∑∞​x[n+m]y∗[n]

随机信号

rxy[m]=E[x[n] y∗[n−m]]r_{xy}[m] = E\left[x[n] \, y^*[n-m]\right] rxy​[m]=E[x[n]y∗[n−m]]

顺序有讲究：rxy[m]r_{xy}[m]rxy​[m] 和 ryx[m]r_{yx}[m]ryx​[m] 在一般情况下不相等，两者满足 rxy[m]=ryx∗[−m]r_{xy}[m] = r_{yx}^*[-m]rxy​[m]=ryx∗​[−m]。所以写互相关时必须交代"谁在前、谁在后"。

三、物理意义

情况 含义
自相关 rxx[0]r_{xx}[0]rxx​[0] 信号的能量（确定性）或平均功率（随机）
自相关 m≠0m \neq 0m=0 信号与延迟后自身的相似度
互相关 rxy[m]r_{xy}[m]rxy​[m] 信号 xxx 与"延迟 mmm 的 yyy"的相似度
rxy[m]r_{xy}[m]rxy​[m] 峰值位置 两信号之间的时延估计
rxx[m]r_{xx}[m]rxx​[m] 衰减快慢 信号"变化快慢"——衰减越快，相邻样点越不相关

四、主要性质对比

1. 对称性

类型 性质
自相关（一般信号） rxx[−m]=rxx∗[m]r_{xx}[-m] = r_{xx}^*[m]rxx​[−m]=rxx∗​[m]
自相关（实信号） rxx[−m]=rxx[m]r_{xx}[-m] = r_{xx}[m]rxx​[−m]=rxx​[m]（偶函数）
互相关 rxy[−m]=ryx∗[m]r_{xy}[-m] = r_{yx}^*[m]rxy​[−m]=ryx∗​[m]
互相关（实信号） rxy[−m]=ryx[m]r_{xy}[-m] = r_{yx}[m]rxy​[−m]=ryx​[m]

为什么自相关是偶函数（共轭对称）？ 推导只需三步，做一遍就再也不会忘：

rxx[−m]=∑nx[n] x∗[n+m]=k=n+m∑kx[k−m] x∗[k]=(∑kx[k] x∗[k−m]) ⁣∗=rxx∗[m]r_{xx}[-m] = \sum_n x[n] \, x^*[n+m] \overset{k = n+m}{=} \sum_k x[k-m] \, x^*[k] = \left( \sum_k x[k] \, x^*[k-m] \right)^{\!*} = r_{xx}^*[m] rxx​[−m]=n∑​x[n]x∗[n+m]=k=n+mk∑​x[k−m]x∗[k]=(k∑​x[k]x∗[k−m])∗=rxx∗​[m]

最后一步交换了求和顺序并取共轭。对实信号，x∗=xx^* = xx∗=x，共轭消失，于是 rxx[−m]=rxx[m]r_{xx}[-m] = r_{xx}[m]rxx​[−m]=rxx​[m]，是真正的偶函数。

这一步为什么必须写：很多结论（如 rxxr_{xx}rxx​ 只含余弦项、功率谱为实偶函数）都建立在偶对称之上。考卷上被问"证明 rxxr_{xx}rxx​ 是偶函数"时，就照这三步写。

2. 最大值位置

  • 自相关：在 m=0m=0m=0 处取最大值

∣rxx[m]∣≤rxx[0],∀m\lvert r_{xx}[m] \rvert \leq r_{xx}[0], \quad \forall m ∣rxx​[m]∣≤rxx​[0],∀m

这个不等式就是柯西-施瓦茨不等式：把 x[n]x[n]x[n] 和 x[n−m]x[n-m]x[n−m] 看成两个向量，内积的模不超过模长之积，而 rxx[0]r_{xx}[0]rxx​[0] 正好是两个模长平方之积的开方。

一般形式与等号条件（等号 ⟺ 两序列线性相关，即只差一个缩放因子）见 施瓦茨不等式速查。

  • 互相关：最大值位置反映两信号的相对时延

∣rxy[m]∣≤rxx[0] ryy[0]\lvert r_{xy}[m] \rvert \leq \sqrt{r_{xx}[0] \, r_{yy}[0]} ∣rxy​[m]∣≤rxx​[0]ryy​[0]​

注意这里右端是两个信号各自零点值乘积的开方，所以 ∣rxy[m]∣≤1\lvert r_{xy}[m] \rvert \leq 1∣rxy​[m]∣≤1 只有在两个信号都做了归一化（rxx[0]=ryy[0]=1r_{xx}[0] = r_{yy}[0] = 1rxx​[0]=ryy​[0]=1）时才成立——这就是下面要讲的归一化互相关。

3. 周期性与相关性

  • 若 x[n]x[n]x[n] 是周期信号，则 rxx[m]r_{xx}[m]rxx​[m] 也是同周期的周期信号
  • 若 x[n]x[n]x[n] 和 y[n]y[n]y[n] 不相关（如信号与独立噪声），则 rxy[m]=0r_{xy}[m] = 0rxy​[m]=0（对随机信号取期望）

4. 与卷积的关系

  • 自相关：rxx[m]=x[m]∗x∗[−m]r_{xx}[m] = x[m] * x^*[-m]rxx​[m]=x[m]∗x∗[−m]
  • 互相关：rxy[m]=x[m]∗y∗[−m]r_{xy}[m] = x[m] * y^*[-m]rxy​[m]=x[m]∗y∗[−m]

也就是说：相关 = 不翻转的那个信号 与 翻转共轭后的另一个信号 做卷积。这正是"卷积要翻转、相关不翻转"这句话的来源。

5. 直流分量的影响

若信号含直流分量 x[n]=xˉ+x~[n]x[n] = \bar{x} + \tilde{x}[n]x[n]=xˉ+x~[n]（x~\tilde{x}x~ 为零均值波动部分），则

rxx[m]=xˉ2+rx~x~[m]r_{xx}[m] = \bar{x}^2 + r_{\tilde{x}\tilde{x}}[m] rxx​[m]=xˉ2+rx~x~​[m]

即自相关里被叠加了一个常数 xˉ2\bar{x}^2xˉ2，而这一项对 mmm 不衰减。后果：

  • 相关图整体被抬高，非零延迟的峰不再趋近于零；
  • 看起来"像"长相关，容易误判为周期性。

工程做法：算自相关前先去均值（减去 xˉ\bar{x}xˉ），否则谱估计在 ω=0\omega = 0ω=0 处会出现虚假尖峰。这一点在功率谱密度估计中尤其重要。

五、归一化相关系数：把"有多像"变成可比的数

原始 rxy[m]r_{xy}[m]rxy​[m] 带着信号的能量量纲，两个不同量级的信号没法直接比较相关强弱。工程上普遍使用归一化相关系数：

ρxy[m]=rxy[m]rxx[0] ryy[0],∣ρxy[m]∣≤1\rho_{xy}[m] = \frac{r_{xy}[m]}{\sqrt{r_{xx}[0]\,r_{yy}[0]}}, \qquad \lvert \rho_{xy}[m] \rvert \leq 1 ρxy​[m]=rxx​[0]ryy​[0]​rxy​[m]​,∣ρxy​[m]∣≤1

由第四节的柯西-施瓦茨不等式，这个归一化保证结果落在 [−1,1][-1,1][−1,1]：

∣ρxy∣\lvert\rho_{xy}\rvert∣ρxy​∣ 含义
111 完全正相关（yyy 是 xxx 的纯缩放/平移）
000 完全不相关（正交）
接近 111 强相关，可信任的时延估计
接近 000 相关峰淹没在噪声里，时延估计不可靠

这是判断"相关峰能不能用"的标准做法：只看到峰还不够，要看 ∣ρxy∣\lvert\rho_{xy}\rvert∣ρxy​∣ 是否明显高于其它延迟处的取值。若整条曲线都在 0.10.10.1 上下浮动，那个"最高点"就是噪声。

统一答题格式：写定义式 → 代入求和 → 定非零区间（或取平均）→ 化简 → 结论。

例题 4：白噪声的自相关

八、应用场景

自相关的应用

  1. 周期检测：从噪声中提取微弱周期信号（相关值在周期倍数处再次出现峰）
  2. 功率谱估计：通过维纳-辛钦定理，自相关的傅里叶变换 = 功率谱密度
  3. 语音处理：基音周期检测（浊音的基音周期对应自相关的第二个峰）
  4. 随机信号分析：判断信号是否为白噪声（自相关是否为冲激）

互相关的应用

  1. 时延估计：雷达、声呐、超声检测
  2. 系统辨识：通过输入输出互相关求系统冲激响应（白噪声激励时 rxy[m]=σ2h[m]r_{xy}[m] = \sigma^2 h[m]rxy​[m]=σ2h[m]）
  3. 信号匹配/模板匹配：在接收信号中寻找已知信号（匹配滤波器）
  4. 通信同步：帧同步、码元同步

工程实现提示：直接按定义算相关是 O(L2)O(L^2)O(L2)。实际系统用 FFT 算——对有限长序列补零到 N≥Lx+Ly−1N\ge L_x+L_y-1N≥Lx​+Ly​−1 后，

rxy[m]  ⟷  X[k] Y∗[k]r_{xy}[m] \;\longleftrightarrow\; X[k]\,Y^*[k] rxy​[m]⟷X[k]Y∗[k]

即"频域相乘再反变换"，复杂度降到 O(Nlog⁡N)O(N\log N)O(NlogN)。补零这一步不能省，否则得到的是循环相关，尾部会绕回头部造成假峰。具体做法见 （十四）DTFT 与 DFT 章节的衔接部分。

九、常见错误提醒

  1. 把时延峰的符号背错：峰在 +n0+n_0+n0​ 还是 −n0-n_0−n0​ 取决于定义式。本文定义下峰在 −n0-n_0−n0​；换一种定义就变正。永远按题目给的定义推，别背结论。
  2. 自相关和互相关搞错顺序：rxy[m]≠ryx[m]r_{xy}[m] \neq r_{yx}[m]rxy​[m]=ryx​[m]，只满足 rxy[m]=ryx∗[−m]r_{xy}[m] = r_{yx}^*[-m]rxy​[m]=ryx∗​[−m]。写的时候先说清楚谁在前。
  3. 忘了共轭：rxy[m]=∑x[n]y∗[n−m]r_{xy}[m]=\sum x[n]y^*[n-m]rxy​[m]=∑x[n]y∗[n−m] 里的共轭在 yyy 上；rxxr_{xx}rxx​ 的共轭在延迟项上。漏掉共轭后对称性检验必然失败。
  4. 忘了自相关的对称性检验：算出 rxx[m]r_{xx}[m]rxx​[m] 后应检查 rxx[−m]=rxx∗[m]r_{xx}[-m] = r_{xx}^*[m]rxx​[−m]=rxx∗​[m]，这是最快的自查手段。
  5. 把 rxx[0]r_{xx}[0]rxx​[0] 当作能量还是功率说不清：取决于是否除以长度，两种归一化不能混用。周期信号必须用平均相关，否则 ∑nx[n]x[n−m]\sum_n x[n]x[n-m]∑n​x[n]x[n−m] 发散。
  6. 以为相关就是卷积：相关不翻转被比较的那个信号（等价于翻转另一个），且互相关要取共轭。
  7. 不去均值就算自相关：直流分量会让自相关整体抬高常数 xˉ2\bar{x}^2xˉ2，容易误判成周期性。先减均值再算。
  8. 以为相关能去除噪声：相关是把噪声平均掉（不相关部分趋于零），需要足够长的数据；短数据上噪声会让峰变毛糙。
  9. 只看峰值不看归一化系数：∣ρxy∣\lvert\rho_{xy}\rvert∣ρxy​∣ 接近 000 时，那个"最高点"就是噪声，不能当时延用。
