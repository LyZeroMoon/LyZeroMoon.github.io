【数字信号处理DSP】（七）卷积和

卷积和

标签： #数字信号处理 #DSP #卷积和 #LSI系统 #单位脉冲响应 #图解法

一、为什么需要卷积？

卷积是离散时间信号处理中最核心的运算之一。它的重要性体现在：

  • LSI系统的描述：线性移不变（LSI）系统的输出等于输入与单位脉冲响应的卷积
  • 信号分解：任何离散时间信号都可以分解为单位脉冲序列的加权和，卷积正是这种分解的自然结果
  • 后续基础：卷积是理解 Z 变换、DFT、滤波器设计的前提

一句话概括它的地位：只要系统是 LSI，输出就只能是卷积。这是在 （二）离散时间系统六大性质判断方法 中"线性 + 时不变"两个性质合起来推出来的必然结论。

二、卷积的定义

1. 卷积和公式

对于两个离散时间序列 x[n]x[n]x[n] 和 h[n]h[n]h[n]，它们的卷积定义为：

y[n]=x[n]∗h[n]=∑k=−∞∞x[k] h[n−k]y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] \, h[n-k] y[n]=x[n]∗h[n]=k=−∞∑∞​x[k]h[n−k]

其中：

  • nnn 为输出序列的时间索引
  • kkk 为求和哑变量
  • ∗*∗ 表示卷积运算符

2. 另一种等价形式

y[n]=∑k=−∞∞x[n−k] h[k]y[n] = \sum_{k=-\infty}^{\infty} x[n-k] \, h[k] y[n]=k=−∞∑∞​x[n−k]h[k]

两种形式等价，由卷积的交换律保证。做题时选哪个更方便就用哪个——如果其中一个序列很长（如 u[n]u[n]u[n]、anu[n]a^nu[n]anu[n]），把它的下标留在 n−kn-kn−k 位置通常更好处理。

1. LSI系统的零状态响应

对于线性移不变系统，若系统的单位脉冲响应为 h[n]h[n]h[n]，则输入 x[n]x[n]x[n] 产生的零状态响应为：

y[n]=x[n]∗h[n]y[n] = x[n] * h[n] y[n]=x[n]∗h[n]

2. 信号分解角度

将输入信号 x[n]x[n]x[n] 表示为加权移位单位脉冲的和：

x[n]=∑k=−∞∞x[k] δ[n−k]x[n] = \sum_{k=-\infty}^{\infty} x[k] \, \delta[n-k] x[n]=k=−∞∑∞​x[k]δ[n−k]

由于系统是线性和移不变的，输出为：

y[n]=∑k=−∞∞x[k] h[n−k]=x[n]∗h[n]y[n] = \sum_{k=-\infty}^{\infty} x[k] \, h[n-k] = x[n] * h[n] y[n]=k=−∞∑∞​x[k]h[n−k]=x[n]∗h[n]

这三步推理（分解 → 用脉冲响应替换 → 用线性叠加求和）就是卷积的全部来历，值得记住上面这个推导。它的结构可以用一张图看得很清楚：

  SA --> SUM["线性叠加求和"]
  SUM --> Y["输出 y[n] = x[n] * h[n]"]

四、图解卷积法（四步走）

计算卷积 y[n]=x[n]∗h[n]y[n] = x[n] * h[n]y[n]=x[n]∗h[n] 的图解步骤如下：

步骤1：翻转（Folding）

将 h[k]h[k]h[k] 关于纵轴翻转得到 h[−k]h[-k]h[−k]。

步骤2：平移（Shifting）

将 h[−k]h[-k]h[−k] 向右平移 nnn 个单位，得到 h[n−k]h[n-k]h[n−k]。

步骤3：相乘（Multiplication）

将 x[k]x[k]x[k] 与 h[n−k]h[n-k]h[n−k] 逐点相乘。

步骤4：求和（Summation）

将所有乘积相加，得到 y[n]y[n]y[n] 在该 nnn 点的值。

重复步骤2~4，遍历所有 nnn 即可得到完整的 y[n]y[n]y[n]。

上图：x={1,2,3,2,1}x=\{1,2,3,2,1\}x={1,2,3,2,1}、h={1,0.5,0.25}h=\{1,0.5,0.25\}h={1,0.5,0.25}。上排把 hhh 先翻转（灰点线是未翻转的 h[k]h[k]h[k]，橙虚线是翻转后的 h[n−k]h[n-k]h[n−k]——一个递减、一个递增，翻转关系一眼可见），再右移到当前的 nnn。下排是逐点乘积，柱高之和就是 y[n]y[n]y[n]：y[2]=4.25y[2]=4.25y[2]=4.25、y[3]=4y[3]=4y[3]=4。窗口每右移一格，橙线跟着右移一格，这就是"重复步骤 2~4"的字面意思。

graph LR
  A["h[k]"] --> B["步骤1 翻转：h[-k]"]
  B --> C["步骤2 平移：h[n-k]"]
  C --> D["步骤3 与 x[k] 逐点相乘"]
  D --> E["步骤4 求和得该 n 处的 y[n]"]
  E -->|n 加 1| C

口诀：翻、移、乘、加。四个字里最容易被忽略的是"移"——移的距离就是当前的输出时刻 nnn，所以每算一个 nnn 都要重新移一次。

五、卷积的性质

性质1：交换律

x[n]∗h[n]=h[n]∗x[n]x[n] * h[n] = h[n] * x[n] x[n]∗h[n]=h[n]∗x[n]

性质2：结合律

(x[n]∗h1[n])∗h2[n]=x[n]∗(h1[n]∗h2[n])(x[n] * h_1[n]) * h_2[n] = x[n] * (h_1[n] * h_2[n]) (x[n]∗h1​[n])∗h2​[n]=x[n]∗(h1​[n]∗h2​[n])

性质3：分配律

x[n]∗(h1[n]+h2[n])=x[n]∗h1[n]+x[n]∗h2[n]x[n] * (h_1[n] + h_2[n]) = x[n] * h_1[n] + x[n] * h_2[n] x[n]∗(h1​[n]+h2​[n])=x[n]∗h1​[n]+x[n]∗h2​[n]

性质4：与单位脉冲的卷积

x[n]∗δ[n]=x[n]x[n] * \delta[n] = x[n] x[n]∗δ[n]=x[n]

性质5：与移位单位脉冲的卷积

x[n]∗δ[n−n0]=x[n−n0]x[n] * \delta[n - n_0] = x[n - n_0] x[n]∗δ[n−n0​]=x[n−n0​]

性质6：与单位阶跃的卷积（累加器）

x[n]∗u[n]=∑k=−∞nx[k]x[n] * u[n] = \sum_{k=-\infty}^{n} x[k] x[n]∗u[n]=k=−∞∑n​x[k]

性质7：时移性质（考试高频）

若 x[n]∗h[n]=y[n]x[n] * h[n] = y[n]x[n]∗h[n]=y[n]，则

x[n−n1]∗h[n−n2]=y[n−n1−n2]x[n-n_1] * h[n-n_2] = y[n-n_1-n_2] x[n−n1​]∗h[n−n2​]=y[n−n1​−n2​]

即两个输入各自移多少，输出就移多少之和。这条性质把"带移位的卷积"直接归约到"先算无移位的卷积，再把结果整体平移"。

它的用法：遇到 x[n−2]∗h[n−1]x[n-2]*h[n-1]x[n−2]∗h[n−1] 这种题，先算 x∗hx*hx∗h，再把结果右移 333，不要重新做四步法。

六、典型例题

统一答题格式：① 判类型（有限长 → 表格/多项式法；无限长 → 定区间后解析求和）；② 定 yyy 的非零区间；③ 逐个 nnn 计算；④ 核长度（Ly=Lx+Lh−1L_y=L_x+L_h-1Ly​=Lx​+Lh​−1）。
「定区间 + 核长度」这两步能在动笔前就把答案框住，算错了立刻能发现。

例题 4：利用卷积性质简化计算

题目：x[n]=δ[n]+2δ[n−1]x[n] = \delta[n] + 2\delta[n-1]x[n]=δ[n]+2δ[n−1]，h[n]=3δ[n]−δ[n−2]h[n] = 3\delta[n] - \delta[n-2]h[n]=3δ[n]−δ[n−2]，求 y[n]=x[n]∗h[n]y[n]=x[n]*h[n]y[n]=x[n]∗h[n]。

（1）策略：含 δ\deltaδ 的序列用性质法，不要做四步法。

（2）展开成四项（分配律）：

=3δ[n]∗δ[n]⏟=δ[n]−δ[n]∗δ[n−2]⏟=δ[n−2]+6δ[n−1]∗δ[n]⏟=δ[n−1]−2δ[n−1]∗δ[n−2]⏟=δ[n−3]=3\underbrace{\delta[n]*\delta[n]}_{=\delta[n]}-\underbrace{\delta[n]*\delta[n-2]}_{=\delta[n-2]}+6\underbrace{\delta[n-1]*\delta[n]}_{=\delta[n-1]}-2\underbrace{\delta[n-1]*\delta[n-2]}_{=\delta[n-3]} =3=δ[n]δ[n]∗δ[n]​​−=δ[n−2]δ[n]∗δ[n−2]​​+6=δ[n−1]δ[n−1]∗δ[n]​​−2=δ[n−3]δ[n−1]∗δ[n−2]​​

七、卷积结果的长度与有效区间

这是手工计算最容易出错的地方，单独拎出来说清楚。

1. 长度规则

设 x[n]x[n]x[n] 非零长度为 LxL_xLx​、h[n]h[n]h[n] 非零长度为 LhL_hLh​，则 y[n]=x[n]∗h[n]y[n] = x[n]*h[n]y[n]=x[n]∗h[n] 的非零长度为

Ly=Lx+Lh−1L_y = L_x + L_h - 1 Ly​=Lx​+Lh​−1

直觉：最前面的非零点只能靠"两者的第一个非零点"对齐产生，最后面的非零点只能靠"两者的最后一个非零点"对齐产生，中间的每个输出点至少有一种配对方式。

2. 有效区间

若 x[n]x[n]x[n] 的非零区间为 [N1,N2][N_1, N_2][N1​,N2​]、h[n]h[n]h[n] 的非零区间为 [M1,M2][M_1, M_2][M1​,M2​]，则 y[n]y[n]y[n] 的非零区间为

[N1+M1,N2+M2][N_1 + M_1, \quad N_2 + M_2] [N1​+M1​,N2​+M2​]

这个区间就是"起始下标相加、结束下标相加"，不用记公式也能推。用它可以直接给例题 1 的结果定界：xxx 在 [0,2][0,2][0,2]、hhh 在 [0,1][0,1][0,1]，则 yyy 在 [0,3][0, 3][0,3]，共 4 点——与表格算出的 {4,13,22,15}\{4,13,22,15\}{4,13,22,15} 一致。

3. 卷积 vs 相关（易混点）

是否翻转 表达式 结果长度
卷积 翻转 ∑kx[k]h[n−k]\sum_k x[k]h[n-k]∑k​x[k]h[n−k] Lx+Lh−1L_x + L_h - 1Lx​+Lh​−1
相关 不翻转 ∑kx[k]y[k−n]\sum_k x[k]y[k-n]∑k​x[k]y[k−n] 同左（也是 Lx+Ly−1L_x + L_y - 1Lx​+Ly​−1）

一句话区分：卷积要"翻"，相关不要"翻"（详见 （四）自相关函数与互相关函数）。自相关可以看成"序列与自己的卷积"，所以长度正好是 2L−12L-12L−1。

八、卷积的计算方法总结

方法 适用场景 特点
图解翻转法 教学理解、短序列 直观，但手工计算慢
表格法 有限长序列 系统化，不易出错
多项式乘法 有限长序列 最快，一次乘法出全部系数
解析法 无限长序列（指数、阶跃） 需要求和公式
性质法 含 δ\deltaδ 的序列 最快，利用卷积性质
FFT法 长序列、工程实现 计算效率高（O(Nlog⁡N)O(N\log N)O(NlogN)）

用 FFT 算卷积：为什么必须补零

频域相乘对应循环卷积，不是线性卷积：

IDFT{X[k]H[k]}=循环卷积\text{IDFT}\big\{X[k]H[k]\big\} = \text{循环卷积} IDFT{X[k]H[k]}=循环卷积

要让两者相等，必须把两个序列都补零到长度 N≥Lx+Lh−1N\ge L_x+L_h-1N≥Lx​+Lh​−1 再做 NNN 点 FFT。不补零会出现"尾部绕回头部"的混叠——本应出现在末尾的项跑到开头，结果全错。

工程惯例：实做时取 N=2⌈log⁡2(Lx+Lh−1)⌉N=2^{\lceil\log_2(L_x+L_h-1)\rceil}N=2⌈log2​(Lx​+Lh​−1)⌉，即不小于 Lx+Lh−1L_x+L_h-1Lx​+Lh​−1 的最小 2 的幂，这样 FFT 最快。

十、常见错误提醒

  1. 求和区间搞错：一定要正确确定 x[k]x[k]x[k] 和 h[n−k]h[n-k]h[n−k] 的非零区间。先写出"下界 ≤ k ≤ 上界"，再判断这个区间是否为空（上界小于下界即为空，y[n]=0y[n]=0y[n]=0）。
  2. 忘记边界：有限长卷积的结果长度 = Lx+Lh−1L_x + L_h - 1Lx​+Lh​−1，且区间 = 两区间首尾分别相加。算完先核这两个数。
  3. 混淆卷积与相关：卷积需要翻转，相关不需要翻转。
  4. 符号混淆：x[n]∗h[n]x[n]*h[n]x[n]∗h[n] 中的 ∗*∗ 是卷积运算符，不是乘法。
  5. 以为矩形卷积一定是三角形：只有等宽矩形才是纯三角；不等宽时是梯形（有平台段）。
  6. anu[n]∗bnu[n]a^n u[n]*b^n u[n]anu[n]∗bnu[n] 直接用几何级数：公比是 a/ba/ba/b 而不是 aaa，容易漏掉外层的 bnb^nbn。结果一定要是 an+1−bn+1a−b\dfrac{a^{n+1}-b^{n+1}}{a-b}a−ban+1−bn+1​ 这种对称形式。
  7. 带移位的卷积重做四步法：应先用性质 7（x[n−n1]∗h[n−n2]=y[n−n1−n2]x[n-n_1]*h[n-n_2]=y[n-n_1-n_2]x[n−n1​]∗h[n−n2​]=y[n−n1​−n2​]），只算一次无移位卷积。
  8. 用 FFT 算卷积不补零：得到的是循环卷积，尾部绕回头部。必须补零到 ≥Lx+Lh−1\ge L_x+L_h-1≥Lx​+Lh​−1。
