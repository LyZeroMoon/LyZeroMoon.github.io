【数字信号处理DSP】（七）卷积和

卷积和

标签： #数字信号处理 #DSP #卷积和 #LSI系统 #单位脉冲响应 #图解法

一、为什么需要卷积？

卷积是离散时间信号处理中最核心的运算之一。它的重要性体现在：

  • LSI系统的描述：线性移不变（LSI）系统的输出等于输入与单位脉冲响应的卷积
  • 信号分解：任何离散时间信号都可以分解为单位脉冲序列的加权和，卷积正是这种分解的自然结果
  • 后续基础：卷积是理解 Z 变换、DFT、滤波器设计的前提

一句话概括它的地位：只要系统是 LSI，输出就只能是卷积。这是在 （二）离散时间系统六大性质判断方法 中"线性 + 时不变"两个性质合起来推出来的必然结论。

二、卷积的定义

1. 卷积和公式

对于两个离散时间序列 x[n]x[n]x[n] 和 h[n]h[n]h[n]，它们的卷积定义为：

y[n]=x[n]∗h[n]=∑k=−∞∞x[k] h[n−k]y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] \, h[n-k] y[n]=x[n]∗h[n]=k=−∞∑∞​x[k]h[n−k]

其中：

  • nnn 为输出序列的时间索引
  • kkk 为求和哑变量
  • ∗*∗ 表示卷积运算符

2. 另一种等价形式

y[n]=∑k=−∞∞x[n−k] h[k]y[n] = \sum_{k=-\infty}^{\infty} x[n-k] \, h[k] y[n]=k=−∞∑∞​x[n−k]h[k]

两种形式等价，由卷积的交换律保证。

三、卷积的物理意义

上图：两个长度 3 的矩形序列卷积，得到长度 5 的三角序列 1,2,3,2,11,2,3,2,11,2,3,2,1。卷积结果长度 = 两序列长度之和减 1。

1. LSI系统的零状态响应

对于线性移不变系统，若系统的单位脉冲响应为 h[n]h[n]h[n]，则输入 x[n]x[n]x[n] 产生的零状态响应为：

y[n]=x[n]∗h[n]y[n] = x[n] * h[n] y[n]=x[n]∗h[n]

2. 信号分解角度

将输入信号 x[n]x[n]x[n] 表示为加权移位单位脉冲的和：

x[n]=∑k=−∞∞x[k] δ[n−k]x[n] = \sum_{k=-\infty}^{\infty} x[k] \, \delta[n-k] x[n]=k=−∞∑∞​x[k]δ[n−k]

由于系统是线性和移不变的，输出为：

y[n]=∑k=−∞∞x[k] h[n−k]=x[n]∗h[n]y[n] = \sum_{k=-\infty}^{\infty} x[k] \, h[n-k] = x[n] * h[n] y[n]=k=−∞∑∞​x[k]h[n−k]=x[n]∗h[n]

这三步推理（分解 → 用脉冲响应替换 → 用线性叠加求和）就是卷积的全部来历，值得记住上面这个推导。它的结构可以用一张图看得很清楚：

graph LR
  X["输入 x[n]"] --> D["分解为 δ 的加权和"]
  D --> SA["每个 δ[n-k] 对应响应 h[n-k]"]
  SA --> SUM["线性叠加求和"]
  SUM --> Y["输出 y[n] = x[n] * h[n]"]
  H["系统特性 h[n]"] --> SA

四、图解卷积法（四步走）

计算卷积 y[n]=x[n]∗h[n]y[n] = x[n] * h[n]y[n]=x[n]∗h[n] 的图解步骤如下：

步骤1：翻转（Folding）

将 h[k]h[k]h[k] 关于纵轴翻转得到 h[−k]h[-k]h[−k]。

步骤2：平移（Shifting）

将 h[−k]h[-k]h[−k] 向右平移 nnn 个单位，得到 h[n−k]h[n-k]h[n−k]。

步骤3：相乘（Multiplication）

将 x[k]x[k]x[k] 与 h[n−k]h[n-k]h[n−k] 逐点相乘。

步骤4：求和（Summation）

将所有乘积相加，得到 y[n]y[n]y[n] 在该 nnn 点的值。

重复步骤2~4，遍历所有 nnn 即可得到完整的 y[n]y[n]y[n]。

graph LR
  A["h[k]"] --> B["步骤1 翻转：h[-k]"]
  B --> C["步骤2 平移：h[n-k]"]
  C --> D["步骤3 与 x[k] 逐点相乘"]
  D --> E["步骤4 求和得该 n 处的 y[n]"]
  E -->|n 加 1| C

口诀：翻、移、乘、加。四个字里最容易被忽略的是"移"——移的距离就是当前的输出时刻 nnn，所以每算一个 nnn 都要重新移一次。

五、卷积的性质

性质1：交换律

x[n]∗h[n]=h[n]∗x[n]x[n] * h[n] = h[n] * x[n] x[n]∗h[n]=h[n]∗x[n]

性质2：结合律

(x[n]∗h1[n])∗h2[n]=x[n]∗(h1[n]∗h2[n])(x[n] * h_1[n]) * h_2[n] = x[n] * (h_1[n] * h_2[n]) (x[n]∗h1​[n])∗h2​[n]=x[n]∗(h1​[n]∗h2​[n])

性质3：分配律

x[n]∗(h1[n]+h2[n])=x[n]∗h1[n]+x[n]∗h2[n]x[n] * (h_1[n] + h_2[n]) = x[n] * h_1[n] + x[n] * h_2[n] x[n]∗(h1​[n]+h2​[n])=x[n]∗h1​[n]+x[n]∗h2​[n]

性质4：与单位脉冲的卷积

x[n]∗δ[n]=x[n]x[n] * \delta[n] = x[n] x[n]∗δ[n]=x[n]

性质5：与移位单位脉冲的卷积

x[n]∗δ[n−n0]=x[n−n0]x[n] * \delta[n - n_0] = x[n - n_0] x[n]∗δ[n−n0​]=x[n−n0​]

性质6：与单位阶跃的卷积（累加器）

x[n]∗u[n]=∑k=−∞nx[k]x[n] * u[n] = \sum_{k=-\infty}^{n} x[k] x[n]∗u[n]=k=−∞∑n​x[k]

六、典型例题

例题1：两个有限长序列的卷积

已知：

x[n]={1,2,3},n=0,1,2x[n] = \{1, 2, 3\}, \quad n=0,1,2 x[n]={1,2,3},n=0,1,2

h[n]={4,5},n=0,1h[n] = \{4, 5\}, \quad n=0,1 h[n]={4,5},n=0,1

求 y[n]=x[n]∗h[n]y[n] = x[n] * h[n]y[n]=x[n]∗h[n]

解：

列出表格法（或图解）：

n 计算过程 y[n]
0 1×4=41\times4 = 41×4=4 4
1 1×5+2×4=5+8=131\times5 + 2\times4 = 5+8=131×5+2×4=5+8=13 13
2 2×5+3×4=10+12=222\times5 + 3\times4 = 10+12=222×5+3×4=10+12=22 22
3 3×5=153\times5 = 153×5=15 15

所以：

y[n]={4,13,22,15},n=0,1,2,3y[n] = \{4, 13, 22, 15\}, \quad n=0,1,2,3 y[n]={4,13,22,15},n=0,1,2,3

例题2：指数序列与单位阶跃的卷积

x[n]=anu[n]x[n] = a^n u[n]x[n]=anu[n]，∣a∣<1\vert a\vert<1∣a∣<1，h[n]=u[n]h[n] = u[n]h[n]=u[n]

求 y[n]=x[n]∗u[n]y[n] = x[n] * u[n]y[n]=x[n]∗u[n]

解：

y[n]=∑k=−∞∞aku[k] u[n−k]y[n] = \sum_{k=-\infty}^{\infty} a^k u[k] \, u[n-k] y[n]=k=−∞∑∞​aku[k]u[n−k]

由于 u[k]u[k]u[k] 使 k≥0k \geq 0k≥0，u[n−k]u[n-k]u[n−k] 使 k≤nk \leq nk≤n，所以：

当 n<0n < 0n<0 时，无重叠区间，y[n]=0y[n]=0y[n]=0；
当 n≥0n \geq 0n≥0 时：

y[n]=∑k=0nak=1−an+11−ay[n] = \sum_{k=0}^{n} a^k = \frac{1-a^{n+1}}{1-a} y[n]=k=0∑n​ak=1−a1−an+1​

因此：

y[n]=1−an+11−au[n]y[n] = \frac{1-a^{n+1}}{1-a} u[n] y[n]=1−a1−an+1​u[n]

例题3：矩形脉冲与自身的卷积

x[n]=RN[n]x[n] = R_N[n]x[n]=RN​[n]（矩形序列，从 000 到 N−1N-1N−1 为1）

求 y[n]=x[n]∗x[n]y[n] = x[n] * x[n]y[n]=x[n]∗x[n]

解：

这是一个三角形序列：

y[n]={n+1,0≤n≤N−12N−1−n,N≤n≤2N−20,otherwisey[n] = \begin{cases} n+1, & 0 \leq n \leq N-1 \\ 2N-1-n, & N \leq n \leq 2N-2 \\ 0, & \text{otherwise} \end{cases} y[n]=⎩⎨⎧​n+1,2N−1−n,0,​0≤n≤N−1N≤n≤2N−2otherwise​

例如 N=3N=3N=3 时：

y[n]={1,2,3,2,1},n=0,1,2,3,4y[n] = \{1, 2, 3, 2, 1\}, \quad n=0,1,2,3,4 y[n]={1,2,3,2,1},n=0,1,2,3,4

例题4：利用卷积性质简化计算

已知 x[n]=δ[n]+2δ[n−1]x[n] = \delta[n] + 2\delta[n-1]x[n]=δ[n]+2δ[n−1]，h[n]=3δ[n]−δ[n−2]h[n] = 3\delta[n] - \delta[n-2]h[n]=3δ[n]−δ[n−2]

求 y[n]=x[n]∗h[n]y[n] = x[n] * h[n]y[n]=x[n]∗h[n]

解：

利用分配律和 δ\deltaδ 的卷积性质：

y[n]=(δ[n]+2δ[n−1])∗(3δ[n]−δ[n−2])=3δ[n]∗δ[n]−δ[n]∗δ[n−2]+6δ[n−1]∗δ[n]−2δ[n−1]∗δ[n−2]=3δ[n]−δ[n−2]+6δ[n−1]−2δ[n−3]\begin{aligned} y[n] &= (\delta[n] + 2\delta[n-1]) * (3\delta[n] - \delta[n-2]) \\ &= 3\delta[n]*\delta[n] - \delta[n]*\delta[n-2] + 6\delta[n-1]*\delta[n] - 2\delta[n-1]*\delta[n-2] \\ &= 3\delta[n] - \delta[n-2] + 6\delta[n-1] - 2\delta[n-3] \end{aligned} y[n]​=(δ[n]+2δ[n−1])∗(3δ[n]−δ[n−2])=3δ[n]∗δ[n]−δ[n]∗δ[n−2]+6δ[n−1]∗δ[n]−2δ[n−1]∗δ[n−2]=3δ[n]−δ[n−2]+6δ[n−1]−2δ[n−3]​

所以：

y[n]=3δ[n]+6δ[n−1]−δ[n−2]−2δ[n−3]y[n] = 3\delta[n] + 6\delta[n-1] - \delta[n-2] - 2\delta[n-3] y[n]=3δ[n]+6δ[n−1]−δ[n−2]−2δ[n−3]

七、卷积结果的长度与有效区间

这是手工计算最容易出错的地方，单独拎出来说清楚。

1. 长度规则

设 x[n]x[n]x[n] 非零长度为 LxL_xLx​、h[n]h[n]h[n] 非零长度为 LhL_hLh​，则 y[n]=x[n]∗h[n]y[n] = x[n]*h[n]y[n]=x[n]∗h[n] 的非零长度为

Ly=Lx+Lh−1L_y = L_x + L_h - 1 Ly​=Lx​+Lh​−1

直觉：最前面的非零点只能靠"两者的第一个非零点"对齐产生，最后面的非零点只能靠"两者的最后一个非零点"对齐产生，中间的每个输出点至少有一种配对方式。

2. 有效区间

若 x[n]x[n]x[n] 的非零区间为 [N1,N2][N_1, N_2][N1​,N2​]、h[n]h[n]h[n] 的非零区间为 [M1,M2][M_1, M_2][M1​,M2​]，则 y[n]y[n]y[n] 的非零区间为

[N1+M1,N2+M2][N_1 + M_1, \quad N_2 + M_2] [N1​+M1​,N2​+M2​]

这个区间就是"起始下标相加、结束下标相加"，不用记公式也能推。用它可以直接给例题 1 的结果定界：xxx 在 [0,2][0,2][0,2]、hhh 在 [0,1][0,1][0,1]，则 yyy 在 [0,3][0, 3][0,3]，共 4 点——与表格算出的 {4,13,22,15}\{4,13,22,15\}{4,13,22,15} 一致。

3. 卷积 vs 相关（易混点）

是否翻转 表达式 结果长度
卷积 翻转 ∑kx[k]h[n−k]\sum_k x[k]h[n-k]∑k​x[k]h[n−k] Lx+Lh−1L_x + L_h - 1Lx​+Lh​−1
相关 不翻转 ∑kx[k]y[k−n]\sum_k x[k]y[k-n]∑k​x[k]y[k−n] 同左（也是 Lx+Ly−1L_x + L_y - 1Lx​+Ly​−1）

一句话区分：卷积要"翻"，相关不要"翻"（详见 （四）自相关函数与互相关函数）。自相关可以看成"序列与自己的卷积"，所以长度正好是 2L−12L-12L−1。

八、卷积的计算方法总结

方法 适用场景 特点
图解翻转法 教学理解、短序列 直观，但手工计算慢
表格法 有限长序列 系统化，不易出错
解析法 无限长序列（指数、阶跃） 需要求和公式
性质法 含 δ\deltaδ 的序列 最快，利用卷积性质
FFT法 长序列、工程实现 计算效率高（O(Nlog⁡N)O(N\log N)O(NlogN)）

十、常见错误提醒

  1. 求和区间搞错：一定要正确确定 x[k]x[k]x[k] 和 h[n−k]h[n-k]h[n−k] 的非零区间
  2. 忘记边界：有限长卷积的结果长度 = Lx+Lh−1L_x + L_h - 1Lx​+Lh​−1
  3. 混淆卷积与相关：卷积需要翻转，相关不需要翻转
  4. 符号混淆：x[n]∗h[n]x[n]*h[n]x[n]∗h[n] 中的 ∗*∗ 是卷积运算符，不是乘法

十一、知识链定位

卷积和（本节）

│

├── 定义：y[n] = Σ x[k] h[n-k]（翻转、平移、相乘、求和）

├── 来历：LSI 系统对单位脉冲分解的线性叠加

├── 性质：交换律 / 结合律 / 分配律 / 与 δ 卷积

└── 长度与区间：Ly = Lx + Lh - 1

│

├── 离散时间系统六大性质：卷积的前提是 LSI（第二节）

├── 自相关与互相关：不翻转的"卷积"（第四节）

├── 离散时间系统的各种响应：零状态响应即卷积（第八节）

├── 时域解法：差分方程与卷积两条路（第九节）

├── Z 变换与收敛域：卷积 → 乘法（第十三节）

└── 系统函数 H(z)：H(z) = Y(z)/X(z) 就是卷积定理的产物（后续章节）
