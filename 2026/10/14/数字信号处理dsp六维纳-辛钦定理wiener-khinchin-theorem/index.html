【数字信号处理DSP】（六）维纳-辛钦定理（Wiener-Khinchin Theorem）

维纳-辛钦定理（Wiener-Khinchin Theorem）

标签： #数字信号处理 #DSP #维纳辛钦 #功率谱密度 #自相关 #随机信号

一、为什么需要维纳-辛钦定理？

在之前的文章中我们学过：

  • 能量信号：可以做傅里叶变换（DTFT）分析频谱
  • 功率信号（周期序列、阶跃、白噪声）：能量无限，傅里叶变换不收敛

那么，功率信号的频率特性该如何分析？

答案是：不看频谱，看功率谱密度（PSD）。
而维纳-辛钦定理告诉我们：

功率谱密度 = 自相关函数的傅里叶变换

这条定理的价值在于：它把"求频谱"这件做不到的事，转化成了"求自相关"这件做得到的事。自相关是一个时域的平均量，只要数据够长就能估计出来，不需要信号绝对可和。

更完整的背景见 （四）自相关函数与互相关函数；PSD 的定义、性质与工程估计方法见 （五）功率谱密度。

三、定理为什么成立（推导思路）

不用背，两行就能想通。先从能量信号下手。

若 x[n]x[n]x[n] 能量有限，定义自相关 rxx[m]=∑nx[n]x∗[n−m]r_{xx}[m] = \sum_n x[n]x^*[n-m]rxx​[m]=∑n​x[n]x∗[n−m]，直接对它做 DTFT：

第二个因子是 X∗(ejω)X^*(e^{j\omega})X∗(ejω)（因为 x∗[k]ejωk=(x[k]e−jωk)∗x^*[k] e^{j\omega k} = \left(x[k]e^{-j\omega k}\right)^*x∗[k]ejωk=(x[k]e−jωk)∗），于是

 F{rxx[m]}=X(ejω) X∗(ejω)=∣X(ejω)∣2 \boxed{\ \mathcal{F}\{r_{xx}[m]\} = X(e^{j\omega}) \, X^*(e^{j\omega}) = \lvert X(e^{j\omega}) \rvert^2\ }  F{rxx​[m]}=X(ejω)X∗(ejω)=∣X(ejω)∣2 ​

能量信号的自相关谱恰好是能量谱密度——这就是维纳-辛钦定理的"能量版"，也叫自相关定理。

对功率信号，能量无限，∣X∣2\lvert X \rvert^2∣X∣2 发散，于是改用平均：把信号截断成长度 NNN 的一段，对其自相关除以 NNN，再令 N→∞N \to \inftyN→∞。取极限后得到的就是功率谱密度。所以：

信号类型 自相关的 DTFT 名称

同一把尺子，只差一个归一化。

五、重要性质

性质1：功率谱密度是实的、非负的

Pxx(ejω)≥0,∀ωP_{xx}(e^{j\omega}) \geq 0, \quad \forall \omega Pxx​(ejω)≥0,∀ω

推导：PxxP_{xx}Pxx​ 是共轭偶对称序列 rxx[−m]=rxx∗[m]r_{xx}[-m] = r_{xx}^*[m]rxx​[−m]=rxx∗​[m] 的 DTFT，实部是偶函数、虚部是奇函数；再结合能量/功率的归一化定义，虚部与负值都被排除，最终只剩非负实数。"非负"是功率谱区别于一般频谱的关键特征——它的物理含义是"功率密度"，而功率不可能为负。

性质2：功率谱密度是周期的

Pxx(ej(ω+2π))=Pxx(ejω)P_{xx}(e^{j(\omega + 2\pi)}) = P_{xx}(e^{j\omega}) Pxx​(ej(ω+2π))=Pxx​(ejω)

周期为 2π2\pi2π，这是离散时间信号的固有特性。工程上只需要看 ω∈[−π,π]\omega \in [-\pi, \pi]ω∈[−π,π]（或 [0,2π][0, 2\pi][0,2π]）这一段。

性质3：总平均功率

信号的平均功率等于功率谱密度在一个周期内的积分平均值：

P=rxx[0]=12π∫−ππPxx(ejω)dωP = r_{xx}[0] = \frac{1}{2\pi} \int_{-\pi}^{\pi} P_{xx}(e^{j\omega}) d\omega P=rxx​[0]=2π1​∫−ππ​Pxx​(ejω)dω

这是时域求平均功率与频域求面积的等价表述，也是"功率守恒"的具体形式。

性质4：对称性

对于实信号：

Pxx(ejω)=Pxx(e−jω)P_{xx}(e^{j\omega}) = P_{xx}(e^{-j\omega}) Pxx​(ejω)=Pxx​(e−jω)

即功率谱密度是偶函数，只需要分析 [0,π][0, \pi][0,π] 区间。

性质5：线性系统输出功率谱

若宽平稳信号通过线性时不变系统 H(ejω)H(e^{j\omega})H(ejω)，则输出功率谱为：

Pyy(ejω)=∣H(ejω)∣2 Pxx(ejω)P_{yy}(e^{j\omega}) = \lvert H(e^{j\omega}) \rvert^2 \, P_{xx}(e^{j\omega}) Pyy​(ejω)=∣H(ejω)∣2Pxx​(ejω)

这里只出现幅频特性，不出现相位——因为功率谱本身不含相位信息。工程上做滤波器对噪声的抑制能力分析，全部依赖这个公式。

六、典型例题

例题1：白噪声的功率谱

白噪声的自相关函数：rxx[m]=σ2δ[m]r_{xx}[m] = \sigma^2 \delta[m]rxx​[m]=σ2δ[m]

解：

Pxx(ejω)=∑m=−∞∞σ2δ[m]e−jωm=σ2P_{xx}(e^{j\omega}) = \sum_{m=-\infty}^{\infty} \sigma^2 \delta[m] e^{-j\omega m} = \sigma^2 Pxx​(ejω)=m=−∞∑∞​σ2δ[m]e−jωm=σ2

→ 白噪声的功率谱是常数，在所有频率上功率均匀分布。时域是冲激、频域是常数，正是上一节对偶性的最典型例子。

例题2：一阶AR过程的功率谱

自相关函数：rxx[m]=σ2a∣m∣r_{xx}[m] = \sigma^2 a^{\lvert m \rvert}rxx​[m]=σ2a∣m∣，∣a∣<1\lvert a \rvert \lt 1∣a∣<1

Pxx(ejω)=∑m=−∞∞σ2a∣m∣e−jωmP_{xx}(e^{j\omega}) = \sum_{m=-\infty}^{\infty} \sigma^2 a^{\lvert m \rvert} e^{-j\omega m} Pxx​(ejω)=m=−∞∑∞​σ2a∣m∣e−jωm

把求和拆成正负两半（利用 a∣m∣a^{\lvert m \rvert}a∣m∣ 的偶对称性）：

=σ2(∑m=0∞ame−jωm+∑m=1∞amejωm)=σ2(11−ae−jω+aejω1−aejω)= \sigma^2 \left( \sum_{m=0}^{\infty} a^m e^{-j\omega m} + \sum_{m=1}^{\infty} a^m e^{j\omega m} \right) = \sigma^2 \left( \frac{1}{1 - ae^{-j\omega}} + \frac{ae^{j\omega}}{1 - ae^{j\omega}} \right) =σ2(m=0∑∞​ame−jωm+m=1∑∞​amejωm)=σ2(1−ae−jω1​+1−aejωaejω​)

Pxx(ejω)=σ2(1−a2)1−2acos⁡ω+a2P_{xx}(e^{j\omega}) = \frac{\sigma^2 (1 - a^2)}{1 - 2a\cos\omega + a^2} Pxx​(ejω)=1−2acosω+a2σ2(1−a2)​

例题3：正弦信号的功率谱

x[n]=Asin⁡(ω0n+ϕ)x[n] = A\sin(\omega_0 n + \phi)x[n]=Asin(ω0​n+ϕ)

  1. 强度验证：把 ω0\omega_0ω0​ 与 −ω0-\omega_0−ω0​ 两个冲激都算进积分，12π⋅2⋅πA22=A22\frac{1}{2\pi}\cdot 2\cdot\frac{\pi A^2}{2} = \frac{A^2}{2}2π1​⋅2⋅2πA2​=2A2​，正好等于正弦信号的平均功率 A2/2A^2/2A2/2；

例题4：周期信号的功率谱

解：

即第 kkk 次谐波的功率就是 ∣ck∣2\lvert c_k \rvert^2∣ck​∣2，NNN 条谱线把总功率分完。这就是用 FFT 做谱分析时"谱线高度代表该频率分量功率"的依据。

七、维纳-辛钦定理的使用条件

条件 说明
宽平稳 均值为常数，自相关函数只与延迟 mmm 有关、与时间起点无关
二阶矩有限 rxx[0]=E[∣x[n]∣2]<∞r_{xx}[0] = E[\lvert x[n] \rvert^2] \lt \inftyrxx​[0]=E[∣x[n]∣2]<∞，即平均功率有限
自相关绝对可和 ∑m∣rxx[m]∣<∞\sum_m \lvert r_{xx}[m] \rvert \lt \infty∑m​∣rxx​[m]∣<∞ 时，Pxx(ejω)P_{xx}(e^{j\omega})Pxx​(ejω) 是连续的普通函数

条件 3 不满足时定理仍然成立，只是结果含冲激。周期分量的自相关不衰减，求和发散，此时要用广义傅里叶变换（允许 δ\deltaδ 函数出现在谱里），这正是例题 3、4 处理的情形。

所以准确的表述是：维纳-辛钦定理对宽平稳、有限平均功率的信号普遍成立；自相关绝对可和只是"谱不含冲激"的充分条件，不是定理成立的必要条件。

八、维纳-辛钦定理的应用

  1. 功率谱估计：通过估计自相关函数，再求傅里叶变换得到功率谱（间接法/BT 法）
  2. 信号检测：在噪声中检测周期信号（功率谱中出现尖峰）
  3. 系统分析：输入输出功率谱关系 Pyy=∣H∣2PxxP_{yy} = \lvert H \rvert^2 P_{xx}Pyy​=∣H∣2Pxx​，用于滤波器噪声抑制分析
  4. 系统辨识：白噪声激励下，输入输出互相关正比于冲激响应
  5. 随机信号处理：分析噪声特性、设计最优滤波器（维纳滤波器的出发点就是这条定理）

九、常见错误提醒

  1. 把功率谱当频谱用：频谱 X(ejω)X(e^{j\omega})X(ejω) 保留幅度和相位、可以有负值；功率谱 PxxP_{xx}Pxx​ 只有幅度信息、恒非负。二者不可互换。
  2. 忘记除以 2π2\pi2π：「积分求总功率」时，P=rxx[0]=12π∫PxxdωP = r_{xx}[0] = \frac{1}{2\pi}\int P_{xx} d\omegaP=rxx​[0]=2π1​∫Pxx​dω，这个 12π\frac{1}{2\pi}2π1​ 常被漏掉，结果会差 2π2\pi2π 倍。
  3. 对周期信号用"自相关绝对可和"的条件：周期信号的自相关是周期的，绝对可和条件不满足，但定理依然成立（谱中含冲激），不要因此认为"定理不适用"。
  4. 混淆能量谱与功率谱：能量信号用 ∣X∣2\lvert X \rvert^2∣X∣2；功率信号用 PxxP_{xx}Pxx​。量纲不同（一个是能量/rad，一个是功率/rad）。
  5. 忽略去均值：含直流分量的信号，自相关里含常数项 xˉ2\bar{x}^2xˉ2，会在 ω=0\omega = 0ω=0 处产生虚假冲激。
  6. 正弦信号的冲激强度写成 A2/2A^2/2A2/2：谱里每个冲激的强度是 πA2/2\pi A^2/2πA2/2，不是 A2/2A^2/2A2/2；A2/2A^2/2A2/2 是积分后的功率。差一个 π\piπ 与一个 2π2\pi2π 归一化。
  7. 以为 PSD 一定连续：只有自相关绝对可和时才是连续函数；含周期分量时必定出现冲激。

十、知识链定位

维纳-辛钦定理（本节）

│

├── 定理：Pxx(e^jω) = DTFT{rxx[m]}

├── 推导：能量信号 rxx 的 DTFT = |X(e^jω)|²（自相关定理）

├── 延拓：功率信号取截断平均的极限

└── 适用：宽平稳 + 有限平均功率（含冲激也能用）
