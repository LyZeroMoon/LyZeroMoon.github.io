【数字信号处理DSP】（五）功率谱密度

功率谱密度

标签： #数字信号处理 #DSP #功率谱密度 #PSD #谱估计 #周期图 #Welch

一、为什么需要功率谱密度？

在前面的学习中我们知道：

  • 能量信号：用傅里叶变换分析频谱（幅度谱、相位谱）
  • 功率信号：傅里叶变换不收敛，无法直接分析频谱

那么，如何描述功率信号的频率特性？

功率谱密度（PSD） 就是答案——它描述的是信号功率在频率上的分布。

与下一章的衔接：（六）维纳-辛钦定理 讲的是"为什么 PSD 等于自相关的傅里叶变换"（定理与推导）；本章讲"PSD 是什么、有哪些性质、工程上怎么算出来"（定义与实现）。两章配合看效果最好。

二、功率谱密度的定义

1. 基于维纳-辛钦定理的定义

对于宽平稳随机序列 x[n]x[n]x[n]，其功率谱密度定义为自相关函数的傅里叶变换：

Pxx(ejω)=∑m=−∞∞rxx[m]e−jωmP_{xx}(e^{j\omega}) = \sum_{m=-\infty}^{\infty} r_{xx}[m] e^{-j\omega m} Pxx​(ejω)=m=−∞∑∞​rxx​[m]e−jωm

逆变换：

rxx[m]=12π∫−ππPxx(ejω)ejωmdωr_{xx}[m] = \frac{1}{2\pi} \int_{-\pi}^{\pi} P_{xx}(e^{j\omega}) e^{j\omega m} d\omega rxx​[m]=2π1​∫−ππ​Pxx​(ejω)ejωmdω

2. 基于截断信号的定义（等效定义）

将无限长信号截断为长度为 NNN 的有限段 xN[n]x_N[n]xN​[n]，取其傅里叶变换 XN(ejω)X_N(e^{j\omega})XN​(ejω)，则功率谱密度为：

Pxx(ejω)=lim⁡N→∞1NE[∣XN(ejω)∣2]P_{xx}(e^{j\omega}) = \lim_{N \to \infty} \frac{1}{N} E\left[ \lvert X_N(e^{j\omega}) \rvert^2 \right] Pxx​(ejω)=N→∞lim​N1​E[∣XN​(ejω)∣2]

两种定义等价，前者理论性强（间接法的出发点），后者更贴近实际计算（直接法的出发点）。注意 1N\frac{1}{N}N1​ 与取期望 E[⋅]E[\cdot]E[⋅] 二者缺一不可——少了期望，得到的是无论怎么加长数据都不收敛的"周期图"。

三、功率谱密度的物理意义

上图：灰线是白噪声（功率谱平坦，各频率能量相同）；蓝线是一阶系统的功率谱，能量集中在低频（低通特性）。功率谱描述的是“功率随频率怎么分布”。

1. 功率的频域分布

信号在 [ω,ω+dω] 内的功率=12πPxx(ejω)dω\text{信号在 } [\omega, \omega+d\omega] \text{ 内的功率} = \frac{1}{2\pi} P_{xx}(e^{j\omega}) d\omega 信号在 [ω,ω+dω] 内的功率=2π1​Pxx​(ejω)dω

2. 总平均功率

信号的总平均功率等于功率谱密度曲线下的面积：

P=rxx[0]=12π∫−ππPxx(ejω)dωP = r_{xx}[0] = \frac{1}{2\pi} \int_{-\pi}^{\pi} P_{xx}(e^{j\omega}) d\omega P=rxx​[0]=2π1​∫−ππ​Pxx​(ejω)dω

3. 直观理解

PSD 形状 物理含义
平坦（常数） 功率在所有频率均匀分布 → 白噪声
集中在低频 信号变化缓慢 → 低通特性
集中在高频 信号剧烈变化 → 高通特性
出现尖峰 含有周期成分 → 正弦信号
出现谷（陷波） 该频率被系统抑制 → 存在零点

4. 双边谱与单边谱

上面的定义在 ω∈[−π,π]\omega \in [-\pi, \pi]ω∈[−π,π] 上给出双边谱。实信号的谱是偶函数（性质 3），负频率部分与正频率部分完全重复，所以工程上常只画 ω∈[0,π]\omega \in [0, \pi]ω∈[0,π]，称为单边谱：

P单边(ω)=2Pxx(ejω),0≤ω≤πP_{\text{单边}}(\omega) = 2 P_{xx}(e^{j\omega}), \quad 0 \leq \omega \leq \pi P单边​(ω)=2Pxx​(ejω),0≤ω≤π

乘 2 是为了保住总功率——把负半轴的能量折到正半轴上来。查资料时务必先确认对方用的是单边还是双边，否则功率会差 2 倍（这在实际测试报告中是常见争议来源）。

四、功率谱密度的性质

性质1：非负性

Pxx(ejω)≥0,∀ωP_{xx}(e^{j\omega}) \geq 0, \quad \forall \omega Pxx​(ejω)≥0,∀ω

功率谱密度始终为非负实数。

性质2：周期性

Pxx(ej(ω+2π))=Pxx(ejω)P_{xx}(e^{j(\omega + 2\pi)}) = P_{xx}(e^{j\omega}) Pxx​(ej(ω+2π))=Pxx​(ejω)

周期为 2π2\pi2π，这是离散时间信号的固有特性。

性质3：对称性（实信号）

对于实信号：

Pxx(ejω)=Pxx(e−jω)P_{xx}(e^{j\omega}) = P_{xx}(e^{-j\omega}) Pxx​(ejω)=Pxx​(e−jω)

即功率谱密度是偶函数，只需分析 [0,π][0, \pi][0,π] 区间。

性质4：与幅频特性的关系

若信号通过一个线性时不变系统 H(ejω)H(e^{j\omega})H(ejω)，则输出功率谱为：

Pyy(ejω)=∣H(ejω)∣2Pxx(ejω)P_{yy}(e^{j\omega}) = \lvert H(e^{j\omega}) \rvert^2 P_{xx}(e^{j\omega}) Pyy​(ejω)=∣H(ejω)∣2Pxx​(ejω)

只有幅频特性参与，相位被"平方"掉了。所以滤波器设计中对噪声的抑制能力，完全由 ∣H∣\lvert H \rvert∣H∣ 的阻带衰减决定。

性质5：功率守恒

12π∫−ππPxx(ejω)dω=rxx[0]=E[∣x[n]∣2]\frac{1}{2\pi} \int_{-\pi}^{\pi} P_{xx}(e^{j\omega}) d\omega = r_{xx}[0] = E\left[\lvert x[n] \rvert^2\right] 2π1​∫−ππ​Pxx​(ejω)dω=rxx​[0]=E[∣x[n]∣2]

五、典型例题

例题1：白噪声的PSD

白噪声 w[n]w[n]w[n]，均值为零，方差 σ2\sigma^2σ2

自相关：rww[m]=σ2δ[m]r_{ww}[m] = \sigma^2 \delta[m]rww​[m]=σ2δ[m]

解：

Pww(ejω)=∑m=−∞∞σ2δ[m]e−jωm=σ2P_{ww}(e^{j\omega}) = \sum_{m=-\infty}^{\infty} \sigma^2 \delta[m] e^{-j\omega m} = \sigma^2 Pww​(ejω)=m=−∞∑∞​σ2δ[m]e−jωm=σ2

→ 白噪声的PSD为常数 σ2\sigma^2σ2，在所有频率上功率均匀分布。

例题2：正弦信号的PSD

x[n]=Asin⁡(ω0n+ϕ)x[n] = A \sin(\omega_0 n + \phi)x[n]=Asin(ω0​n+ϕ)

自相关：rxx[m]=A22cos⁡(ω0m)r_{xx}[m] = \frac{A^2}{2} \cos(\omega_0 m)rxx​[m]=2A2​cos(ω0​m)

解：

Pxx(ejω)=πA22[δ(ω−ω0)+δ(ω+ω0)],−π<ω≤πP_{xx}(e^{j\omega}) = \frac{\pi A^2}{2} \left[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)\right], \quad -\pi \lt \omega \leq \pi Pxx​(ejω)=2πA2​[δ(ω−ω0​)+δ(ω+ω0​)],−π<ω≤π

→ 正弦信号的功率集中在 ±ω0\pm\omega_0±ω0​ 两个频率点上。

例题3：一阶AR过程的PSD

x[n]=ax[n−1]+w[n]x[n] = a x[n-1] + w[n]x[n]=ax[n−1]+w[n]，∣a∣<1\lvert a \rvert \lt 1∣a∣<1，w[n]w[n]w[n] 为方差 σw2\sigma_w^2σw2​ 的白噪声

Pxx(ejω)=σw2∣1−ae−jω∣2=σw21−2acos⁡ω+a2P_{xx}(e^{j\omega}) = \frac{\sigma_w^2}{\lvert 1 - a e^{-j\omega} \rvert^2} = \frac{\sigma_w^2}{1 - 2a\cos\omega + a^2} Pxx​(ejω)=∣1−ae−jω∣2σw2​​=1−2acosω+a2σw2​​

→ 当 a>0a \gt 0a>0 时，PSD集中在低频；a<0a \lt 0a<0 时，PSD集中在高频。

这里的"分母 = 系统函数模的平方"不是巧合。把差分方程写成 H(z)=11−az−1H(z) = \frac{1}{1-az^{-1}}H(z)=1−az−11​，白噪声通过这个系统后输出就是 x[n]x[n]x[n]，于是直接套性质 4：

Pxx=∣H(ejω)∣2σw2=σw2∣1−ae−jω∣2P_{xx} = \lvert H(e^{j\omega}) \rvert^2 \sigma_w^2 = \frac{\sigma_w^2}{\lvert 1 - ae^{-j\omega} \rvert^2} Pxx​=∣H(ejω)∣2σw2​=∣1−ae−jω∣2σw2​​

AR 过程的谱 = 白噪声谱 × 系统幅频特性的平方，这是随机信号建模中最常用的推理方式。

例题4：通过系统后的PSD

白噪声 w[n]w[n]w[n]（PSD = σ2\sigma^2σ2）通过一个理想低通滤波器 H(ejω)H(e^{j\omega})H(ejω)：

Pyy(ejω)=∣H(ejω)∣2⋅σ2={σ2,∣ω∣<ωc0,ωc<∣ω∣≤πP_{yy}(e^{j\omega}) = \lvert H(e^{j\omega}) \rvert^2 \cdot \sigma^2 = \begin{cases} \sigma^2, & \lvert \omega \rvert \lt \omega_c \\ 0, & \omega_c \lt \lvert \omega \rvert \leq \pi \end{cases} Pyy​(ejω)=∣H(ejω)∣2⋅σ2={σ2,0,​∣ω∣<ωc​ωc​<∣ω∣≤π​

七、功率谱密度的估计方法（实际应用）

在实际工程中，我们无法获得无限长信号，需要通过有限长数据估计PSD。三类经典方法的关系如下：

graph TD
  D["有限长数据 x[n], n = 0 到 N-1"] --> P1["周期图法（直接法）"]
  D --> P2["自相关法（间接法 / BT 法）"]
  P2 --> P2a["第一步：估计自相关序列"] --> P2b["第二步：对 M 段做 DTFT"]
  P1 --> P1a["N 点 FFT 后取模平方再除以 N"]
  P1a --> W["Welch 法：分段加窗重叠再平均"]
  P2b --> W
  W --> R["方差减小、谱更平滑的估计结果"]

1. 周期图法（直接法）

P^xx(ejω)=1N∣∑n=0N−1x[n]e−jωn∣2\hat{P}_{xx}(e^{j\omega}) = \frac{1}{N} \left\lvert \sum_{n=0}^{N-1} x[n] e^{-j\omega n} \right\rvert^2 P^xx​(ejω)=N1​​n=0∑N−1​x[n]e−jωn​2

优点：计算简单（FFT实现）
缺点：估计方差大，不平滑（加长数据方差不降，这是周期图的著名缺陷）

2. 自相关法（间接法，BT法）

  1. 先估计自相关函数 r^xx[m]\hat{r}_{xx}[m]r^xx​[m]
  2. 再做傅里叶变换得到PSD

P^xx(ejω)=∑m=−MMr^xx[m]e−jωm\hat{P}_{xx}(e^{j\omega}) = \sum_{m=-M}^{M} \hat{r}_{xx}[m] e^{-j\omega m} P^xx​(ejω)=m=−M∑M​r^xx​[m]e−jωm

优点：比周期图法平滑
缺点：分辨率降低（截断到 ±M\pm M±M 相当于加窗，MMM 越小越平滑但峰越胖）

3. Welch法（改进周期图法）

  • 将数据分段，每段加窗（常用汉宁窗）
  • 允许段间重叠（典型 50%）
  • 对各段周期图取平均

这是最常用的现代PSD估计方法。原理很直白：周期图方差大是因为"只测了一次"，把数据切成 KKK 段得到 KKK 个独立估计再平均，方差就降到约 1/K1/K1/K；代价是每段变短、频率分辨率下降。平滑度与分辨率之间的权衡，是谱估计永恒的主题。

九、常见错误提醒

  1. 忘记 1N\frac{1}{N}N1​ 或忘记取期望：少了这两样得到的只是周期图，不是 PSD 的一致估计。
  2. 双边谱与单边谱混用：单边谱 = 双边谱 × 2（ω>0\omega \gt 0ω>0 部分）。看图时先确认纵轴定义，否则功率差 2 倍。
  3. 把 PSD 当作"某个频率上的功率"：PSD 是密度，单位是功率/rad。某频率上的功率只有在它是离散谱线（冲激）时才有确定值，连续谱上只能谈"某带宽内的功率"。
  4. 以为数据越长谱越平滑：周期图的方差与数据长度无关，加长数据只是让谱线更密（分辨率更高），不会让曲线变平滑；要平滑必须做平均。
  5. 算 PSD 前不去均值：直流分量会在 ω=0\omega = 0ω=0 处顶出一个巨大尖峰，把真正的低频谱结构全压扁。先减均值是最省事的一步。
  6. 加窗后忘记补偿能量：加窗会降低总功率（汉宁窗约损失一半），需要按窗函数的能量归一化因子补偿，否则幅值读数偏低。
  7. 用 ∣X∣2\lvert X \rvert^2∣X∣2 分析功率信号：能量信号才有 ∣X∣2\lvert X \rvert^2∣X∣2；对周期信号、白噪声直接套用会发散。
  8. 把 AR 谱当成"真谱"：模型谱是拟合出来的，阶数选错会造出虚假峰或抹掉真实峰。
