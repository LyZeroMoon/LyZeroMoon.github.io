【强化学习RL】（四）贝尔曼方程

贝尔曼方程（Bellman Equation）

标签： #强化学习 #RL #贝尔曼方程 #动态规划 #最优价值

本系列所有可操作实验的入口：强化学习实验室

贝尔曼方程（Bellman Equation） 是强化学习的核心数学工具，它将一个多步决策问题分解为当前步 + 后续步的递归形式。

本质上，它回答了这个问题：

「一个状态（或状态-动作对）的价值，等于当前能立刻获得的奖励，加上接下来所有状态价值的折扣期望。」

一、核心思想：递归分解

贝尔曼方程的核心洞察是：回报（Return）可以拆成两部分：

Gt=Rt+1+γGt+1G_t = R_{t+1} + \gamma G_{t+1} Gt​=Rt+1​+γGt+1​

  • 第一部分 Rt+1R_{t+1}Rt+1​：执行动作后立刻获得的奖励。
  • 第二部分 γGt+1\gamma G_{t+1}γGt+1​：从下一个状态开始，未来所有奖励的折扣总和。

「未来的价值」和「现在的价值」是同一回事，只是往后挪了一步。这就构成了递归。

二、四种常见的贝尔曼方程

根据你关心的对象（状态价值 VVV 或动作价值 QQQ）以及是否追求最优，有四种形式。

2.1 贝尔曼期望方程（Bellman Expectation Equation）—— 针对给定策略 π

方程 公式 含义
VVV 的期望方程 Vπ(s)=∑aπ(a∣s)[R(s,a)+γ∑s′P(s′∣s,a)Vπ(s′)]V^\pi(s) = \sum_a \pi(a\vert s) \big[ R(s,a) + \gamma \sum_{s'} P(s'\vert s,a) V^\pi(s') \big]Vπ(s)=∑a​π(a∣s)[R(s,a)+γ∑s′​P(s′∣s,a)Vπ(s′)] 当前状态值 = 按策略选动作的平均（即时奖励 + 下一状态值）
QQQ 的期望方程 Qπ(s,a)=R(s,a)+γ∑s′P(s′∣s,a)∑a′π(a′∣s′)Qπ(s′,a′)Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\vert s,a) \sum_{a'} \pi(a'\vert s') Q^\pi(s',a')Qπ(s,a)=R(s,a)+γ∑s′​P(s′∣s,a)∑a′​π(a′∣s′)Qπ(s′,a′) 当前动作值 = 即时奖励 + 下一状态所有动作值的平均

2.2 贝尔曼最优方程（Bellman Optimality Equation）—— 针对最优策略 π*

Q∗Q^*Q∗ 的最优方程 Q∗(s,a)=R(s,a)+γ∑s′P(s′∣s,a)max⁡a′Q∗(s′,a′)Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'\vert s,a) \max_{a'} Q^*(s',a')Q∗(s,a)=R(s,a)+γ∑s′​P(s′∣s,a)maxa′​Q∗(s′,a′) 最优动作值 = 即时奖励 + 下一状态最好动作的值

关键区别：

  • 期望方程：对动作取平均（按策略 π\piπ 的概率）。
  • 最优方程：对动作取最大值（选最好的那一个）。

三、同一个方程的几种写法

四、为什么贝尔曼方程如此重要

1. 提供递归结构。 将一个无限步的问题转化为「一步 + 递归」，使得可以用动态规划、TD 学习等方法逐步求解。

2. 自洽性条件。 任何正确的价值函数都必须满足贝尔曼方程。它是验证价值函数是否正确的「黄金标准」。

3. 算法设计的根基。

算法 用哪条方程 怎么用
值迭代 最优方程 直接使用最优贝尔曼方程迭代更新 VVV
策略迭代 期望方程 + 最优方程 先用期望方程评估策略（V=R+γPVV = R + \gamma P VV=R+γPV），再用最优方程改进策略
Q-learning QQQ 的最优方程 使用 QQQ 的最优贝尔曼方程进行离线更新

五、一句话总结

贝尔曼方程 = 「当前价值 = 即时奖励 + 未来价值的折扣期望」，它把整个强化学习问题变成了一个可迭代、可求解的递归结构。

4 道简答题的参考解析

题 13 解析

差别只有一处：∑aπ(a∣s)\sum_a \pi(a\vert s)∑a​π(a∣s) 换成了 max⁡a\max_amaxa​。平均只能评价「按 π\piπ 走会怎样」，取最大直接跳到「最好能怎样」。性质也随之变了：期望方程是线性的，能求逆；最优方程带 max⁡\maxmax，不线性，只能迭代。

题 14 解析

是贝尔曼期望方程的向量写法，对应「给定策略 π\piπ」。用在策略评估：策略定下来，PPP 和 RRR 也就定了，解这个线性方程就得到 VπV^\piVπ。

题 15 解析

当检验标准用。把算出来的 VVV 代回方程右边，如果两边不相等，说明 VVV 算错了，或 PPP、RRR 记错了。迭代算法也正是拿「两边的差」当停止条件——差降到足够小，就认为已经满足方程。

题 16 解析

值迭代直接用最优方程当更新规则；策略迭代两步走，期望方程做策略评估、最优方程做策略改进；Q-learning 用 QQQ 的最优方程更新，max⁡\maxmax 落在下一状态的动作上。
