【网络协议安全】（六）DoS 与 DDoS

DoS 与 DDoS

标签： #网络协议安全 #DoS #DDoS #剧毒包 #流量清洗

对应第 1 章下册 P55–79。只列考点。

一、概念

DoS：攻击者通过某种手段，有意地造成计算机或网络不能正常运转，从而不能向合法用户提供所需服务，或者使服务质量降低。

  • 服务：系统提供的、用户在对其使用中会受益的功能。
  • 拒绝服务：任何对服务的干涉，如果使其可用性降低或失去可用性，就称为拒绝服务。例：计算机系统崩溃、带宽耗尽、硬盘被填满。
  • 三种攻击方式：消耗系统或网络资源、阻断访问路径、更改系统配置。

DDoS：处于不同位置的多个攻击者同时向一个或多个目标发起拒绝服务攻击；或一个/多个攻击者控制了位于不同位置的多台机器，利用这些机器对受害者同时实施拒绝服务攻击。

三个特点：攻击来源的分散性、协同性，攻击力度的汇聚性。

1999 年 11 月，CERT/CC 组织的分布式系统入侵者工具研讨会（DSIT Workshop）上，与会专家首次概括了 DDoS 攻击技术。

二、为什么能成功

三条，缺一不可：

  1. TCP/IP 协议存在漏洞，可以被攻击者利用；
  2. 网络提供 Best-Effort 服务，不区分数据流量是不是攻击流量；
  3. 网络带宽和系统资源是有限的。

这三条正好对应第（二）篇的“尽力而为”与“资源有限”。答题时把“协议有漏洞 + 不区分流量 + 资源有限”写全即可。

分类两个维度：

  • 按攻击协议层：数据链路层、网络层、传输层和应用层；
  • 按攻击协议：SMTP、ICMP、IP、TCP 等。

三、三大类原理

类型 一句话 代表
剧毒包型 一个畸形包就让协议栈崩 WinNuke、Teardrop、Land、Ping of death、循环攻击
风暴型 大量无用包占满资源（又叫带宽攻击） 直接风暴、反射攻击 DRDoS
重定向型 把包引到别处 改 ARP 表、改 DNS 缓存

剧毒包（Killer Packet）：利用协议本身或其软件实现中的漏洞，通过一些畸形的数据包使受害者系统崩溃，也称为“漏洞攻击”或“协议攻击”。PPT 明确说：这些方式虽已过时，但思路仍值得借鉴。

重定向型：通过修改网络中的一些参数，或 ARP 表、DNS 缓存，使受害者发出的、或发向受害者的数据包被重定向到其他地方。它常被用于窃听或中间人攻击，所以很多人不把它当 DoS。注意这句——它算不算 DoS 有争议，答简答时要写出来。

四、剧毒包细节

Teardrop（泪滴 / 碎片攻击）：利用异常的数据分片导致接收方在处理分片时崩溃。

原理：利用 Windows 95/NT/3.1 和低版本 Linux 处理 IP 分片的漏洞，发送偏移地址重叠的 UDP 数据包分片，使目标机器在重组分片时出现异常错误，导致系统崩溃或重启。

正常分片：偏移 0 / 175 / 350，各段首尾相接。攻击分片：第二片的偏移落在第一片内部，重组时长度计算出错（负长度或越界），拷入缓冲区时越界。

两个变种（都靠分片，但目的不同）

变种 目的 原理 防御
小片段攻击 不是 DoS，是穿透防火墙 用很小的片段，让防火墙要检测的信息落到下一个片段里。例：把 TCP 头拆到两片，标志位进入第二片，只按标志位过滤的防火墙找不到标志位就放行 设置分片长度下限，确保第一个分片含所有必需头信息；或检测时先重组，重组后符合规则才放行
分片耗尽 让防火墙 / IDS 拒绝服务 防火墙为检测碎片攻击要缓存分片、等齐再重组；攻击者发大量永远凑不齐的分片，占满其 CPU 与存储 限制重组队列、超时丢弃、限制单源分片数

循环攻击（振荡攻击 / 乒乓攻击）

原理：两个都会产生输出的端口之间建立连接后，第一个端口的输出成为第二个端口的输入，导致第二个端口产生输出；第二个端口的输出又成为第一个端口的输入，如此往复，两端口间产生大量数据包，导致拒绝服务。

典型：Echo Chargen 攻击

  • Chargen（UDP 19）收到一个数据包后，产生一个字符串作为回应；
  • Echo（UDP 7）收到数据包后原样返回；
  • 攻击者向 A 系统的 Echo 端口发一个好像来自 B 系统 Chargen 端口的包（伪造 B 的 IP 与端口），或反向发一个——A、B 两端口间就会来回不停地产生 UDP 包。

防御：用防火墙过滤 19 端口的数据包即可（一句话答案，考到就写这句）。

五、风暴型

原理：通过大量“无用”的数据包占用过多资源，也称为“带宽攻击”。两类：直接风暴型、反射攻击（DRDoS）。

僵尸网络链条：Hacker（黑客）→ Master（主攻手）→ Zombie（僵尸）。准备过程：发现漏洞 → 取得用户权 → 取得控制权 → 植入木马 → 清除痕迹 → 留后门 → 做好攻击准备。危害分三级：骨干级、链路级、应用级——骨干网络资源浪费、链路堵塞、业务中断。

用于攻击的分组三类

  • TCP 洪流（floods）：发大量设置了不同标志的 TCP 分组，常用 SYN、ACK、RST。其中 TCP SYN 攻击使目标主机不断为 TCP 连接分配内存，其他功能分配不到足够内存。
  • ICMP Echo 请求/响应（Ping floods）：发大量 ICMP 分组。
  • UDP 洪流：发大量基于 UDP 的应用协议包，如 NTP、SSDP、DNS——这类既能直接灌，也能做反射放大。

六、防御

一、检测

难点：不容易定位攻击者的位置。

  • Internet 上绝大多数网络不限制源地址，伪造源地址非常容易；
  • 通过攻击代理的攻击，只能找到代理的位置；
  • 各种反射式攻击，无法定位源攻击者。

依据工具特征标志检测：

  • 特定端口：trinoo 用 TCP 27655、UDP 27444 和 31335；NTP DRDoS 检测 123 端口；
  • 标志位：Shaft 攻击所用的 TCP 分组序列号都是 0x28374839；
  • 特定数据内容。

另有统计检测、主机网络连接特征检测。

依据异常流量检测（四条，常考多选）：

  • 明显超出该网络正常工作时极限通信流量的现象（可在主干路由器建 ACL 监测过滤）；
  • 特大型的 ICMP 和 UDP 数据包——很可能是 DDoS 的控制信息；
  • 不属于正常连接通信的 TCP 和 UDP 数据包；
  • 数据段内容只包含文字和数字字符（没有空格、标点、控制字符）——往往是 BASE64 编码后的字符集。

二、防范

  • 限制带宽：限制特定协议占用的带宽，但并不是完善的方法；
  • 终端防御：及时安装厂商补丁、运行尽可能少的服务、增强容忍性；
  • 入口过滤：只允许必要的通信——设置严格的防火墙策略、封锁所有无用的数据。

结论：完全阻止是不可能的，防范可减少被攻击的机会。

三、流量清洗

定义：对 DDoS 攻击流量与正常业务数据混合在一起的流量进行净化，去掉攻击流量、保留正常业务流量，保证业务 7×24 小时不间断。

四个关键环节：攻击监测和判断 → 流量牵引 → 清洗过滤 → 流量回送。

设备角色：Probe 负责攻击检测，Defender 负责流量牵引、攻击防护、流量注入，Datacenter 负责管理呈现；与路由器协调告警，通知黑洞防护。

七、易错辨析

错误说法 判据 反例
“DDoS 就是很多台机器一起 ping” 关键是受控与协同，不是数量 僵尸网络被 Master 统一指挥，才有“汇聚性”
“中毒包攻击已经过时，不用管” PPT 明说思路值得借鉴 Teardrop 的重叠偏移思路，后来变成穿透防火墙的小片段攻击
“Teardrop 靠超大包压垮目标” 它靠分片偏移重叠 每片都不大，是重组时长度算出负数而崩溃
“循环攻击需要两个漏洞” 只需要两个会回应的服务 Echo 与 Chargen 都是正常服务，被互相指认才成攻击
“过滤 7 端口可以防循环攻击” 放大器是 Chargen 过滤 19 端口即可；只封 7 仍可由 Chargen 发起
“重定向型不算 DoS” 定义上它降低可用性，但常归为窃听 改 DNS 缓存把流量引走，业务确实不可用；学界通常放在中间人攻击里讲
“流量清洗就是封 IP” 清洗要保留正常业务 直接封 IP 会误伤同网段正常用户，且攻击者换 IP 即绕过

选择题

判断题

10 道判断题

1. DoS 攻击必须侵入目标主机才能实施。

2. DDoS 的特点是分散性、协同性、汇聚性。

3. DDoS 技术是在 1999 年 11 月的 DSIT Workshop 上首次被概括的。

4. 网络提供 Best-Effort 服务，会区分攻击流量与正常流量。

5. 剧毒包型攻击利用的是协议本身或软件实现中的漏洞。

6. Teardrop 攻击利用的是偏移地址重叠的分片。

7. Xmas 扫描是剧毒包攻击的一种。

8. 循环攻击中，Chargen 服务使用 UDP 19 端口。

9. 防御循环攻击可以用防火墙过滤 19 端口。

10. 流量清洗的四个环节是监测判断、流量牵引、清洗过滤、流量回送。

答案

  1. 错。消耗资源、阻断路径、改配置都能造成拒绝服务，不必入侵。
  2. 对。
  3. 对。CERT/CC 组织的分布式系统入侵者工具研讨会。
  4. 错。Best-Effort 不区分流量性质，这正是 DDoS 能成功的原因之一。
  5. 对。所以又叫“漏洞攻击”或“协议攻击”。
  6. 对。重组时长度计算出错，导致崩溃或重启。
  7. 错。Xmas 是端口扫描（发全 1 标志位探端口），不是剧毒包。
  8. 对。Chargen 19 产生字符串回应，Echo 7 原样返回。
  9. 对。一句话答案就是过滤 19 端口。
  10. 对。

简答题

9 道简答题

1. 写出 DoS 与 DDoS 的定义，并说明 DDoS 的三个特点。

2. DDoS 为什么能成功？

3. DoS 按原理分哪三类？各举一例。

4. 什么是剧毒包攻击？举出五种。

5. 叙述 Teardrop 攻击的原理。

6. 利用分片的攻击有哪两个变种？目的分别是什么？

7. 叙述循环攻击的原理，并说明 Echo Chargen 攻击怎么做、怎么防。

8. DDoS 检测的难点在哪？依据哪些特征检测？

9. DoS 防御分哪三个层面？流量清洗的四个环节是什么？

答案要点

1. DoS：攻击者有意造成计算机或网络不能正常运转，从而不能向合法用户提供服务或使服务质量降低。DDoS：不同位置的多个攻击者同时向一个或多个目标发起 DoS，或一个/多个攻击者控制不同位置的多台机器同时实施。特点：分散性、协同性、汇聚性。

2. ① TCP/IP 协议存在漏洞可被利用；② 网络提供 Best-Effort 服务，不区分流量是否为攻击流量；③ 网络带宽和系统资源有限。

3. 剧毒包型——Teardrop，一个畸形包让协议栈崩溃；风暴型——SYN Flood / 反射放大，大量无用包占满带宽；重定向型——改 ARP 表或 DNS 缓存，把流量引走。

4. 利用协议本身或软件实现中的漏洞，通过畸形数据包使受害者系统崩溃，也叫漏洞攻击、协议攻击。五种：WinNuke、Teardrop、Land、Ping of death、循环攻击。

5. 发送偏移地址重叠的 UDP 数据包分片，第二片的偏移落在第一片内部；目标在重组时按偏移与长度计算出现负长度或越界，拷入缓冲区时出错，导致系统崩溃或重启。影响 Win95/NT/3.1 与低版本 Linux。

6. ① 小片段攻击：目的不是 DoS 而是穿透防火墙——把 TCP 头拆到两片，标志位落到第二片，只检测第一片或只按标志位过滤的防火墙就会放行；② 分片耗尽：发大量永远凑不齐的分片，占满防火墙/IDS 用于重组的 CPU 与存储，造成其拒绝服务。

7. 两个都会产生输出的端口互连后，一方输出成为另一方输入，往复放大。Echo（UDP 7）原样返回，Chargen（UDP 19）收到包就产生字符串；攻击者伪造源地址，让 A 的 Echo 与 B 的 Chargen 互相指认，两端口间来回不停产生 UDP 包。防御：防火墙过滤 19 端口。

8. 难点：Internet 上多数网络不限制源地址，伪造容易；经代理的攻击只能找到代理；反射攻击无法定位真实源。检测依据：工具特征（trinoo 的 TCP 27655、UDP 27444/31335，Shaft 序列号 0x28374839，特定数据内容）、统计特征、主机连接特征、异常流量（超极限流量、特大 ICMP/UDP 包、非正常连接、Base64 字符集内容）。

9. 检测、防范、流量清洗。防范：限制带宽、终端防御（打补丁、少开服务、增强容忍性）、入口过滤（严格防火墙策略、封锁无用数据）；完全阻止不可能。清洗四环节：监测判断、流量牵引、清洗过滤、流量回送。

一句话总结：三种原理一句话——一个包弄崩（剧毒包）、一堆包占满（风暴）、把包引走（重定向）；防御一句话——检测难在溯源，防范靠补丁与过滤，最后靠清洗四环节。
