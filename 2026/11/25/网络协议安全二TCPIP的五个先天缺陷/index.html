【网络协议安全】（二）TCP/IP 的五个先天缺陷

TCP/IP 的五个先天缺陷

标签： #网络协议安全 #TCPIP #IP欺骗 #分组交换 #DDoS

对应第 1 章上册 P30–35。只列考点。

# 考点 考法
1 设计初衷与安全缺陷的因果关系 简答（必考）
2 五个问题的名称与顺序 填空、简答
3 每个问题的机制与对应攻击 简答
4 分组交换为何比电路交换更易受攻击 简答
5 IP 欺骗为何可行、为何难追 简答
6 尽力而为与 DDoS 的关系 简答

一、设计初衷

Internet 的设计目的是在各科研机构之间共享资源。为了尽可能方便计算机之间的互连与资源共享，对安全性考虑较少，因此存在一些固有的安全缺陷——即一些容易被攻击者利用的特性。

因果链一句话：资源共享优先 → 互连尽量简单 → 认证与追踪被省掉 → 缺陷是设计取舍的结果，不是实现 bug。

这是简答的落脚点：五个问题都能追到“为了方便共享而省掉的东西”。

二、问题一：资源共享与分组交换

两个子问题：

  • 公开服务必须可见。潜在的受害者（如 Web 服务器）为了提供公开服务，必须与 Internet 连接且对公众开放；这种可见性通过全球可路由的 IP 地址实现。→ 攻击者先找得到你。
  • 分组交换本身更脆弱。与电信网（电路交换）相比：路由分散决策、流量无序；攻击数据包在被判断是否恶意之前就已经被转发到受害者。→ 很容易被 DoS 攻击。
电路交换（电信网） 分组交换（Internet）
路径 连接建立时确定，独占 逐包独立选路
决策 集中、有序 分散、无序
能否事前拒绝 链路建立前可拒绝 转发之后才可能被识别
安全后果 难注入 易 DoS、易注入伪造包

三、问题二：认证与可追踪性

  • 没有认证机制：任何一个终端接入即可访问全网（电信网不是）。后果是 IP 欺骗——攻击者可以伪造数据包中任何区域的内容，然后发到 Internet 中。
  • 不可追踪：通常情况下路由器不具备数据追踪功能（不保持连接记录）。原因是路由器为无状态转发：转发只需查表，逐包保存记录会带来无法承受的存储与处理开销。
  • 所以没有现实的方法验证一个数据包是否来自于它所声称的地方；攻击者通过 IP 欺骗隐藏来源，就能发起攻击而不必为后果负责。

这一条是后面所有“伪造源地址”攻击（SYN Flood、Smurf、反射放大）的共同前提。

四、问题三、四：尽力而为与匿名

问题三：尽力而为（best-effort）

  • 网络不承诺带宽、时延、顺序；把资源分配与公平性完全寄托在终端的自律上是不现实的。
  • 所有用户共享所有资源，给一个用户的服务会受到其他用户的影响。→ DDoS 利用的正是这一点：不必攻破你，只要把共享资源占满。

问题四：匿名与隐私

  • IP 地址具有双重性：它既是定位标识（路由要用），又被当作身份标识（服务用它认人）。
  • 普通用户无法知道对方的真实身份，也无法拒绝来路不明的信息（如邮件）→ 冒充、抵赖。
  • 应对思路：终端名字与地址分离。
  • PPT 上那句名言：On the Internet, nobody knows you are a dog——没人知道你是一条狗。地址看得见，身份不可信，这就是匿名问题的全部。

五、问题五：对全球网络基础设施的依赖

全球网络基础设施不提供可靠性、安全性保证，这让攻击者可以放大攻击效力：

  • 协议设计不恰当：一些（尤其是畸形的）数据包比其他包耗费更多资源。例：TCP SYN 包比普通 TCP 包占用的目标资源更多——要分配 TCB、进半连接队列。
  • Internet 是一个大“集体”：其中有很多不安全的系统，可被征用为跳板、僵尸。

六、易错辨析

错误说法 判据 反例
“这些缺陷是 TCP/IP 实现有 bug” 缺陷来自设计取舍 无状态转发是路由器性能的前提，不是写错了
“分组交换更安全，因为路径不固定” 路径不固定＝无法预置过滤，也＝无法追踪 攻击包照样到达受害者，只是到达后才可能被识别
“路由器不记录连接是因为存储小” 是架构上的无状态设计 存储再大，逐包记录也会拖垮转发性能
“IP 欺骗能伪造源地址，所以能冒充任何人” 伪造只解决“看起来从哪来” 回包发往被伪造的地址，攻击者收不到，三次握手完不成
“DDoS 必须攻破目标主机” 攻击的是共享资源 带宽、连接表被占满即可，主机本身没被入侵

选择题

判断题

对错先写在纸上，再展开对答案。

10 道判断题

1. Internet 的安全缺陷主要来自协议实现中的编程错误。

2. 分组交换采用路由分散决策，因此流量是无序的。

3. 攻击数据包在到达受害者之前一定先被判断为恶意。

4. Internet 没有认证机制，任何终端接入即可访问全网。

5. 路由器不保存连接记录，是导致攻击难以追踪的原因之一。

6. 尽力而为的含义是网络保证每个用户获得相同带宽。

7. IP 地址既是定位标识，也被当作身份标识使用。

8. 终端名字与地址分离的提出，是为了解决匿名带来的冒充与抵赖。

9. TCP SYN 包与普通 TCP 包消耗的目标资源相同。

10. 电路交换的缺点是带宽固定、网络资源利用率低。

答案

  1. 错。是设计初衷带来的固有缺陷（为共享而牺牲安全），不是实现 bug。
  2. 对。路由分散决策，各路由器独立选路，流量无序。
  3. 错。分组交换下，攻击包在被判断为恶意之前就已经转发到受害者。
  4. 对。这正是问题二的前提，也是 IP 欺骗可行的根本原因。
  5. 对。无记录就无法回溯来源，无法验证数据包是否来自其所声称的地方。
  6. 错。尽力而为是不承诺带宽与时延，资源靠抢占，用户之间互相影响。
  7. 对。双重性正是匿名问题的根源：定位用的地址被当成了身份。
  8. 对。名字标识身份、地址标识位置，分离后地址不再冒充身份。
  9. 错。SYN 要分配 TCB、进半连接队列，比普通 TCP 包占用更多资源。
  10. 对。优点是时延小、透明传输。

填空题

16 道填空题

1. Internet 的设计目的是在各科研机构之间 ______。

2. 五个问题依次是：资源共享与分组交换、、尽力而为、、对全球网络基础设施的依赖。

3. 公开服务的可见性通过 ______ 实现。

4. 分组交换的两条脆弱性：路由分散决策导致 ______；攻击包在 ______ 之前就已被转发。

5. 电信网采用 ______ 交换，Internet 采用 ______ 交换。

6. 电路交换的优点：、；缺点：______。

7. 分组交换的优点：；缺点：。

8. 由于没有认证机制，Internet 上出现了 ______ 攻击。

9. 路由器通常不具备 ______ 功能，因此没有现实方法验证数据包的来源。

10. 尽力而为策略把网络资源的分配与公平性寄托在 ______ 上。

11. IP 地址的双重性指：既是 ______，又被当作 ______。

12. 针对匿名问题提出的新体系是 ______ 与 ______ 分离。

13. 畸形包能放大攻击效力，典型例子是 ______ 包比普通 TCP 包占用更多目标资源。

14. Internet 是很多 ______ 系统组成的大集体，可被征用为跳板。

15. 电路交换的“透明传输”指 ______。

16. 五个问题的共同根源是设计时 ______。

答案

  1. 共享资源。
  2. 认证与可追踪性；匿名与隐私。
  3. 全球可路由的 IP 地址。
  4. 流量无序；被判断是否恶意。
  5. 电路；分组。
  6. 时延小；透明传输；带宽固定、资源利用率低。
  7. 多路复用、资源利用率高；实时性差。
  8. IP 欺骗。
  9. 数据追踪（保持连接记录）。
  10. 终端的自律。
  11. 定位标识；身份标识。
  12. 终端名字；地址。
  13. TCP SYN。
  14. 不安全。
  15. 传输过程中不对用户数据做任何处理，原样送达。
  16. 对安全性考虑较少（共享优先）。

简答题

9 道简答题

1. 说明 TCP/IP 安全缺陷与设计初衷的因果关系。

2. 列出因特网的五个固有问题。

3. 为什么说分组交换比电路交换更容易受到攻击？

4. 说明问题一的两个子问题，并各举一种对应攻击。

5. 解释 IP 欺骗为什么可行，又为什么难以追责。

6. 路由器为什么不保持连接记录？

7. 尽力而为策略为什么会导致 DDoS？

8. 什么是 IP 地址的双重性？它带来什么问题？有何应对思路？

9. 问题五如何“放大攻击效力”？举两个方面的例子。

答案要点

1. 目的是科研机构之间共享资源，因此设计上尽量方便互连与共享、对安全考虑较少；共享要求公开可达与无认证接入，于是产生了公开可见、可伪造来源、资源被抢占等固有缺陷。结论：这些缺陷是设计取舍的结果，不是实现错误。

2. ① 资源共享与分组交换；② 认证与可追踪性；③ 尽力而为；④ 匿名与隐私；⑤ 对全球网络基础设施的依赖。

3. 电路交换在建立连接时就确定了独占路径，链路建立前可以拒绝；分组交换路由分散决策、流量无序，每个包独立转发，攻击包在被判断是否恶意之前就已经被转发到受害者，因此既难事前拦截也难事后追踪。

4. ① 公开服务必须可见：为提供公开服务必须连网并对公众开放，可见性靠全球可路由 IP 实现——对应主机扫描、端口扫描等侦查。② 分组交换脆弱：路由分散、流量无序、先转发后判断——对应 DoS / DDoS。

5. 可行：Internet 没有认证机制，任何终端接入即可访问全网，数据包首部的任何区域都可被伪造。难追：路由器不保持连接记录、不做追踪，没有现实方法验证数据包是否来自其所声称的地方，攻击者可隐藏来源而不担责。

6. 路由器是逐包无状态转发的设备，转发只需查路由表；为每个包保存连接记录会带来无法承受的存储与处理开销，也无法扩展到骨干速率。

7. 尽力而为不承诺带宽、时延与公平性，所有用户共享所有资源、互相影响；资源分配靠终端自律，而攻击者不会自律，只要把带宽、连接表等共享资源占满，合法用户就得不到服务——不需要攻破主机。

8. 双重性：IP 地址既是定位标识（路由必须用），又被应用当作身份标识。问题：普通用户无法知道对方真实身份，也无法拒绝来路不明的信息，导致冒充与抵赖。思路：终端名字与地址分离，名字标识身份、地址标识位置。

9. ① 协议设计不恰当，畸形包比正常包耗资源更多，如 TCP SYN 包要分配 TCB、占半连接队列；② Internet 由大量不安全系统组成，攻击者可批量征用为跳板与僵尸，把单点攻击放大为分布式攻击。

一句话总结：五个问题都是“为共享而省掉安全”的结果——公开可达、无认证、先转发后判断、资源靠抢、地址当身份；记住“五个名字 + 每条对应一种攻击”，简答就够用了。
