【强化学习RL】（六）蒙特卡洛

蒙特卡洛（Monte Carlo）

标签： #强化学习 #RL #蒙特卡洛 #无模型 #采样

本系列所有可操作实验的入口：强化学习实验室

一、核心思想

上一章能把 VVV 算出来，是因为 PPP、RRR 都在手上；这两样拿不到，那条式子一个数都算不出来。本章换掉的就是这个前提。

蒙特卡洛方法的核心非常简单：用大量实际采样的回报 GtG_tGt​ 的平均值，来近似期望价值。

V(s)≈1N∑i=1NGt(i)V(s) \approx \frac{1}{N} \sum_{i=1}^{N} G_t^{(i)} V(s)≈N1​i=1∑N​Gt(i)​

其中 Gt(i)G_t^{(i)}Gt(i)​ 是第 iii 次访问状态 sss 时，从该状态开始的完整轨迹回报。

二、与动态规划的关键区别

对比维度 动态规划（DP） 蒙特卡洛（MC）
是否需要模型 需要已知 PPP 和 RRR 不需要，只需采样经验
更新方式 自举（用其他状态的估计值更新当前状态） 不自举，用完整的真实回报
数据来源 解析计算 实际交互采样
适用范围 状态空间小、模型已知 模型未知、可仿真交互

三、算法流程（首次访问 MC）

四、首次访问 vs 每次访问

变体 做法 性质
首次访问 MC 每条轨迹中，每个状态只取第一次出现的回报 无偏估计，理论分析方便
每次访问 MC 每条轨迹中，每个状态每次出现都取回报 有偏（轻微），数据利用率更高

那点偏差从哪来：同一条轨迹里同一状态出现两次，两个 GGG 共享后半段路径、彼此不独立；而分母 N(s)N(s)N(s)（访问了几次）本身是随机数。平均除以随机数，期望就不再严格等于真值——样本一多就收敛到同一个值。

五、蒙特卡洛的优点与缺点

优点

  • 无需环境模型：只需要能与环境交互采样。
  • 无偏估计：每次估计都是真实期望的无偏近似。
  • 聚焦于感兴趣的状态：可以只评估某些状态，不必全扫。
  • 不受马尔可夫性限制：即使环境不是严格马尔可夫的，MC 也能工作（它不靠自举，所以受违反的伤害更小）。

缺点

  • 必须等到轨迹结束：无法在轨迹中途更新，学习延迟。
  • 方差大：单条轨迹的回报波动很大，需要大量采样才能稳定。
  • 不适用于持续任务：没有终止状态的任务无法定义完整轨迹。
  • 探索不足：如果策略很少访问某些状态，对这些状态的估计会很差。

六、MC 策略评估的公式表达

给定策略 π\piπ，蒙特卡洛方法通过采样来近似 Vπ(s)V^\pi(s)Vπ(s)：

Vπ(s)=Eπ[Gt∣St=s]≈1N(s)∑i=1N(s)Gt(i)V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] \approx \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_t^{(i)} Vπ(s)=Eπ​[Gt​∣St​=s]≈N(s)1​i=1∑N(s)​Gt(i)​

也可以写成增量更新形式（便于在线学习）：

V(s)←V(s)+α[Gt−V(s)]V(s) \leftarrow V(s) + \alpha \left[ G_t - V(s) \right] V(s)←V(s)+α[Gt​−V(s)]

其中 α\alphaα 是学习率，Gt−V(s)G_t - V(s)Gt​−V(s) 是蒙特卡洛误差。

七、MC 控制（寻找最优策略）

将 MC 用于控制（同时评估和改进策略）时，需要解决探索问题。注意统计对象也换了：改进策略要比较同一个 sss 下的不同动作，而 V(s)V(s)V(s) 已经按 π\piπ 把动作平均掉了，所以控制阶段估的是 Q(s,a)Q(s,a)Q(s,a)，一对 (s,a)(s,a)(s,a) 一个格子。

同策略 MC 控制（On-policy MC）

  • 使用 ε\varepsilonε-贪心策略：以 1−ε1-\varepsilon1−ε 概率选最优动作，ε\varepsilonε 概率随机选。
  • 评估和改进的是同一个策略。

异策略 MC 控制（Off-policy MC）

  • 行为策略（Behavior Policy）：负责探索，生成数据。
  • 目标策略（Target Policy）：我们要优化的策略。
  • 使用重要性采样修正分布偏差。

九、直观类比

蒙特卡洛方法就像：你想知道一家餐厅的平均水平。

  • 你不去查菜谱和厨房流程（不建模 PPP 和 RRR）。
  • 而是亲自去吃很多次，每次吃完记录总分（回报 GtG_tGt​）。
  • 吃了足够多次后，把所有分数平均，就是你对这家餐厅的评价（V(s)V(s)V(s)）。

缺点也很形象：你必须每次都吃完一整顿饭才能给分（需要完整轨迹），而且偶尔遇到特别好吃或特别难吃的一餐，会让你的评价波动很大（方差高）。

十、一句话总结

蒙特卡洛方法 = 用大量完整轨迹的回报平均值，无模型地估计价值函数；优点是简单无偏，缺点是必须等轨迹结束且方差大。

下一篇把「整条轨迹的回报」换成「一步奖励 + 下一状态的估计」——走一步就能更新。

附：方差到底有多大（拖一下就知道）

某个状态的回报只有两种可能：一半概率 0，一半概率 10。

  • 真值 V(s)=5V(s) = 5V(s)=5，单条回报的标准差 σ=5\sigma = 5σ=5。
  • 采两条恰好是 0 和 10，平均 5——看起来完美，但这只是碰巧。
  • 只采一条，估值要么 0 要么 10，误差 5。
  • 想让估值稳在 ±0.5\pm 0.5±0.5 以内，需要 σ/N≤0.5\sigma/\sqrt{N} \le 0.5σ/N​≤0.5，也就是 N≥100N \ge 100N≥100 条轨迹。

这就是「无偏但方差大」的全部含义：平均下来不歪，采得少时落在哪全看运气。
