# 贝尔曼方程（Bellman Equation）

**标签：** #强化学习 #RL #贝尔曼方程 #动态规划 #最优价值

> 本系列所有可操作实验的入口：[强化学习实验室](/rl/)

---

**贝尔曼方程（Bellman Equation）** 是强化学习的核心数学工具，它将一个多步决策问题分解为**当前步 + 后续步**的递归形式。

本质上，它回答了这个问题：

> 「一个状态（或状态-动作对）的价值，等于当前能立刻获得的奖励，加上接下来所有状态价值的折扣期望。」

## 一、核心思想：递归分解

贝尔曼方程的核心洞察是：回报（Return）可以拆成两部分：

$$
G_t = R_{t+1} + \gamma G_{t+1}
$$

- 第一部分 $R_{t+1}$：执行动作后立刻获得的奖励。
- 第二部分 $\gamma G_{t+1}$：从下一个状态开始，未来所有奖励的折扣总和。

「未来的价值」和「现在的价值」是同一回事，只是往后挪了一步。这就构成了递归。

## 二、四种常见的贝尔曼方程

根据你关心的对象（状态价值 $V$ 或动作价值 $Q$）以及是否追求最优，有四种形式。

### 2.1 贝尔曼期望方程（Bellman Expectation Equation）—— 针对给定策略 π

| 方程 | 公式 | 含义 |
|---|---|---|
| $V$ 的期望方程 | $V^\pi(s) = \sum_a \pi(a|s) \big[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s') \big]$ | 当前状态值 = 按策略选动作的平均（即时奖励 + 下一状态值） |
| $Q$ 的期望方程 | $Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s') Q^\pi(s',a')$ | 当前动作值 = 即时奖励 + 下一状态所有动作值的平均 |

### 2.2 贝尔曼最优方程（Bellman Optimality Equation）—— 针对最优策略 π*

| 方程 | 公式 | 含义 |
|---|---|---|
| $V^*$ 的最优方程 | $V^*(s) = \max_a \big[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \big]$ | 最优状态值 = 选最好的动作（即时奖励 + 下一状态最优值） |
| $Q^*$ 的最优方程 | $Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a')$ | 最优动作值 = 即时奖励 + 下一状态最好动作的值 |

**关键区别：**

- 期望方程：对动作取**平均**（按策略 $\pi$ 的概率）。
- 最优方程：对动作取**最大值**（选最好的那一个）。

## 三、同一个方程的几种写法

2.1 表里那条 $V$ 的期望方程，常见五种写法。它们是同一个式子的不同排法，不是五个不同的方程。

| 写法 | 公式 | 什么时候用 |
|---|---|---|
| 定义式 | $V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$ | 只给定义，还没有递归，算不出数 |
| 期望简写 | $V^\pi(s) = \mathbb{E}_\pi\big[R(s,a) + \gamma V^\pi(s')\big]$ | 理论推导，把两层求和藏进 $\mathbb{E}$ |
| 合并求和 | $V^\pi(s) = \sum_a \pi(a|s) \big[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')\big]$ | 最原始的递归式，就是 2.1 第一行 |
| 拆成两条 | $V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)$，$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')$ | 讲清 $V$ 与 $Q$ 的关系，第 8 篇的起点 |
| 矩阵 | $\mathbf{V}^\pi = \mathbf{R}^\pi + \gamma \mathbf{P}^\pi \mathbf{V}^\pi$ | 动态规划、求逆、证明解唯一 |

矩阵式里那两个量，是「合并求和」那一行把动作平均掉的结果：

$$
\mathbf{R}^\pi(s) = \sum_a \pi(a|s) R(s,a), \qquad
\mathbf{P}^\pi(s, s') = \sum_a \pi(a|s) P(s'|s,a)
$$

第三篇那个 $V = (I - \gamma P)^{-1} R$ 就建在这条式子上；当时 $R^\pi$、$P^\pi$ 怎么来的没说，这里补上。

**不用背五个。** 记住 2.1 那一行就够，其余都是它的排法：把 $\sum_a \pi$ 和 $\sum_{s'} P$ 写全 = 合并求和；用 $\mathbb{E}_\pi$ 盖住 = 期望简写；给中括号里那部分起个名字叫 $Q$ = 拆成两条；把 $V$ 摞成向量 = 矩阵。

**最优方程形状完全相同**，只把 $\sum_a \pi(a|s)$ 换成 $\max_a$：

$$
V^*(s) = \max_a \big[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\big]
$$

这是 2.2 里的那条，不是第六种写法。

## 四、为什么贝尔曼方程如此重要

**1. 提供递归结构。** 将一个无限步的问题转化为「一步 + 递归」，使得可以用动态规划、TD 学习等方法逐步求解。

**2. 自洽性条件。** 任何正确的价值函数都必须满足贝尔曼方程。它是验证价值函数是否正确的「黄金标准」。

**3. 算法设计的根基。**

| 算法 | 用哪条方程 | 怎么用 |
|---|---|---|
| 值迭代 | 最优方程 | 直接使用最优贝尔曼方程迭代更新 $V$ |
| 策略迭代 | 期望方程 + 最优方程 | 先用期望方程评估策略（$V = R + \gamma P V$），再用最优方程改进策略 |
| Q-learning | $Q$ 的最优方程 | 使用 $Q$ 的最优贝尔曼方程进行离线更新 |

## 五、一句话总结

> 贝尔曼方程 = 「当前价值 = 即时奖励 + 未来价值的折扣期望」，它把整个强化学习问题变成了一个可迭代、可求解的递归结构。

<details class="ly-fold">
<summary>4 道简答题的参考解析</summary>

**题 13 解析**

差别只有一处：$\sum_a \pi(a|s)$ 换成了 $\max_a$。平均只能评价「按 $\pi$ 走会怎样」，取最大直接跳到「最好能怎样」。性质也随之变了：期望方程是线性的，能求逆；最优方程带 $\max$，不线性，只能迭代。

**题 14 解析**

是贝尔曼期望方程的向量写法，对应「给定策略 $\pi$」。用在策略评估：策略定下来，$P$ 和 $R$ 也就定了，解这个线性方程就得到 $V^\pi$。

**题 15 解析**

当检验标准用。把算出来的 $V$ 代回方程右边，如果两边不相等，说明 $V$ 算错了，或 $P$、$R$ 记错了。迭代算法也正是拿「两边的差」当停止条件——差降到足够小，就认为已经满足方程。

**题 16 解析**

值迭代直接用**最优方程**当更新规则；策略迭代两步走，**期望方程**做策略评估、**最优方程**做策略改进；Q-learning 用 **$Q$ 的最优方程**更新，$\max$ 落在下一状态的动作上。
