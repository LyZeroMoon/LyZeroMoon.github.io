## 一、判断公式

离散时间序列 `x[n]` 为**周期序列**的条件是：

> 存在正整数 N，使得对所有 n 满足：**x[n+N] = x[n]**

最小的正整数 N 称为**基本周期**。

---

## 二、不同类型序列的周期判断

### 1️⃣ 正弦序列 x[n] = A·sin(ω₀n + φ)

**判断方法**：
- 计算 ω₀ / 2π
- 若结果为**有理数** → 周期序列
- 若结果为**无理数** → 非周期序列

**周期计算公式**：
- N = 2π / ω₀ （结果化为最简整数）
---
**示例1**：x[n] = sin(πn/4)
- ω₀ = π/4
- ω₀/2π = (π/4)/(2π) = 1/8 → 有理数 ✅
- 周期 N = 2π/(π/4) = 8

**示例2**：x[n] = sin(3n)
- ω₀ = 3
- ω₀/2π = 3/(2π) ≈ 0.477 → 无理数 ❌
- **非周期序列**

---

### 2️⃣ 复指数序列 x[n] = e^(jω₀n)

**判断方法**：与正弦序列完全相同

- ω₀/2π 为有理数 → 周期序列，N = 2π/ω₀
- ω₀/2π 为无理数 → 非周期序列

**示例3**：x[n] = e^(jπn/3)
- ω₀ = π/3
- ω₀/2π = 1/6 → 有理数 ✅
- 周期 N = 6

**示例4**：x[n] = e^(jn)
- ω₀ = 1
- ω₀/2π = 1/(2π) → 无理数 ❌
- **非周期序列**

---

### 3️⃣ 多个正弦相加的序列

**判断方法**：
- 分别求出每个分量的周期 N₁, N₂, ...
- 若所有分量周期之比为有理数 → 整体周期为各周期的最小公倍数（LCM）
- 若存在无理数比例 → 非周期

**示例5**：x[n] = sin(πn/3) + cos(πn/4)
- 第一项：ω₁=π/3 → N₁=6
- 第二项：ω₂=π/4 → N₂=8
- LCM(6,8)=24 → **周期 N=24** ✅

**示例6**：x[n] = sin(πn/3) + sin(n)
- 第一项：N₁=6
- 第二项：非周期 ❌
- **整体非周期**

---

### 4️⃣ 实指数序列 x[n] = aⁿ

**结论**：实指数序列**永远不是周期序列**（除非 a=0 或 a=1 的平凡情况）

因为指数函数是单调的，不可能满足 x[n+N] = x[n]。

## 五、一句话总结

> **正弦/复指数序列：ω₀/2π 为有理数 ⇔ 周期序列**
