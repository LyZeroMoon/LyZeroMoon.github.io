## 一、802.11 协议族

**为什么要用 WLAN**：让网络使用更自由；让建设更经济、通信更便利；让工作更高效。

**协议族的两个部分**：

| 部分 | 成员 |
|---|---|
| PHY（物理层） | 802.11（1/2 Mbps）、802.11b（5.5/11）、802.11a（54）、802.11g（54）、802.11n（300） |
| MAC（补充标准） | 802.11e—QoS、**802.11i—安全增强**、802.11f—漫游和切换、802.11h—动态调整、802.11s—mesh |

**四个主标准对比**（考填空题的高发区）：

| 项目 | 802.11 | 802.11b | 802.11a | 802.11g |
|---|---|---|---|---|
| 发布 | 1997.7 | 1999.9 | 1999.9 | 2003.6 |
| 合法频宽 | 83.5 MHz | 83.5 MHz | **325 MHz** | 83.5 MHz |
| 频率范围 | 2.400–2.483 GHz | 2.400–2.483 GHz | **5.15–5.35、5.725–5.85 GHz** | 2.400–2.483 GHz |
| 非重叠信道 | 3 | 3 | **12** | 3 |
| 物理速率（Mbps） | 1、2 | 1、2、5.5、11 | 6–54 | 6–54 |
| 与 11b 相容 | — | — | **不能互通** | 可互通 |

三条结论：**2.4 GHz 频段只有 3 个非重叠信道**，5 GHz 有 12 个；802.11a 与 11b/g **不能互通**（频段不同）；11g 与 11b 可互通。

## 二、网络基本元素

| 术语 | 含义 |
|---|---|
| **SSID** | Service Set ID，服务集识别码，即无线网络的名字 |
| **STA** | Station，任何无线终端设备 |
| **AP** | Access Point，接入点 |
| **BSS** | Basic Service Set，基本服务集，一个 AP 及其关联的 STA |
| **ESS** | Extended Service Set，扩展服务集，**采用相同 SSID 的多个 BSS** 形成的更大规模虚拟 BSS |
| **DS** | Distribution System，分布式系统，连接多个 AP 的骨干 |
| **Ad Hoc** | 无线自组织网络，STA 之间**直接互连**、共享资源，**无需 AP** |

记住 ESS 的定义句式："相同 SSID 的多个 BSS"。这是名词解释的标准答案。

## 三、接入四步与扫描

**MAC 层用户接入管理过程，固定四步**：

| 步骤 | 名称 | 干什么 |
|---|---|---|
| 1 | **Scanning** | 发现网络，找到可连的 AP |
| 2 | **Authentication** | 身份认证 |
| 3 | **Association** | 关联，加入 BSS |
| 4 | 数据收发（加密） | 开始传数据 |

顺序不能换：**先扫描、再认证、后关联、最后传数据**。

**Scanning 的两种方式**：

| 方式 | 做法 | 特点 |
|---|---|---|
| **Passive Scanning** | STA 侦听 AP 定期发送的 **Beacon 帧** | **找到时间较长，但 STA 节电** |
| **Active Scanning** | STA 在每个信道上发送 **Probe request**，从 AP 回的 **Probe response** 中取 SSID | **能迅速找到** |

**Passive 为什么省电**：全程只收不发，射频不用发射。**Active 为什么快**：主动问，不用等 Beacon 周期。

## 四、CSMA/CA

**全称**：带**冲突避免**的载波侦听多路访问。与有线网的 CSMA/CD 只差一个词，机制完全不同：

**工作方式两条**：

1. 送出数据前监听媒体状态，确定没人使用，**维持一段时间**，再**等待一段随机时间**后，依然无人使用才送出数据；
2. 送出数据前，先发送**请求传送报文 RTS** 给目标端，等待目标端回应 **CTS** 后，才开始传送。

**为什么无线不能"边发边听"（CSMA/CD 用不了）**：

| 原因 | 说明 |
|---|---|
| 无法边发边收 | 无线射频半双工，发射时收不到，冲突检测不到 |
| 隐藏终端 | A 与 C 都听不到对方，却都能到 B，冲突发生在**接收端**而不是发送端 |
| 冲突代价高 | 没有冲突检测，只能靠**避免** |

所以无线用"**先约好再发**"（RTS/CTS + 随机退避）代替"发了再检测"。

**RTS / CTS 的利弊**：

| | 内容 |
|---|---|
| 缺点 | 网络的效率下降（多了两次握手） |
| 优点 | 两种控制帧都很短，**开销小**；若不用，一旦冲突导致数据帧重发，浪费的时间**更大** |

## 五、恶意接入点与隐藏 SSID

**恶意 AP 的两种来源**：

| 类型 | 做法 | 危害 |
|---|---|---|
| **伪造 AP**（钓鱼） | 放大无线信号、用**相同的 SSID**（如 "CMCC"、"UCAS"） | 客户端探测软件误以为它是合法 AP，用户连上去做网上操作，账号密码全被截获 |
| **内部人员私搭 AP** | 有效用户未经允许安装无线 AP | 使**远处的用户轻易进入内网**，绕过了建筑墙体和边界防护 |

两类都叫"恶意访问接入点"，区别：前者在**外部冒充**，后者在**内部开口**。

**隐藏 SSID**：把 SSID 不广播，是**最简单方便的保证无线网络安全的手段之一**。做法是办公网用隐藏 SSID（员工手工输入），访客用另一个公开 SSID。

**它为什么只是"之一"**：

1. **Active Scanning 能问出 SSID**——STA 发 Probe request 时带着目标 SSID，抓包即可看到；
2. 客户端连上后，**Beacon 与管理帧里仍有 SSID**；
3. 即便隐藏成功，攻击者只要伪造同名 AP 就能反向钓鱼。

所以隐藏 SSID 是"减少被扫到"，不是"防止被接入"。

## 六、易错辨析

| 错误说法 | 判据 | 反例 |
|---|---|---|
| "无线也用 CSMA/CD" | 无线用 CSMA/**CA** | 射频半双工，无法边发边听 |
| "CSMA/CA 一定能避免冲突" | 只是降低概率 | 隐藏终端仍可能冲突，才需要 RTS/CTS |
| "RTS/CTS 提升效率" | 单看握手是降低效率 | 它的价值在于避免长帧重传，总体可能换算 |
| "802.11a 比 11b 新所以兼容" | 频段不同 | 5 GHz 与 2.4 GHz 不能互通 |
| "BSS 和 ESS 是一回事" | ESS 是相同 SSID 的多个 BSS | 一个 AP 一个 BSS，一层楼多个 AP 才构成 ESS |
| "Ad Hoc 也要 AP" | 不需要 | 终端之间直连 |
| "隐藏 SSID 能防蹭网" | 能被 Probe 问出来 | 抓 Probe request 即得 SSID |
| "2.4 GHz 有 11 个信道就 11 个不重叠" | 只有 3 个不重叠 | 1、6、11 |

### 简答题

<details class="ly-fold">
<summary>9 道简答题</summary>

**1.** 简述 802.11 网络接入的四个步骤。

**2.** 比较 Passive Scanning 与 Active Scanning。

**3.** CSMA/CA 的工作方式是什么？

**4.** 为什么无线网络不能使用 CSMA/CD？

**5.** RTS/CTS 有什么优缺点？

**6.** 802.11b、11a、11g 在频段与速率上有何区别？

**7.** 恶意访问接入点有哪两种来源？各自的危害是什么？

**8.** 隐藏 SSID 的原理是什么？为什么它不能真正防蹭网？

**9.** 区分 SSID、BSS、ESS、DS 四个概念。

---

**答案要点**

**1.** ① Scanning：发现网络、找到可接入的 AP；② Authentication：身份认证；③ Association：关联到 BSS；④ 数据收发（加密）。顺序固定，关联必须在认证之后。

**2.** Passive：STA 只侦听 AP 定期发的 Beacon 帧来发现网络，全程不发射，所以节电，但需要等 Beacon 周期，**找到时间长**。Active：STA 在每个信道主动发 Probe request，AP 回 Probe response 告知 SSID，**能迅速找到**，代价是耗电且暴露自己的探测意图。

**3.** 发送前先监听媒体：确认空闲后维持一段时间，再等一个随机时间，仍然空闲才发。为避免冲突，可先发 RTS、收到对方 CTS 后再发数据；收到确认才认为成功，否则退避重发。

**4.** 三点：无线射频半双工，发射时无法接收，检测不到冲突；存在隐藏终端，两个站点互相听不到却都覆盖同一接收者，冲突发生在接收端；无线环境噪声大、信噪比低，冲突检测不可靠。所以改为"发送前避免"。

**5.** 缺点：多两次握手，网络效率下降。优点：RTS/CTS 帧很短、开销小；若不用，一旦长数据帧冲突就要整体重传，浪费更大。所以适合大帧、隐藏终端明显的场景。

**6.** 11b：2.4 GHz，1/2/5.5/11 Mbps，3 个非重叠信道；11a：5 GHz，6–54 Mbps，12 个非重叠信道，与 11b/g 不互通；11g：2.4 GHz，6–54 Mbps，兼容 11b。频段决定能否共存，调制方式决定速率上限。

**7.** ① 伪造 AP：攻击者用与合法网络相同的 SSID、更强的信号，使客户端探测软件误判为合法 AP，用户连上后所有操作被窃取。② 内部私搭 AP：内部有效用户未经批准安装 AP，把内网延伸到墙体之外，远处攻击者可直接进入内网，绕过边界防护。

**8.** 原理：AP 不在 Beacon 中广播 SSID，终端必须手工输入网络名才能关联，普通扫描列表里看不到。局限：Active Scanning 时 STA 会主动发送带 SSID 的 Probe request，抓包即可获得；已关联终端的管理帧中也含 SSID；攻击者还可以伪造同名 AP 反向钓鱼。所以它只降低被发现概率。

**9.** SSID 是网络的名字，用于标识服务集；BSS 是一个 AP 与其关联 STA 构成的基本服务集；ESS 是采用相同 SSID 的多个 BSS 组成的更大虚拟服务集，支持漫游；DS 是连接各 AP 的分布式系统（骨干网），负责在 AP 之间转发。

</details>

> **一句话总结**：无线四步是扫描、认证、关联、传数据；两种扫描一个省电一个快；CSMA/CA 用"先约后发"替代"边发边听"，因为射频半双工且存在隐藏终端；恶意 AP 外部冒充、内部开口，隐藏 SSID 只降低被扫到的概率。
