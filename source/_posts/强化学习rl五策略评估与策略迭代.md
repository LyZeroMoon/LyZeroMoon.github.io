## 一、策略评估（Policy Evaluation）

### 1.1 定义

策略评估是指：给定一个固定的策略 $\pi$，计算它的状态价值函数 $V^\pi(s)$（或 $Q^\pi(s,a)$）。

### 1.2 用什么公式

使用贝尔曼期望方程：

$$
V^\pi(s) = \sum_a \pi(a\mid s) \left[ R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s') \right]
$$

### 1.3 怎么算

有两种方式：

| 方式 | 做法 | 适用场景 |
|---|---|---|
| 解析求解 | 解线性方程组 $V = (I - \gamma P^\pi)^{-1} R^\pi$ | 状态数很小（几十以内） |
| 迭代求解 | 反复套用更新公式 $V_{k+1}(s) = \sum_a \pi(a|s) [R + \gamma \sum_{s'} P V_k]$ 直到收敛 | 状态数较大时 |

### 1.4 一句话

策略评估就是回答：「如果我按这个策略走，每个状态平均能拿多少分？」

## 二、策略改进（Policy Improvement）

### 2.1 定义

策略改进是指：根据当前的价值函数 $V^\pi$（或 $Q^\pi$），构造一个比原来更好的策略 $\pi'$。

### 2.2 怎么做

使用贪心策略：在每个状态 $s$，选择使 $Q^\pi(s,a)$ 最大的动作：

$$
\pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s') \right]
$$

### 2.3 为什么有效

策略改进定理保证：如果 $\pi'$ 是按上述贪心方式从 $V^\pi$ 构造出来的，那么 $\pi'$ 至少不比 $\pi$ 差，即：

$$
V^{\pi'}(s) \geq V^\pi(s), \quad \forall s
$$

### 2.4 一句话

策略改进就是回答：「既然知道了每个状态的价值，那我能不能换个动作做得更好？」

## 三、策略迭代（Policy Iteration）

### 3.1 定义

策略迭代是将策略评估和策略改进交替进行，直到策略不再变化（即收敛到最优策略）的算法。

### 3.2 算法流程

```text
1. 初始化：随机选择一个策略 π₀
2. 重复直到收敛：
   a. 策略评估：计算当前策略 π_k 的价值函数 V^{π_k}
   b. 策略改进：基于 V^{π_k} 构造新策略 π_{k+1}(s) = argmax_a Q^{π_k}(s,a)
3. 如果 π_{k+1} = π_k，则 π_k 就是最优策略 π*
```

### 3.3 图示

```text
π₀ → [策略评估] → V^{π₀} → [策略改进] → π₁
π₁ → [策略评估] → V^{π₁} → [策略改进] → π₂
...
π_k → [策略评估] → V^{π_k} → [策略改进] → π_{k+1} = π_k → 停止
```

## 四、三种方法的对比

| 方法 | 做了什么 | 更新依据 | 最终产出 |
|---|---|---|---|
| 策略评估 | 固定策略，算 $V$ | 贝尔曼期望方程（$\sum \pi$） | 该策略下的价值函数 |
| 策略改进 | 固定 $V$，改进 $\pi$ | 贪心取 $\max Q$ | 更好的策略 |
| 策略迭代 | 交替评估→改进 | 评估用期望方程，改进用贪心 | 最优策略 $\pi^*$ 和 $V^*$ |

## 五、与值迭代的关系

| 对比维度 | 策略迭代 | 值迭代 |
|---|---|---|
| 更新对象 | 交替更新 $\pi$ 和 $V$ | 只更新 $V$，最后提取 $\pi$ |
| 每轮成本 | 策略评估可能需多轮迭代 | 每轮只做一次 $\max$ 更新 |
| 收敛判断 | 策略不再变化 | 价值变化小于阈值 |
| 收敛速度 | 通常迭代次数少（策略空间小） | 迭代次数多但每轮快 |
| 本质 | 在策略空间中搜索 | 在价值空间中搜索 |

## 六、直观类比（厨师做菜）

| 概念 | 类比 |
|---|---|
| 策略 $\pi$ | 一份菜谱 |
| 策略评估 | 按这份菜谱做一道菜，尝味道，打分（85分） |
| 策略改进 | 根据打分，修改菜谱（盐减半，火候调大） |
| 策略迭代 | 反复：改菜谱 → 做菜 → 尝味道 → 再改菜谱，直到菜谱不能再改进 |
| 值迭代 | 不管菜谱，直接琢磨「理想中这道菜应该是什么味」，最后反推出菜谱 |

## 七、总结

- 策略评估：给定 $\pi$，算 $V^\pi$（用期望方程）
- 策略改进：给定 $V^\pi$，改进 $\pi$（用贪心）
- 策略迭代：评估 → 改进 → 评估 → 改进 ... 直到收敛
- 三者关系：策略迭代 = 策略评估 + 策略改进 的交替循环

<summary>4 道简答题的参考解析</summary>

**题 13 解析**

策略评估只负责「算账」：策略定死不动，反复代期望方程把 $V^\pi$ 算出来。它不产生新策略。而策略评估算出的 $V^\pi$ 正是策略改进的输入——没有它，贪心那一步没有得比。

**题 14 解析**

有两条路。状态少时直接解线性方程组 $V = (I-\gamma P^\pi)^{-1}R^\pi$，一次算准，代价是 $O(n^3)$ 的求逆。状态多时改为迭代：从任意 $V_0$ 出发反复代期望方程，$\gamma<1$ 时误差每轮乘 $\gamma$，收敛到同一个解。后者不求逆，也不要求 $P^\pi$ 可逆。

**题 15 解析**

因为 $Q^\pi(s,a)$ 里已经含了「在 $s$ 做 $a$、之后按 $\pi$ 走」的全部信息。按 $Q^\pi$ 取 $\max$ 得到的策略，在每一个状态上的动作都不比按 $\pi$ 抽样差；把这件事在整条轨迹上展开，就得到 $V^{\pi'}(s)\ge V^\pi(s)$ 对每个 $s$ 成立。等号成立即说明 $\pi$ 已经最优。

**题 16 解析**

策略迭代的停止条件是「策略不再变化」——$\pi_{k+1}=\pi_k$，此时贪心已经选不出更好的动作，$\pi_k$ 就是 $\pi^*$。值迭代没有显式策略可比，只能看价值：两轮之间 $V$ 的最大变化小于阈值就停，最后再用 $\arg\max_a Q$ 把策略提取出来。
