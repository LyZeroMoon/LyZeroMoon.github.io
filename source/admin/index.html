只在这里输入这一次。它会被你的密码加密后保存，明文不会上传。

加密后的配置会随站点一起公开（仓库是公开的），但没有密码无法解开。请设置一个足够强的密码，不要用常见的单词或生日。
还没有 Token？点这里看怎么生成
  1. 打开 github.com/settings/tokens
  2. 点 Generate new token → Generate new token (classic)

  4. 权限勾选 repo 和 workflow（两个都要）

小游戏

导航栏上的「小游戏」板块。这里能开关整站游戏、指定哪款放在游戏中心最前面， 以及逐款启停、调序、改文案。改动要点了「发布游戏设置」、等构建走完才在线上生效。

打开游戏中心

每款游戏都要有同名脚本 source/js/games/<id>.js。 「id」是脚本文件名，也是最高分在本地的存储键，所以出过成绩的不要改它； 要换名字改「显示名称」就好。
